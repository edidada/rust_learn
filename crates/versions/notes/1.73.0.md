# Rust 1.73.0（2023-10-05）

> 来源：[releases.rs/docs/1.73.0](https://releases.rs/docs/1.73.0/)；演示：`cargo run -p versions --bin rustc_1_73_0`

## Language
- `clippy::fn_null_check` 上提为 `useless_ptr_null_checks`。
- `noop_method_call` 默认 warn。
- 宏中支持 try/async 的插值块。
- `unconditional_recursion` lint 可检测递归 drop。
- 对部分被错误判定为"不重叠"的 impl 添加 future 兼容警告。
- **`invalid_reference_casting` 变为默认 deny**（1.72 warn 转正：`&T` 转成 `&mut T` 是 UB）。

## Compiler
- 在 `.comment` 节写入版本信息（同 GCC/Clang）；v0 符号重整文档化。
- **稳定 `extern "thiscall"` 与 `"thiscall-unwind"` ABI**（x86 Windows）。
- 与 trait 相比，只在 impl 上检查 outlives 目标；定长不可反驳切片模式推导为数组类型；存在显式 auto trait impl 时丢弃默认实现。
- 新 tier 3 目标：`aarch64-unknown-teeos`、`csky-unknown-linux-gnuabiv2`、`riscv64-linux-android`、`riscv64gc-unknown-hermit`、`x86_64-unikraft-linux-musl`、`x86_64-unknown-linux-ohos`；`wasm32-wasi-preview1-threads` 升 tier 2。

## Libraries
- 为 `Arc<File>` 实现 Read/Write/Seek。
- `io::Sink` 功能并入 `io::Empty`。
- `Backtrace` 实现 `RefUnwindSafe`；`ExitStatus` 实现 `Default`。
- 为 str 实现 `SliceIndex<(Bound<usize>, Bound<usize>)>` — 可用 `Bound` 对切片。
- **默认 panic handler 消息格式改变**；`assert_eq!`/`assert_ne!` 的 panic 消息更干净。
- 修正（已弃用的）Android stat 结构定义。

## Stabilized APIs
- `Unsigned {integer}::div_ceil` — 向上取整除法。
- `Unsigned {integer}::next_multiple_of` / `checked_next_multiple_of` — 下一个倍数。
- `std::ffi::FromBytesUntilNulError`（补充稳定路径）。
- `std::os::unix::fs::{chown, fchown, lchown}` — 文件属主修改。
- **`LocalKey::<Cell<T>>::get/set/take/replace`** — 无需 with 即可操作 Cell 线程局部。
- **`LocalKey::<RefCell<T>>::with_borrow/with_borrow_mut/set/take/replace`** — RefCell 线程局部便捷方法。
- 以下 API 现在可在 const 上下文使用：`rc::Weak::new`、`sync::Weak::new`、`NonNull::as_ref`。

## Cargo
- 自定义 build script 中使用 `cargo::`（旧 `cargo:` 前缀的变体）时报错。

## Compatibility Notes
- 最低外部 LLVM 更新到 15。
- 检查返回位置 impl Trait 的非定义性使用（return position impl Trait）。

## Internal Changes
- 移除 LLVM pointee 类型（只支持 opaque pointers）；PGO/LTO/BOLT 构建流水线移植到 Rust；更新 LLVM 17 等。
