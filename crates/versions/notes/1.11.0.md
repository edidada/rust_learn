# Rust 1.11.0（2016-08-18）

> 来源：[releases.rs/docs/1.11.0](https://releases.rs/docs/1.11.0/)；演示：`cargo run -p versions --bin rustc_1_11_0`

## Language
- 支持 `cfg_attr` 嵌套；块尾允许产生语句的花括号宏调用；宏可在 trait 定义内部展开；`#[macro_use]` 自身被宏展开时也正常工作。

## Stabilized APIs
- `BinaryHeap::append`
- `BTreeMap::append` / `split_off`
- `BTreeSet::append` / `split_off`
- `f32::to_degrees` / `to_radians`（libcore 层面稳定，此前仅 libstd）
- `f64::to_degrees` / `to_radians`
- `Iterator::sum` / `product`
- `Cell::get_mut` / `RefCell::get_mut`

## Libraries
- `thread_local!` 支持单次调用多个定义并可加属性。
- `Cow` 实现 `Default`；`Wrapping` 实现 binary/octal/lower-hex/upper-hex Display；range 类型实现 Hash。
- `assert_eq!` 接受自定义错误消息（对齐 `assert!`）。
- 主线程名字从 `<main>` 改为 `main`。

## Cargo
- 禁止指定传递依赖的 feature；Windows 控制台颜色；cdylib 支持；`package.metadata` 键不再警告（留给第三方工具）；防止 dirty 发布；补全/颜色等大量修复。

## Performance
- 投影缓存大幅加速类型检查；**默认 HashMap 哈希器换成 SipHash 1-3**（更快且仍抗碰撞攻击）；Ipv4Addr 比较快 10 倍。

## Rustdoc / Tooling
- rustdoc 一批修复；rustc 更擅长定位 MSVC 工具链；更多错误有编号与扩展解释。

## Misc
- rustc 不再因递归 re-export 卡死；要求 LLVM 3.7+；支持 16 位指针宽度（为 AVR 铺路）。

## Compatibility Notes
- const/static 不能是非 Sized 类型。
- 宏 `follow-set` 限制规则（RFC 550 修正）启用（1.10 起警告）。
- cfg 属性处理重构，个别角落场景破坏。
