# Rust 1.7.0（2016-03-03）

> 来源：[releases.rs/docs/1.7.0](https://releases.rs/docs/1.7.0/)；演示：`cargo run -p versions --bin rustc_1_7_0`

## Libraries
- **Stabilized APIs**：
  - `Path::strip_prefix`（改名自 relative_from）及新错误类型 `path::StripPrefixError`
  - `Ipv4Addr::is_loopback`/`is_private`/`is_link_local`/`is_multicast`/`is_broadcast`/`is_documentation`
  - `Ipv6Addr::is_unspecified`/`is_loopback`/`is_multicast`
  - `Vec::as_slice`/`as_mut_slice`、`String::as_str`/`as_mut_str`
  - `<[T]>::clone_from_slice`（要求等长）、`<[T]>::sort_by_key`
  - 整型 checked/saturating/overflowing 全家桶：`checked_rem/neg/shl/shr`、`saturating_mul`、`overflowing_add/sub/mul/div/rem/neg/shl/shr`（i32/u32 等全部原始整型）
  - FFI：`CString::into_string`/`into_bytes(_with_nul)`、`IntoStringError` 及其方法、`From<CString> for Vec<u8>`
  - 哈希：`std::hash::BuildHasher`/`build_hasher`/`BuildHasherDefault`、`HashMap::with_hasher`/`with_capacity_and_hasher`、`HashSet::with_hasher`/`with_capacity_and_hasher`、`RandomState`
  - `f32::to_degrees`/`to_radians`（f64 此前已稳定）
- ASCII UTF-8 校验快 7~14 倍（String/str 从字节构造更快）。
- LineWriter（含 `io::stdout`）用 memchr 找换行提速。
- `str::replace` 接受 Pattern；`Any` 支持非 Sized；`Hash` 实现于 `Duration`。
- BTreeMap 重写省内存并提升插入/遍历（最多 5 倍）；BTreeSet/LinkedList 协变化。

## Misc
- rustdoc 测试时把 `--cfg` 传给 rustc；编译器默认带 RPATH 构建；`--enable-new-dtags`。

## Cargo
- `cargo rustc --profile`；rerun-if-changed 修复。

## Compatibility Notes
- **RFC 1214 健全性错误正式生效**（1.4 起警告的关联类型/生命周期问题现在报错）。
- 可见性计算 bug 修复，先以 `private_in_public` lint 警告多个周期。
- 默认类型参数在非类型定义位置出现会警告（未来转错误）。
- **`".".parse::<f32>()` 现在返回 Err 而不是 Ok(0.0)**。
- 闭包参数的借用不能活过闭包本身。
