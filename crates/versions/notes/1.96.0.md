# Rust 1.96.0（2026-05-28）

> 来源：[releases.rs/docs/1.96.0](https://releases.rs/docs/1.96.0/)；演示：`cargo run -p versions --bin rustc_1_96_0`

## Language
- 允许把 expr 元变量传给 `cfg!`。
- 元组表达式里总是强转 never 类型。
- 罕见场景下避免对函数参数的错误推断引导。
- inline asm 支持 s390x 向量寄存器。
- 允许 `ManuallyDrop` 类型的常量作模式（修 1.94.0 引入的回归）。

## Compiler
- LoongArch Linux 目标启用 link relaxation；`riscv64gc-unknown-fuchsia` 基线升到 RVA22 + vector。

## Libraries
- **支持对 NonZero 整数 range 的迭代**。
- 重构"valid for read/write"定义：排除空指针，例外移到个别方法上。
- 修 SGX 上通过 `ToSocketAddr` 的延迟 host 解析。

## Stabilized APIs
- **`assert_matches!`、`debug_assert_matches!`**
- `From<T> for AssertUnwindSafe<T>`
- `From<T> for LazyCell<T, F>` / `From<T> for LazyLock<T, F>`
- **`core::range` 模块扩展**：`RangeToInclusive`、`RangeToInclusiveIter`、`RangeFrom`、`RangeFromIter`、`Range`、`RangeIter`

## Cargo
- 依赖可同时指定 git 仓库与备用 registry（本地用 git，发布用 registry 版本）。
- 支持 `target.'cfg(..)'.rustdocflags` 配置。
- 修 CVE-2026-5222 / CVE-2026-5223。

## Rustdoc
- Deprecation 注释按普通文档渲染（不再 pre-wrap/剥 `<p>`；强制换行用行尾两空格）。
- impl items 不再触发 `missing_doc_code_examples` lint。
- 侧栏分开 methods 与 associated functions。

## Compatibility Notes（全列）
- `#[repr(Int)]` 枚举在含"uninhabited 零大小字段"边角情况的布局修正。
- **禁止 unsize 强转到 `Pin<Foo>`（Foo 不实现 Deref）**——此前能编过但类型无有用公共 API。
- rustc 不再对 wasm 目标传 `--allow-undefined`。
- 意外稳定过的 `#![reexport_test_harness_main]` 被门控。
- return-position-impl-trait-in-traits 类型过私 → 报错。
- `uninhabited_static` lint 在依赖中报告并升为 deny。
- windows-gnu 分布式构建含 non-split debuginfo（改善 backtrace）。
- 更多位置校验 const 泛型参数类型正确性。
- 移除 `-Csoft-float`。
- `use S::{self as Other};` 不再允许（`{self}` 导入需要模块父级）。
- `export_name`/`link_name`/`link_section` 重复时**第一个生效**（原先行为相反）。
- 最低外部 LLVM 升至 21。
- avr 目标上 `c_double` 改为 f32（匹配 C double=32-bit）——破坏性但必要。
- `BTreeMap::append()` 优化后，错误 Ord 实现的类型可能 panic。

## Internal
- JSON targets：aarch64 softfloat 目标必须设置 `rustc_abi = "softfloat"`；target specs 对 LLVM ABI 值更严格并与 `cfg(target_abi)` 关联。
