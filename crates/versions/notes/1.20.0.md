# Rust 1.20.0（2017-08-31）

> 来源：[releases.rs/docs/1.20.0](https://releases.rs/docs/1.20.0/)；演示：`cargo run -p versions --bin rustc_1_20_0`

## Language
- **关联常量（associated constants）正式稳定**：可以在 `impl` 块中定义 `const`，也可以放在 trait 定义里，取代散落的全局常量。
  ```rust
  struct Level;
  impl Level { const MAX: u8 = 10; }
  ```
- **一大批宏 bug 被修复**。

## Compiler
- 结构体字段现在会正确地向期望类型做类型强转（coercion）。
- 启用 wasm 的 LLVM 后端，可用 `wasm32-experimental-emscripten` 目标构建。
- 部分错误信息更加友好。
- 为支持的平台增加 RELRO（RELocation Read-Only）支持。
- `rustc` 在编译失败时报告**错误总数**（以前只显示失败 pass 内的数量）。
- 展开阶段加速 29 倍；新增 `msp430-none-elf` 目标；修复 Redox 上的回溯。

## Libraries
- 放宽 `{HashMap,BTreeMap}::{Keys,Values}` 的 `Debug` 约束。
- 为未定长（unsized）元组实现 `PartialEq/Eq/PartialOrd/Ord/Debug/Hash`。
- 为 `Ref/RefMut/MutexGuard/RwLockReadGuard/RwLockWriteGuard` 实现 `fmt::{Display, Debug}`。
- 为 `DefaultHasher` 实现 `Clone`；为 `SyncSender` 实现 `Sync`；为 `char` 实现 `FromStr`。
- `f32/f64::is_sign_negative/is_sign_positive` 正确处理 NaN 符号。
- `unimplemented!()` 允许携带消息：`unimplemented!("Waiting for 1.21")`。
- `thread_local!` 支持 `pub(restricted)`；Unicode 升级到 10.0.0。
- `{f32,f64}::{min,max}` 改用 Rust 重新实现；`Iterator::nth` 对 `ops::{Range,RangeFrom}` 变为 O(1)。
- `#[repr(align(N))]` 的 N 上限提高为 2^31−1（原先 2^15）。
- `{OsStr,Path}::Display` 减少分配。

## Stabilized APIs
- `CStr::into_c_string`、`CString::as_c_str`、`CString::into_boxed_c_str`
- `Chain::get_mut`、`Chain::get_ref`、`Chain::into_inner`
- `Option::get_or_insert_with`、`Option::get_or_insert`
- `OsStr::into_os_string`、`OsString::into_boxed_os_str`
- `Take::get_mut`、`Take::get_ref`
- `Utf8Error::error_len`
- `char::EscapeDebug` / `char::escape_debug`
- `compile_error!` 宏
- `f32::from_bits`、`f32::to_bits`、`f64::from_bits`、`f64::to_bits`
- `mem::ManuallyDrop`
- `slice::sort_unstable_by_key`、`slice::sort_unstable_by`、`slice::sort_unstable`
- `str::from_boxed_utf8_unchecked`、`str::as_bytes_mut`、`str::from_utf8_mut`、`str::from_utf8_unchecked_mut`、`str::get_mut`、`str::get_unchecked_mut`、`str::get_unchecked`、`str::get`、`str::into_boxed_bytes`

## Cargo
- API token 位置从 `~/.cargo/config` 迁移到 `~/.cargo/credentials`。
- `src/bin` 的子目录中含 `main.rs` 的多文件二进制也会被构建（如 `src/bin/server/main.rs` → `target/debug/server`）。
- `cargo install` 支持 `--vers` 指定版本；新增 `--no-fail-fast`。
- crate root 文件约定调整。

## Compatibility Notes
- 返回 `'static` 类型（而非用生命周期参数）的函数可用性下降。
- `is_sign_{negative,positive}` 重新实现后开始考虑 NaN 的符号（行为变化）。
