# Rust 1.79.0（2024-06-13）

> 来源：[releases.rs/docs/1.79.0](https://releases.rs/docs/1.79.0/)；演示：`cargo run -p versions --bin rustc_1_79_0`

## Language
- **稳定 inline const 表达式 `const { … }`**：在任何表达式位置内联一段保证编译期求值的代码；块内产生的是常量语义（对浮点特殊值、与运行时产生差异的逻辑极有用），比关联常量更轻量。
- 阻止 opaque 类型在同一函数内以不同 region 被实例化两次。
- 稳定处于 phase 4/5 的 WebAssembly target feature。
- 新增 `redundant_lifetimes` lint：检测语义上冗余的生命周期标注。
- 稳定 `unnameable_types` lint：对无法命名的公共类型告警。
- 宏内启用 debuginfo；稳定 `-C collapse-macro-debuginfo` 与 `#[collapse_debuginfo]`。
- 临时生命周期延长传播进 `if`/`match` 表达式。
- 约束 const fn 调用的 promotion；警告 crate-private trait 的 impl 细化（`refining_impl_trait`）。
- **稳定 associated type bounds（RFC 2289）**：`T: Iterator<Item: Clone>` 形式的关联类型界。
- 稳定从其他模块或 crate 导入 `main`。
- 检查函数类型返回类型的良构性；重做 impl Trait 生命周期推断；归纳循环改为 ambiguous。

## Compiler
- `-C strip` 只作用于二进制；稳定 `-Crelro-level`；稳定 `--check-cfg`（编译器部分）。
- 新目标：aarch64-apple-visionos(-sim)、riscv32ima-unknown-none-elf（tier 3）；若干 Windows gnullvm 目标升 tier 2。

## Libraries
- `FromIterator for (impl Default + Extend, …)`；`{Div,Rem}Assign<NonZero<X>>`；MSVC 默认库在 core 中链接；std 启用帧指针。

## Stabilized APIs
- `{integer}::unchecked_add` / `unchecked_mul` / `unchecked_sub`
- `<[T]>::split_at_unchecked` / `split_at_mut_unchecked`
- `<[u8]>::utf8_chunks` / `str::Utf8Chunks` / `str::Utf8Chunk`
- `<*const T>::is_aligned` / `<*mut T>::is_aligned` / `NonNull::is_aligned`
- `<*const [T]>::len` / `<*mut [T]>::len` / `<*const [T]>::is_empty` / `<*mut [T]>::is_empty` / `NonNull::<[T]>::is_empty`
- `CStr::count_bytes` / `io::Error::downcast` / `num::NonZero<T>`（泛型化） / `path::absolute`
- `proc_macro::Literal::byte_character` / `proc_macro::Literal::c_string`
- 以下可用于 const 上下文：`Atomic*::into_inner`、`io::Cursor::new/get_ref/position`、`io::empty/repeat/sink`、`panic::Location::caller/file/line/column`

## Cargo
- `lib.name` 禁止连字符（归一化为 `_`）；稳定 `cargo add` 的 MSRV 感知版本选择；切换到 gitoxide 列出文件。

## Rustdoc
- 总是显示稳定性版本；多路径条目合并搜索结果；`/` 键搜索。

## Compatibility Notes
- 最低外部 LLVM 升至 17。
- `RustcEncodable`/`RustcDecodable` 软性去稳定。
- `wasm_c_abi` future-incompat lint 对不合规范的 C ABI 告警。
- 函数类型返回类型的良构检查。
