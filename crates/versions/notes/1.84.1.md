## 说明（patch release）
- 修复重复 crate 诊断中的 ICE 132920（编译器内部错误而非用户代码错误）。
- 修复增量重编译时**重叠 impl（overlapping impls）报错**的问题。
- 修复与下一代 trait solver 相关的**编译缓慢**问题。
- 修复 LLVM location discriminator 值超限时的 debuginfo 问题。
- 从源码构建 Rust 的修复：llvm-objcopy 仅在启用 llvm tools 时分发；非 Git 源支持 profile override；复制 LLVM 工具前解析符号链接；tarball 源码可使用 ci-rustc。
