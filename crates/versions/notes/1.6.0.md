# Rust 1.6.0（2016-01-21）

> 来源：[releases.rs/docs/1.6.0](https://releases.rs/docs/1.6.0/)；演示：`cargo run -p versions --bin rustc_1_6_0`

## Language
- **`#![no_std]` 稳定化**（RFC 1184）：crate 只链接 core 库；core 定义基础类型/trait 且零平台依赖，是操作系统等裸机环境的基石；core 的大部分 API 随之稳定。

## Libraries
- **Stabilized APIs**：
  - `Read::read_exact`
  - `ErrorKind::UnexpectedEof`（改名自 UnexpectedEOF）
  - `fs::DirBuilder`、`DirBuilder::new`、`recursive`、`create`、`os::unix::fs::DirBuilderExt`（含 `mode`）
  - `vec::Drain`、`Vec::drain`、`string::Drain`、`String::drain`、`vec_deque::Drain`、`VecDeque::drain`、`HashMap::drain`、`HashSet::drain`、`BinaryHeap::drain`
  - `Vec::extend_from_slice`（改名自 push_all）
  - `Mutex::get_mut`/`into_inner`、`RwLock::get_mut`/`into_inner`
  - `Iterator::min_by_key`（改名自 min_by）、`Iterator::max_by_key`（改名自 max_by）
- `assert_eq!` 支持非 `Sized` 参数（如数组）。
- 毫秒计时的定时 API 弃用（`Condvar::wait_timeout_ms`、`thread::sleep_ms`、`thread::park_timeout_ms`），统一改用 `Duration`。
- `Vec` 增长算法微调，避免过度分配。
- 无损 `From`：整数→浮点（仅无损场景）、f32→f64、`Cow<Path>` 与 `PathBuf` 互转、`From<T> for Box/Rc/Arc`；`IntoIterator` 实现于 `&PathBuf`/`&Path`。
- `BinaryHeap` 重构小幅提速；有序切片排序快 50%。

## Cargo
- 在 `$CARGO_HOME/bin` 中查找子命令；构建脚本可发 `rerun-if-changed`；**通配符依赖的 crate 拒绝发布**；`cargo clean --release`。

## Misc
- `unreachable_code` lint 对发散参数报警；解析器提示易混淆 Unicode 字符；部分宏错误在定义期报告。

## Compatibility Notes
- 不再使用 `RUST_PATH` 环境变量找 crate（pre-cargo 时代遗留）。
- 隐私检查器若干 bug 修复可能使旧代码报错。
- 模块与单元/元组结构体不能重名；元组结构模式 `Foo(..)` 不能再匹配单元结构体（先警告）；与 const 同名的模式变为错误。
- 跨 crate trait 方法解析时默认类型参数的修复。
