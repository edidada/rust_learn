# Rust 1.64.0（2022-09-22）

> 来源：[releases.rs/docs/1.64.0](https://releases.rs/docs/1.64.0/)；演示：`cargo run -p versions --bin rustc_1_64_0`

## Language
- union 允许 `&mut`（可变引用）或由允许类型组成的元组作字段。
- `&T` 指向的内存全是 `UnsafeCell` 字节时，允许 deallocate 该内存（放宽归还判定）。
- 新 allow-by-default lint `unused_tuple_struct_fields`：未使用的元组结构体字段告警（未来转 warn）。

## Compiler
- Nintendo Switch 作为 tier 3 target；ELF 上 `#[used]` 用 llvm.compiler.used；`--diagnostic-width` 设置终端宽度；iOS/tvOS/watchOS 支持 link-flavor rust-lld。

## Libraries
- 解除 compare-exchange 内存序限制（顺序允许任意组合）。
- `OsString` 实现 `fmt::Write`（可 `write!` 进 OsString）。
- `RwLockReadGuard` 协变；`std::net::{Into,Incoming}` 实现 `FusedIterator`。
- `{Arc,Box}<T: AsRawFd>` 实现 `AsRawFd`；`ptr::copy`/`swap` 是无类型拷贝。
- `available_parallelism` 支持 cgroupv1；缓解许多 `mem::uninitialized` 误用。

## Stabilized APIs
- `future::IntoFuture` / `future::poll_fn` / `task::ready!`
- `num::NonZero*::checked_mul` / `checked_pow` / `saturating_mul` / `saturating_pow`
- `num::NonZeroI*::{abs, checked_abs, overflowing_abs, saturating_abs, unsigned_abs, wrapping_abs}`
- `num::NonZeroU*::{checked_add, checked_next_power_of_two, saturating_add}`
- `os::unix::process::CommandExt::process_group` — 子进程组
- `os::windows::fs::FileTypeExt::{is_symlink_dir, is_symlink_file}`
- 以下类型从 std::ffi 复制到 core/alloc：`core::ffi::{CStr, FromBytesWithNulError}`、`alloc::ffi::{CString, FromVecWithNulError, IntoStringError, NulError}`
- 以下类型从 std::os::raw 也可通过 `core::ffi`/`std::ffi` 使用：`ffi::{c_char, c_double, c_float, c_int, c_long, c_longlong, c_schar, c_short, c_uchar, c_uint, c_ulong, c_ulonglong, c_ushort}`
- 以下 API 可用于 const 上下文：`slice::from_raw_parts`

## Cargo
- **workspace 继承**：`workspace.package` / `workspace.dependencies` 让子包公共化 workspace 级设置（版本、依赖统一）。
- `cargo build --target` 接受多次，可一次构多 target；`--jobs` 支持负数（从最大 CPU 反推）。
- `cargo add` 更新 Cargo.lock；`cargo rustc --crate-type <ty>`；GitHub rev hash 拉取性能提升。

## Misc
- rustup stable 渠道提供 rust-analyzer component。

## Compatibility Notes
- 所有 `-linux-gnu` 目标内核基线提升到至少 3.2、glibc 2.17。
- 网络基础类型改用理想 Rust 布局而非 C 系统布局（transmute 这些类型会出问题）。
- 对 `transmute_copy` 的 `U` 比 `T` 大的情况加断言。
- BTreeMap 一个 soundness bug 修复（借用数据可提前 drop）。
- C-like 枚举 cast 到 int 的 Drop 行为变化（本就不被推荐）。
- NLL 中 closure 后绑定生命周期与父函数关联；const-eval 时错误进 future-incompat 报告。
- thumbv6m-none-eabi 上 asm! 不再接受用高寄存器（r8..r14）作输入输出操作数的错误 asm。
- 修复 RPIT（return-position impl Trait）作为关联类型值时未满足全部 bound 也被接受的问题。
