# Rust 1.32.0（2019-01-17）

> 来源：[releases.rs/docs/1.32.0](https://releases.rs/docs/1.32.0/)；演示：`cargo run -p versions --bin rustc_1_32_0`

## Language
### 2018 edition
- 宏定义可用 `?` 重复符（零或一次，类似 `*`/`+`）。
- 无 `super/self/crate` 前缀的模块路径优先解析为**当前模块中的同名项**（enum、struct 等），其次才是外部 crate/prelude：
  ```rust
  enum Color { Red, Green, Blue }
  use Color::*;
  ```

### 所有 edition
- 可对 `PhantomData<T>` 类型做模式匹配。
- 宏 `literal` 匹配符可匹配任意字面量（`1`、`'A'`、`"Hello World"`）。
- **`Self` 可作单元/元组结构体的构造器与模式**；`Self` 也可用在类型定义里（`where Self: PartialOrd<Self>`、`Box<Self>` 等）。
- trait 可标 `#[must_use]`：返回 `impl Trait`/`dyn Trait` 且未使用时警告。

## Compiler
- **默认分配器由 jemalloc 改为系统分配器**（编译器自身在 Linux/macOS 仍用 jemalloc）。
- 新增 `aarch64-pc-windows-msvc` 目标。

## Libraries
- `PathBuf` 实现 `FromStr`；`Box<[T]>` 实现 `FromIterator<T>`。
- **`dbg!` 宏稳定**：快速打印表达式值与位置。
- 以下 API 成为 const fn（可用于 const 上下文）：`Cell::as_ptr`、`UnsafeCell::get`、`char::is_ascii`、`iter::empty`、`ManuallyDrop::new/into_inner`、`RangeInclusive::start/end`、`NonNull::as_ptr`、`slice::as_ptr`、`str::as_ptr`、`Duration::as_secs/subsec_millis/subsec_micros/subsec_nanos`、`CStr::as_ptr`、`Ipv4Addr::is_unspecified`、`Ipv6Addr::new/octets`。

## Stabilized APIs
- 全部整型的 `to_be_bytes/to_le_bytes/to_ne_bytes/from_be_bytes/from_le_bytes/from_ne_bytes`（`i8..u128`、`isize/usize`）

## Cargo
- `cargo c` = `cargo check` 别名；alt registry URL 允许用户名。

## Misc
- rust-src 发行版包含 libproc_macro。

## Compatibility Notes
- AVX 的 `_mm256_stream_si256/_mm256_stream_pd/_mm256_stream_ps` 参数从 `*const` 改为 `*mut`（原实现不健全）。
