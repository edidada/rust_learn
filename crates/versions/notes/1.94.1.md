# Rust 1.94.1（2026-03-26）

> 来源：[releases.rs/docs/1.94.1](https://releases.rs/docs/1.94.1/)；演示：`cargo run -p versions --bin rustc_1_94_1`

Patch 版本，内容少，逐条照实记录：

## 修复
- 修复 `wasm32-wasip1-threads` 目标上 `std::thread::spawn` 不可用的问题（平台后端修复）。

## 兼容性
- **移除 `std::os::windows::fs::OpenOptionsExt` 上新加的方法**：这些方法当时 unstable，而该 trait 并非 sealed，不能向非 sealed trait 添加非 default 方法（会破坏下游实现者），故回退——等 trait sealed 后再补。

## Clippy
- 修复 `match_same_arms` lint 的 ICE（内部编译错误）。

## Cargo
- `tar` 依赖更新到 0.4.45，解决 **CVE-2026-33055 / CVE-2026-33056**（打包/解包路径相关）；crates.io 用户不受影响。
