# Rust 1.41.1（2020-02-27）

> 来源：[releases.rs/docs/1.41.1](https://releases.rs/docs/1.41.1/)；演示：无（patch 版仅 bugfix，不配演示）

## 说明
patch 版本，无语言/库稳定化内容，只有 bugfix（以下为该页列出的修复项）。

## Patch Fixes
- 总是检查 static 项的类型（Always check types of static items）。
- 总是检查 `Copy` impl 的生命周期约束（Always check lifetime bounds of Copy impls）。
- 修复 `Layout::repeat` 调用方的一处错误编译（miscompilation）。
- 官方原宣布 1.41.0 是最后一个为 tier 1/2 的 32 位 Apple 目标发布二进制的版本，但未料到会有 patch 发布；**1.41.1 的发布物仍包含这些 32 位 Apple 目标**。

## 演示对照
patch 版无新增稳定 API，不提供演示。
