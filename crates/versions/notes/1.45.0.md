# Rust 1.45.0（2020-07-16）

> 来源：[releases.rs/docs/1.45.0](https://releases.rs/docs/1.45.0/)；演示：`cargo run -p versions --bin rustc_1_45_0`

## Language
- **越界浮点→整数的 `as` 定义为饱和转换**（此前是 UB）；性能敏感且确认不越界时可用 `{f64,f32}::to_int_unchecked`。
- `mem::Discriminant<T>` 使用 T 的判别类型，而非固定 `u64`。
- **函数式过程宏可用于 expression/pattern/statement 位置**——凡 `macro_rules!` 可用之处均可使用函数式 proc macro。

## Compiler
- 可单独覆盖 target-feature：`-C target-feature=+avx2 -C target-feature=+fma` 等价 `+avx2,+fma`。
- 新增 `force-unwind-tables`、`embed-bitcode`、`code-model=tiny` 旗标。
- 新增 tier 3 目标（mipsel-sony-psp、thumbv7a-uwp-windows-msvc）。
- 升级 LLVM 10。

## Libraries
- `net::{SocketAddr, SocketAddrV4, SocketAddrV6}` 实现 `PartialOrd`/`Ord`。
- `proc_macro::TokenStream` 实现 `Default`。
- **char 可用在 Range 迭代**：`for ch in 'a'..='z'` 遍历码点。
- `OsString` 实现 `FromStr`。
- 有符号整数新增 `saturating_neg`、全部整数新增 `saturating_abs`。
- `Arc<T>`/`Rc<T>` 实现 `From<Cow>`；`Box` 从 `Cow`（`T: [T: Copy]`/`str`/`CStr`/`OsStr`/`Path`）。
- `Box<[T]>` 实现 `From<[T; N]>`。
- 所有 NonZero 整数实现 `BitOr`/`BitOrAssign`。
- 原子整数新增 `fetch_min`/`fetch_max`/`fetch_update`。

## Stabilized APIs
- `Arc::as_ptr` — Arc 指向的裸指针
- `BTreeMap::remove_entry` — 按键移出 (key,value)
- `Rc::as_ptr` — 同 Arc::as_ptr（Rc 版）
- `rc::Weak::as_ptr` / `from_raw` / `into_raw` — Weak 与裸指针互转
- `str::strip_prefix` — 剥离前缀
- `str::strip_suffix` — 剥离后缀
- `sync::Weak::as_ptr` / `from_raw` / `into_raw` — 跨线程 Weak 版
- `char::UNICODE_VERSION` — Unicode 版本常量
- `Span::resolved_at` / `located_at` / `mixed_site` — proc_macro Span 工具
- `unix::process::CommandExt::arg0` — 自定义 argv[0]

## Cargo
- 用 `embed-bitcode` 优化磁盘占用与构建时间。

## Misc
- rustdoc 支持 Markdown 删除线（`~~过时信息~~`）。
- rustdoc 弃用 API 消息新增 emoji。

## Compatibility Notes
- "自初始化 static"（用自身构造自身的值）是 unsound，现在编译错误。
- Windows 上 `{f32,f64}::powi` 结果可能略有变化（LLVM intrinsic 变更）。
- rustdoc CLI 删除了额外的错误退出码。
- rustc 的 `lto` 旗标与新版 `embed-bitcode=no` 不兼容；推荐在 Cargo profile 里控制 LTO。

## Internals Only
- Clippy 变成 git subtree；统一所有快照类型的 undo log。
