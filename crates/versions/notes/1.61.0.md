# Rust 1.61.0（2022-05-19）

> 来源：[releases.rs/docs/1.61.0](https://releases.rs/docs/1.61.0/)；演示：`cargo run -p versions --bin rustc_1_61_0`

## Language
- **const fn 能力扩展**：
  - const fn 签名可加泛型 trait bounds
  - const fn 签名可用 `impl Trait`（参数/返回位置）
  - const fn 内可以创建、cast、传递函数指针
  - 递归调用可设置函数 opaque `impl Trait` 返回值
- `#[link]` 属性和命令行的链接修改器（含 `+whole-archive` modifier）。
- char 类型 debuginfo 描述为 UTF-32；`#[target_feature]` 支持更多 aarch64 特性；x86 `adx` target_feature 稳定。

## Libraries
- `ManuallyDrop<T>` 文档明确同 `T` 布局；`#[ignore = "…"]` 消息会打印。
- Windows 缺失 stdio 句柄一致显示为 NULL。
- `std::io::stdio::lock()` 返回 `'static` 句柄：以前锁句柄借用 stdout 临时值，`let out = std::io::stdout().lock();` 不能写出；现在可以，消除常见 pitfall。
- `Vec::from_raw_parts` 输入要求放宽。
- `std::thread::available_parallelism` 考虑 cgroup 配额（如 8 vCPU 限 50% 时返回 4）。

## Stabilized APIs
- `Pin::static_mut` / `Pin::static_ref`
- `Vec::retain_mut` / `VecDeque::retain_mut` — 就地按谓词保留（可变访问）
- `Write for Cursor<[u8; N]>`
- `std::os::unix::net::SocketAddr::from_pathname`
- `std::process::ExitCode` / `std::process::Termination` — main 可返回自定义退出码
- `std::thread::JoinHandle::is_finished` — 非阻塞查询线程是否结束
- 以下 API 可用于 const 上下文：`<*const T>::{offset, wrapping_offset, add, sub, wrapping_add, wrapping_sub}`（`*mut T` 对应）、`<[T]>::as_mut_ptr`、`<[T]>::as_ptr_range/as_mut_ptr_range`

## Cargo
- 无特性变化，见兼容性注释。

## Compatibility Notes
- native static 库链接不再默认 whole-archive；可能新出链接错误（需重排序依赖或用 `+whole-archive` modifier）。
- FFI 捕捉第二次 unwind（Rust panic 清理期间）导致进程 abort。
- proc-macro 不再看到 group 包裹的 ident 匹配器。
- r# 原始字符串 `#` 个数须 < 256。
- 检查 dyn 类型满足 trait bound 时超级 trait bound 现在强制。
- `cargo vendor` 每个 `--sync` 只接受一个值。
- `cfg(all())` / `cfg(any())` 内谓词总是求值（不再短路），nightly-only 语法配 `all(feature=...)` 将编译失败，应改 `cfg_attr` 或嵌套 cfg。
- bootstrap：static-libstdcpp 默认启用。
