# Rust 1.84.0（2025-01-09）

> 来源：[releases.rs/docs/1.84.0](https://releases.rs/docs/1.84.0/)；演示：`cargo run -p versions --bin rustc_1_84_0`

## Language
- 允许 `#[deny]` 出现在 `#[forbid]` 内（作为 no-op）。
- `-Ctarget-feature` 切换可能造成 ABI 不匹配 unsoundness 的特性时给出警告。
- coherence 使用下一代 trait solver。
- 允许强转丢弃 trait 对象的 principal。
- Windows 上 `include!()` 一律支持 `/` 作路径分隔符。
- **对指针解引用取 raw ref 安全化**：`&raw const *ptr`（对裸指针解引用取新指针）不再需要 unsafe——新建指针本身不读内存。
- 稳定 s390x、Arm64EC inline assembly。
- 对"立即被 drop 的临时值建指针"加 lint。
- `extern "C"` 函数 unwinding 时执行 drop glue。

## Compiler
- `--print host-tuple`；当前目标不支持的调用约定触发硬错误；unexpected_cfgs lint 也作用于外部宏；wasm multivalue/reference-types/tail-call 特性稳定；wasm32v1-none 升 tier 2。

## Libraries
- `From<&mut {slice}> for Box/Rc/Arc<{slice}>`；`{float}::copysign/abs/signum` 移入 core；`NonZero` 实现 `LowerExp`/`UpperExp`；`FromStr for CString`、`TryFrom<CString> for String`；`std::os::darwin` 公开。

## Stabilized APIs
- `Ipv6Addr::is_unique_local` / `is_unicast_link_local`
- `core::ptr::with_exposed_provenance` / `with_exposed_provenance_mut`
- `<ptr>::addr` / `expose_provenance` / `with_addr` / `map_addr`
- `<int>::isqrt` / `checked_isqrt` / `<uint>::isqrt` / `NonZero::isqrt`
- `core::ptr::without_provenance` / `without_provenance_mut` / `dangling` / `dangling_mut`
- `Pin::as_deref_mut`
- 以下可用于 const 上下文：`Atomic*::from_ptr`（各原子类型）、`<ptr>::is_null` / `as_ref` / `as_mut`、`Pin::new` / `new_unchecked` / `get_ref` / `into_ref` / `get_mut` / `get_unchecked_mut` / `static_ref` / `static_mut`

## Cargo
- 稳定 MSRV 感知 resolver 配置；稳定 resolver v3。

## Rustdoc
- rustdoc-search：类型驱动搜索改进。

## Compatibility Notes
- LoongArch Linux 默认启用 LSX。
- 移除 `-Zprofile`（gcov 风格覆盖）；`-Cinstrument-coverage` 与 PGO 不受影响。
- 移除 `wasm32-wasi` 目标（彻底改名为 `wasm32-wasip1`）。
- `&pin (mut|const) T` 现在被解析为类型（极端宏展开场景可能受影响）。
- legacy `std::arch` 调用语法不能再声明项或函数体。
- 不支持的调用约定 → 硬错误；下一代 trait solver 用于 coherence。
