# Rust 1.2.0（2015-08-07）

> 来源：[releases.rs/docs/1.2.0](https://releases.rs/docs/1.2.0/)；演示：`cargo run -p versions --bin rustc_1_2_0`

约 1200 处变更。

## Highlights
- **DST 强制转换**：智能指针（如 `Rc`）可容纳无固定大小的类型（数组、trait 对象），`Rc<[T]>` 终于此版本可用。
- 并行 codegen 回归可用，可大幅加快 large debug 构建（`-C codegen-units=N` 开启）；自举再快 33%。
- Windows MSVC 链接实验性支持（首个版本），推荐继续 MinGW。
- 自举比 1.1 再快 30%。

## Breaking Changes
- `char::to_uppercase`/`to_lowercase` 改为真正 Unicode 大小写映射（视为 bugfix）。
- `mem::align_of` 语义对齐为 clang alignof 的最小对齐；`mem::min_align_of` 弃用。
- `#[packed]` 属性不再被静默接受（本来就没作用）。
- 关联类型默认值移入 `associated_type_defaults` feature gate（1.1 语法上可写但没效果）。

## Language
- `ref mut` 模式在匹配可解引用值时正确调用 `DerefMut`。

## Libraries
- `Extend` 对 `String`、`Vec`、`LinkedList`、`VecDeque`、`BinaryHeap`、`BTreeSet`、`BTreeMap` 等实现了引用迭代器版本。
- `iter::once` 产出单元素迭代器；`iter::empty` 产出空迭代器。
- `str::matches`/`rmatches` 返回子串匹配迭代器。
- `Cell`/`RefCell` 实现 `Eq`。
- 整型新增显式回绕方法：`wrapping_div`/`rem`/`neg`/`shl`/`shr`（补充已有的 add/sub/mul；默认算术溢出仍非法）。
- `{:#?}` 的替代 Debug（pretty print）格式。
- `fmt::Formatter` 实现 `fmt::Write`；新增 debug_struct/debug_tuple/debug_list/debug_set/debug_map 构建器。
- `str` 新增 `to_uppercase`/`to_lowercase`。
- 毒锁（poisoned lock）易用性：`PoisonError` 暴露 `into_inner`/`get_ref`/`get_mut`；`RwLock`/`Mutex` 的 `is_poisoned`。
- Stdio 的 FromRawFd/AsRawFd（Unix）与 ChildStdin/Out/Err 的对应实现（Windows）。
- `io::ErrorKind` 新变体 `InvalidData`。

## Misc
- 拼错类型启发式更聪明；unsafe 指针间 no-op 转换生成更高效代码；胖指针按一对立即数传递（更快编译、更小代码）。
