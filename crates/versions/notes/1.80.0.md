# Rust 1.80.0（2024-07-25）

> 来源：[releases.rs/docs/1.80.0](https://releases.rs/docs/1.80.0/)；演示：`cargo run -p versions --bin rustc_1_80_0`

## Language
- 文档化最大分配大小；允许任意指针上的零字节偏移与 ZST 读写。
- 支持 C23 无命名参数的变参（`void f(...)` 形式）。
- **稳定 `exclusive_range_pattern`**：模式中可用 `..=` 的姊妹形式——排他区间 `0..5` 作为模式（1.80 起 `a..b` 可直接匹配排除上界）。
- 在部分场景保证 `Result` 的布局与 ABI。

## Compiler
- `cc` 升级 v1.0.97；`repr(packed(1))` 类型允许字段重排；对影响 unsafe 代码的 never type fallback 加 lint；`for_loops_over_fallibles` lint 扩展。
- 新 tier 3 目标 x86_64-unknown-linux-none；wasm32-wasip2 默认 PIC。

## Libraries
- **`size_of`/`size_of_val`/`align_of`/`align_of_val` 进入 prelude**（无需 `std::mem::` 前缀）。
- 违反 FD 所有权时中止进程；`io::Write::write_fmt` 在 formatter 失败时 panic；`PathBuf::set_extension` 会加路径分隔符时 panic。
- `unchecked_{add,sub,neg,mul,shl,shr}` 加 `assert_unsafe_precondition`。

## Stabilized APIs
- `impl Default for Rc<CStr>` / `Rc<str>` / `Rc<[T]>` / `Arc<str>` / `Arc<CStr>` / `Arc<[T]>`
- `impl IntoIterator for Box<[T]>`；`impl FromIterator<String> for Box<str>`；`impl FromIterator<char> for Box<str>`
- **`LazyCell` / `LazyLock`**（本期重点：标准库自带惰性初始化，线程安全的 `LazyLock` 取代常见 once_cell 例行代码）
- `Duration::div_duration_f32` / `div_duration_f64`
- `Option::take_if` / `Seek::seek_relative` / `BinaryHeap::as_slice`
- `NonNull::offset` / `byte_offset` / `add` / `byte_add` / `sub` / `byte_sub` / `offset_from` / `byte_offset_from` / `read` / `read_volatile` / `read_unaligned` / `write` / `write_volatile` / `write_unaligned` / `write_bytes` / `copy_to` / `copy_to_nonoverlapping` / `copy_from` / `copy_from_nonoverlapping` / `replace` / `swap` / `drop_in_place` / `align_offset`
- `<[T]>::split_at_checked` / `split_at_mut_checked` / `str::split_at_checked` / `str::split_at_mut_checked`
- `str::trim_ascii` / `trim_ascii_start` / `trim_ascii_end`；`<[u8]>::trim_ascii` / `trim_ascii_start` / `trim_ascii_end`
- `Ipv4Addr::BITS` / `to_bits` / `from_bits`；`Ipv6Addr::BITS` / `to_bits` / `from_bits`
- `Vec::<[T; N]>::into_flattened`；`<[[T; N]]>::as_flattened` / `as_flattened_mut`
- 以下可用于 const 上下文：`<[T]>::last_chunk`、`BinaryHeap::new`

## Cargo
- `-Zcheck-cfg` 始终启用；target 排除时警告而非发布失败；稳定 `cargo update --precise <yanked>`；`cargo add` 不改 Cargo.toml 权限；IPv6-only 网络支持 `cargo fix`。

## Rustdoc
- 支持搜索引用；稳定 `custom_code_classes_in_docs`；跨 crate 场景修复枚举变体显示。

## Compatibility Notes
- rustfmt 对非 ASCII 行长估算变化；orphan check 正确处理类型别名；`std::env::{set_var, remove_var}` 不再可转为安全函数指针/实现 Fn 族；若干 lint 变硬错误；`ReentrantLockGuard` 与 `StdoutLock`/`StderrLock` 的 `Sync` 变化；`FromIterator for Box<str>` 引发的类型推断失败（time crate <0.3.35 受影响）。
