# Rust 1.80.1（2024-08-08）

> 来源：[releases.rs/docs/1.80.1](https://releases.rs/docs/1.80.1/)；演示：无代码演示（补丁版，无新语言/API 面）

## 说明（patch release）
- 修复 jump threading MIR 优化中比较浮点数时的一处**错误编译（miscompilation）**：`a < b` 形式的浮点比较在某些分支折叠场景下可能被错误地优化掉。
- **回滚 1.80.0 对 `dead_code` lint 的变更**：1.80.0 曾使 `dead_code` 对某些通过 trait 方法/间接调用使用的项更敏感，导致误报，1.80.1 恢复 1.79.x 的行为。
