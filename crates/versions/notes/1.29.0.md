# Rust 1.29.0（2018-09-13）

> 来源：[releases.rs/docs/1.29.0](https://releases.rs/docs/1.29.0/)；演示：`cargo run -p versions --bin rustc_1_29_0`

## Compiler
- 最低 LLVM 提至 5.0，随后升级到 LLVM 7；新增 `powerpc64le-unknown-linux-musl`、`aarch64-unknown-hermit`、`x86_64-unknown-hermit` 目标。

## Libraries
- `Once::call_once` 不再要求 `Once` 为 `'static`。
- `BuildHasherDefault` 实现 `PartialEq/Eq`；`Box<CStr>/Box<OsStr>/Box<Path>` 实现 `Clone`。
- `OsString` 与 `&str` 互为 `PartialEq`；`Cell<T>` 允许未定长 `T`；`SocketAddr` 在 Redox 上稳定。

## Stabilized APIs
- `Arc::downcast` — 把 `Arc<dyn Any>` 转回具体类型。
- `Iterator::flatten` — 拍平嵌套迭代。
- `Rc::downcast` — 把 `Rc<dyn Any>` 转回具体类型。

## Cargo
- 可自动修复部分损坏 lockfile（`--locked` 可禁）。
- 新增 `cargo fix` 子命令：自动把 2015 版代码迁移到 2018。
- `cargo doc` 支持 `--document-private-items`。

## Misc
- rustdoc `--cap-lints` 选项；失败退出码规范化（编译失败=1，panic=101）；Clippy 预览可通过 rustup 安装。

## Compatibility Notes
- `str::{slice_unchecked, slice_unchecked_mut}` 弃用，改用 `str::get_unchecked(begin..end)`。
- `std::env::home_dir` 弃用（行为反直觉），建议 crates.io 的 `dirs` crate。
- rustc 不再静默忽略 target spec 中的无效数据；`cfg` 属性与 `--cfg` 参数校验更严格。
