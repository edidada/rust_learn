# Rust 1.52.0（2021-05-06）

> 来源：[releases.rs/docs/1.52.0](https://releases.rs/docs/1.52.0/)；演示：`cargo run -p versions --bin rustc_1_52_0`

## Language
- 新增 `unsafe_op_in_unsafe_fn` lint：检查 `unsafe fn` 内部的 unsafe 代码是否又包了 `unsafe { }` 块。默认 allow，未来 edition 可能升级为警告/硬错误。
- 可变数组引用现在可以 cast 为与元素同类型的指针。

## Compiler
- 默认 LLVM 升级到 LLVM 12。
- 新增 tier 3：`s390x-unknown-linux-musl`、`riscv32gc-unknown-linux-musl` / `riscv64gc-unknown-linux-musl`、`powerpc-unknown-openbsd`。

## Libraries
- `OsString` 实现 `Extend` 与 `FromIterator`。
- `cmp::Reverse` 加 `#[repr(transparent)]`。
- `Arc<impl Error>` 实现 `error::Error`。
- 所有整数除法和取余运算变为 const。

## Stabilised APIs
- `Arguments::as_str` — 当只含一个格式串时取出它
- `char::MAX` / `char::REPLACEMENT_CHARACTER` / `char::UNICODE_VERSION`
- `char::decode_utf16` — 解析 UTF-16 序列（含未配对代理）
- `char::from_digit` / `char::from_u32` / `char::from_u32_unchecked`
- `slice::partition_point` — 二分查找分界点
- `str::rsplit_once` / `str::split_once` — 一次分割成前后两半
- 以下既有 API 变 const：`char::len_utf8/len_utf16/to_ascii_uppercase/to_ascii_lowercase/eq_ignore_ascii_case`、`u8::to_ascii_uppercase/to_ascii_lowercase/eq_ignore_ascii_case`

## Rustdoc
- Rustdoc lint 变为 tool lint，需 `rustdoc::` 前缀（如 `#[warn(rustdoc::broken_intra_doc_links)]`）。旧写法暂允许。
- 支持 argument files；生成 smart punctuation；Markdown 支持 task lists。

## Misc
- 测试可传多个过滤器：`cargo test -- foo bar`。
- Windows 上 rustup 分发 std 的 PDB 符号便于调试。

## Compatibility Notes
- 构建脚本禁止设置 `RUSTC_BOOTSTRAP`。
- 移除 `x86_64-rumprun-netbsd` 目标；弃用 `x86_64-sun-solaris`（改 `x86_64-pc-solaris`）。
- Rustdoc 代码块语言分隔符只认 `,`、空格、`\t`。
- rustc 捕捉更多 `pub_use_of_private_extern_crate` 情形。
- proc-macro 空白处理变化：与旧版 proc-macro-hack 同用可能 panic，`cargo update` 即可修复。
- `#[derive]` 改为普通宏属性。
- 注：本版引入的增量编译校验问题导致 **1.52.1 紧急关闭增量编译**，详见 1.52.1 笔记。
