# Rust 1.71.1（2023-08-03）

> 来源：[releases.rs/docs/1.71.1](https://releases.rs/docs/1.71.1/)；演示：`cargo run -p versions --bin rustc_1_71_1`

Patch 版本，内容很少，全部照实记录。

## Changes
- **修复 CVE-2023-38497**：Cargo 解压依赖时未遵守 umask——本机用户可能篡改影响其他用户构建产物的文件。
- 修复 Rustup 用户的 bash 补全。
- 调用 `borrow()` 时不再显示 `suspicious_double_ref_op` lint。
- 修复两个编译器 ICE（内部错误）：内联兼容性检查前先替换类型；derive(..) 的 missing method 建议中不再使用 can_eq。
- 修复从源码 tarball 构建 Rust 1.71.0。
