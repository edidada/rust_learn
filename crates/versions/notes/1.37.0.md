# Rust 1.37.0（2019-08-15）

> 来源：[releases.rs/docs/1.37.0](https://releases.rs/docs/1.37.0/)；演示：`cargo run -p versions --bin rustc_1_37_0`

## Language
- **`#[must_use]` 用于类型包裹场景**：`#[must_use]` 的类型放进 tuple/Box/array 后未使用也会警告。
- **`cfg`/`cfg_attr` 可用于泛型参数**。
- **类型别名引用枚举变体**：`type MyOption = Option<u8>` 后可写 `MyOption::Some(y)` / `MyOption::None`。
- **`_` 可作为 const 名**：`const _: u32 = 5;`，用于编译期断言等。
- 枚举可用 `#[repr(align(X))]`。
- `?` Kleene 宏重复操作符在 2015 edition 可用。
- **注**：const generics（参数化数组相关）是 **MVP 预告**：1.37 官宣了该方向（含 `[T; N]` 方案设计讨论），但真正的 const generics 稳定要等 1.51 的 `min_const_generics`，本版并无稳定语法。

## Compiler
- `-C profile-generate` / `-C profile-use` 启用 PGO（Profile-Guided Optimization）。
- `rust-lldb` 包装脚本修复。

## Libraries
- `mem::MaybeUninit<T>` 与 `T` ABI 兼容（注释/类型层面修正）。

## Stabilized APIs
- `BufReader::buffer` — 取内部缓冲区内容
- `BufWriter::buffer` — 同上（写入缓冲）
- `Cell::from_mut` — `&mut T` 转 `&Cell<T>`
- `Cell<[T]>::as_slice_of_cells` — `[T]` 切片转 `&[Cell<T>]`
- `DoubleEndedIterator::nth_back` — 从尾部取第 n 项
- `Option::xor` — 两 Option 有且仅有一个 Some 时返回它
- `Wrapping::reverse_bits` — Wrapping 反转位
- `i8/i16/i32/i64/i128/isize::reverse_bits` — 反转位序
- `u8/u16/u32/u64/u128/usize::reverse_bits` — 同上（无符号版）
- `slice::copy_within` — 切片内复制（memcpy 语义）

## Cargo
- 发布可执行 crate 时默认包含 `Cargo.lock`。
- `[package]` 可指定 `default-run = "foo"` 作为 `cargo run` 的默认二进制。

## Compatibility Notes
- 用 `...` 表示闭区间（如 `0...10`）的模式默认改为警告，请用 `..=`。
- trait object 不加 `dyn` 前缀默认改为警告，请写 `dyn Trait`。
