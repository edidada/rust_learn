# Rust 1.49.0（2020-12-31）

> 来源：[releases.rs/docs/1.49.0](https://releases.rs/docs/1.49.0/)；演示：`cargo run -p versions --bin rustc_1_49_0`

## Language
- **union 可以实现 `Drop`，且 union 字段可以是 `ManuallyDrop<T>`**。
- **可以 cast uninhabited 枚举到整数**——空枚举（如 `enum Void {}`）转为整型合法。
- **模式中可按引用和按移动混合绑定**——`ref` 选择性借用个别字段，其余移动：
  ```rust
  let Person { name, ref age } = person; // name 移动，age 借用
  ```

## Compiler
- `aarch64-unknown-linux-gnu` 升为 tier 1。
- 新增 tier 2 目标：`aarch64-apple-darwin`、`aarch64-pc-windows-msvc`。
- 新增 tier 3 目标：`mipsel-unknown-none`。
- 最低支持的 LLVM 版本提升到 LLVM 9。
- 测试中线程的输出现在会被捕获。
- 部分目标的 os/vendor 值改为 "none"/"unknown"（* 平台分层说明见官方 platform support 页）。

## Libraries
- `RangeInclusive` 的 `contains` 与索引现在会检查是否已耗尽（`is_empty` 后继续用会按逻辑正确处理）。
- `ToString::to_string` 默认实现不再收缩内部缓冲。

## Stabilized APIs
- `slice::select_nth_unstable` — 原地把第 n 小元素排到正确位置，返回 `(小于, 恰好, 大于)` 三段
- `slice::select_nth_unstable_by` — 指定比较函数版本
- `slice::select_nth_unstable_by_key` — 按键版本
- 以下既有方法成为 const：
  - `Poll::{is_ready, is_pending}`

## Cargo
- `cargo-package` 打包现在应可独立复现。
- `cargo-tree` 现在标记 proc-macro crate。
- 新增 `CARGO_PRIMARY_PACKAGE` 构建期环境变量：当被构建的 crate 是用户用 `-p` 或默认选择的主包时设置。
- 指定 packages/targets 时可使用 glob 模式。

## Compatibility Notes
- `i686-unknown-freebsd` 从 host tier 2 降为 target tier 2。
- 以分号结尾的宏即使展开为空也按语句对待。
- rustc 现在校验枚举变体上部分内建属性的有效性（此前无效/未用属性可被忽略）。
- 文档注释中的前导空白剥离更统一，可能改变行为（官方有相关文章说明）。
- 关联类型不再推断 trait 约束。

## Internal Only
- rustc 内部 crate 改用 initial-exec 线程局部存储模型。
- resolve 中可见性只计算一次。
- `llvm-libunwind` bootstrap 配置新增 `system` 选项。
- bootstrap 新增 `--color` 配置终端颜色。
