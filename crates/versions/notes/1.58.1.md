# Rust 1.58.1（2022-01-20）

> 来源：[releases.rs/docs/1.58.1](https://releases.rs/docs/1.58.1/)；演示：`cargo run -p versions --bin rustc_1_58_1`

## Patch（此为补丁版本）
- **修复 `std::fs::remove_dir_all` 的竞态条件**（CVE-2022-21658）：符号链接攻击下可能误删非目标目录。
- Clippy：
  - 修 `useless_format` 对捕获参数的处理。
  - `non_send_fields_in_send_ty` 移到 nursery。
- 修 missing import 时的错误信息；修 rustfmt 不格式化 stdin 生成的文件。
