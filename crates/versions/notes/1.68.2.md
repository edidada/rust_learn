# Rust 1.68.2（2023-03-28）

> 来源：[releases.rs/docs/1.68.2](https://releases.rs/docs/1.68.2/)；演示：`cargo run -p versions --bin rustc_1_68_2`

Patch 版本，内容很少，全部照实记录。

## Changes
- **更新 Cargo 内置的 GitHub RSA host key**：GitHub 在 2023-03-24 轮换了该密钥（旧密钥泄露）。
- **把旧的 GitHub RSA host key 标记为 revoked**：即使系统仍然信任泄露的旧密钥，Cargo 也拒绝接受。
- Cargo 的 SSH host key 校验新增对 `@revoked` 的支持，并为 `@cert-authority` 提供更好的错误信息。
