# Rust 1.91.1（2025-11-10）

> 来源：[releases.rs/docs/1.91.1](https://releases.rs/docs/1.91.1/)；演示：`cargo run -p versions --bin rustc_1_91_1`

Patch 版本，仅两处修复：

## Fixes
- **illumos 启用文件锁支持**：修好在 illumos 上 Cargo 不锁 build 目录的问题（`File::lock` 家族的平台实现；1.89 稳定后的平台补齐）。
- **修复 `wasm_import_module` 属性跨 crate 失效**：修 WASM 目标上的链接器报错（cross-crate 场景下该属性信息丢失导致 `--import-memory` 等符号未按声明导入）。
