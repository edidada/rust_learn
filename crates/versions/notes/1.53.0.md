# Rust 1.53.0（2021-06-17）

> 来源：[releases.rs/docs/1.53.0](https://releases.rs/docs/1.53.0/)；演示：`cargo run -p versions --bin rustc_1_53_0`

## Language
- **Unicode 标识符**：标识符可用 Unicode（符合 UAX #31 标准，类似 Python；Rust 用 NFC 规范化）。不允许 ◆、🦀 这类非字符字形。
- **or-patterns（`|` 可用于子模式）**：以前 `|` 只能连整段 pattern，现在能在内部用，如 `matches!(x, Some(1 | 2))`。
- 新增 `:pat_param` `macro_rules!` 匹配器：语义同 `:pat`，为未来 edition 里 `:pat` 改语义做准备。

## Compiler
- 最低外部 LLVM 升至 LLVM 10。
- 新增 tier 3：`wasm64-unknown-unknown`。
- Windows MSVC 上闭包/async 函数的 debuginfo 改进。

## Libraries
- Android 上有 `android_set_abort_message` 时 abort 消息会转发。
- `slice::IterMut<'_, T>` 实现 `AsRef<[T]>`。
- **任意长度数组实现 `IntoIterator`**：`arr.into_iter()` 方法调用当前返回 `impl Iterator<Item = &T>`（未来 edition 可能改成 `Item = T`）；直接 `IntoIterator::into_iter(arr)` 调用则按值返回 `impl Iterator<Item = T>`。
- 所有 `NonZero` 整数类型有 `leading_zeros`/`trailing_zeros`。
- `{f32,f64}::from_str` 按 IEEE 754 解析/输出特殊值（NaN、-0）。
- 可用 `(Bound<usize>, Bound<usize>)` 对切片索引。
- 所有数值类型新增 `BITS` 关联常量（如 `u32::BITS`）。

## Stabilised APIs
- `AtomicBool::fetch_update` / `AtomicPtr::fetch_update` — CAS 循环助手
- `BTreeMap::retain` / `BTreeSet::retain` — 就地按谓词删除
- `BufReader::seek_relative` — 相对 seek（少一次系统调用）
- `DebugStruct::non_exhaustive` — Debug 输出尾部省略号
- `Duration::MAX` / `Duration::ZERO` / `Duration::is_zero` / `Duration::{saturating_add, saturating_mul, saturating_sub}`
- `ErrorKind::Unsupported` — 新错误分类
- `Option::insert` — 就地写入并返回旧值（未占用也不消耗）
- `Ordering::{is_eq, is_ge, is_gt, is_le, is_lt, is_ne}` — Ordering 判等判断
- `OsStr::{is_ascii, make_ascii_lowercase, make_ascii_uppercase, to_ascii_lowercase, to_ascii_uppercase}`
- `Peekable::peek_mut` — 可变窥视
- `Rc::decrement_strong_count` / `Rc::increment_strong_count`
- `Vec::extend_from_within` — 从自身范围扩展
- `array::from_mut` / `array::from_ref` — 从 `&T`/`&mut T` 造 `&[T; 1]`/`&mut [T; 1]`
- `cmp::{max_by_key, max_by, min_by_key, min_by}` — 自定义函数取最值
- `f32::is_subnormal` / `f64::is_subnormal` — 检查次正规数

## Cargo
- 支持默认分支非 master 的 git 仓库；切换到 Cargo.lock v3 格式。
- macOS 目标默认 split-debuginfo（unpacked）。
- 新项目 `Cargo.toml` 不再包含 `authors` 字段。

## Rustdoc
- 新增 `rustdoc::bare_urls` lint：URL 未加超链接时告警。

## Compatibility Notes
- 属性展开改为基于 token 的处理。
- `Ipv4Addr::from_str` 除十六进制外，也不再接受八进制 IP（如 `010.1.1.1`，安全考虑）。
- 新增的 `BITS` 常量可能与外部定义冲突（lexical-core 0.4–0.7 已发修复版）。
- 增量编译依 1.52.1 依旧默认关闭，除非设置 `RUSTC_FORCE_INCREMENTAL=1`。
