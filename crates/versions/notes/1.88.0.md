# Rust 1.88.0（2025-06-26）

> 来源：[releases.rs/docs/1.88.0](https://releases.rs/docs/1.88.0/)；演示：`cargo run -p versions --bin rustc_1_88_0`

## Language
- **稳定 let chains（`#![feature(let_chains)]`，仅 2024 edition）**：`if let … && let …`（也可与布尔表达式混用），let 子表达式里的模式可反驳（refutable）或不可反驳。
- 稳定 `#![feature(naked_functions)]`：`#[naked]` 函数无编译器生成的 prologue/epilogue，可完全控制生成的汇编（面向 asm/底层场景）。
- 稳定 `#![feature(cfg_boolean_literals)]`：`#[cfg(true)]`/`#[cfg(false)]` 布尔字面量作谓词。
- `#[bench]` 彻底去稳定化（无 `custom_test_frameworks` 时是硬错误）。
- 新增 warn-by-default `dangerous_implicit_autorefs` lint（裸指针解引用的隐式自动引用，下版将升 deny）。
- 新增 `invalid_null_arguments` lint（clippy::invalid_null_ptr_usage uplift，防 null 指针误用）。
- 内建 impl 与平凡 where 子句的 trait impl 候选优先级变化；检查泛型 const 参数默认值的类型。

## Compiler
- 稳定 `-Cdwarf-version`（选择生成的 DWARF 调试信息版本）。

## Platform Support
- i686-pc-windows-gnu 降为 tier 2。

## Libraries
- `#[should_panic]` 失败消息去掉反引号；`[T; N]::from_fn` 保证按索引递增顺序调用（对有状态闭包有保证）；libtest `--nocapture` 弃用（改用 `--no-capture`）；保证 `{float}::NAN` 是 quiet NaN。

## Stabilized APIs
- `Cell::update`
- `impl Default for *const T` / `*mut T`
- `HashMap::extract_if` / `HashSet::extract_if`
- `hint::select_unpredictable`
- `proc_macro::Span::line` / `column` / `start` / `end` / `file` / `local_file`
- `<[_]>::as_chunks` / `as_chunks_mut` / `as_chunks_unchecked` / `as_chunks_unchecked_mut` / `as_rchunks` / `as_rchunks_mut`
- `mod ffi::c_str`
- 以下此前已稳定 API 现可用于 const 上下文：`NonNull<T>::replace` / `<*mut T>::replace`、`std::ptr::swap_nonoverlapping`、`Cell::replace` / `get` / `get_mut` / `from_mut` / `as_slice_of_cells`

## Cargo
- 稳定自动垃圾回收（build dir GC）；gzip 压缩改用 zlib-rs。

## Rustdoc
- doctest 可按 target 名用 `ignore-*` 属性忽略；稳定 `--test-runtool`/`--test-runtool-arg`（如 qemu 跑 doctest）。

## Compatibility Notes
- 粘贴 token 内部表示变更完成（部分晦涩声明宏被正确拒绝）。
- `#[bench]` 硬错误（同上）。
- 借用检查修复：部分"总是真"的模式此前被过度允许，现在正确拒绝。
- 最低外部 LLVM 升至 19。
- 非 Rust ABI 的向量类型未启用所需 target feature 时是硬错误。
