# Rust 1.65.0（2022-11-03）

> 来源：[releases.rs/docs/1.65.0](https://releases.rs/docs/1.65.0/)；演示：`cargo run -p versions --bin rustc_1_65_0`

## Language
- **对带 `#[non_exhaustive]` 变体的枚举做 as 转换报错**：防止用 `as` 破坏非穷尽枚举的表示稳定性。
- **let-else 稳定化**：`let PAT = EXPR else { ... }`，模式不匹配时执行 `else` 块（必须发散：`return`/`break`/`continue`/`panic!` 等），大幅减少嵌套 `match`/`if let`。
- **GATs（泛型关联类型）稳定化**：允许关联类型带自己的泛型参数/生命周期，如 `type Item<'a>;`，可写 lending iterator 等模式。
- **从 Clippy 引入 lint：`let_underscore_drop`、`let_underscore_lock`**：对有 `Drop` 的值/锁用 `let _ =` 忽略时警告。
- **label-break-value 稳定化**：可从任意带标签的块中 break 出去：`'a: { ... break 'a; ... }`。
- **未初始化的整数、浮点、裸指针视为 immediate UB**：正确方式是使用 `MaybeUninit`。
- **raw-dylib 稳定化**（Windows x86_64 / aarch64 / thumbv7a）：链接时无需导入库文件。
- **禁止对外部 ADT（foreign ADT）实现 Drop**。

## Compiler
- **Linux 上 `-Csplit-debuginfo` 稳定**。
- 使用 niche-filling 优化即使多个变体有数据。
- 关联类型投影在解析底层类型前先验证 well-formed。
- 非 shorthand 可见性正确 stringify；unsizing 时规范化结构体字段类型。
- 更新到 LLVM 15；aarch64 调用 ABI 正确 zeroext。
- debuginfo：枚举用类 C++ 编码泛化。
- 新增 `special_module_name` lint；coverage 默认生成唯一 profraw；允许 iOS/tvOS 动态链接。
- 新 tier 3 目标：`armv4t-none-eabi`、`powerpc64-unknown-openbsd`、`riscv64-unknown-openbsd`。

## Libraries
- `derive(PartialEq)` 不再生成 `PartialEq::ne`。
- Windows RNG 默认用 `BCRYPT_RNG_ALG_HANDLE`；禁止把 `System` 与直接系统分配器混用。
- 文档注明不支持写非阻塞 stdio/stderr。
- `Layout` 的大小向上取整对齐后不得溢出 `isize::MAX`（同时修改 `Layout::from_size_align_unchecked` 安全条件）。

## Stabilized APIs
- `std::backtrace::Backtrace` — 捕获栈回溯的稳定类型。
- `Bound::as_ref` — `Bound<&T>`/`Bound<&mut T>` 到 `Bound<&T>` 的引用转换。
- `std::io::read_to_string` — 稳定版的"把 Reader 读成 String"自由函数。
- `<*const T>::cast_mut` — `*const T` 转 `*mut T`。
- `<*mut T>::cast_const` — `*mut T` 转 `*const T`。
- 以下 API 现在可在 const 上下文使用：`<*const T>::offset_from`、`< *mut T>::offset_from`。

## Cargo
- 对部分哈希也应用 GitHub fast path。
- home bin 路径已在 PATH 中则不重复添加。
- pending 队列考虑优先级，优化大 crate 图构建的调度。

## Compatibility Notes
- `Layout` 大小向上对齐后不得溢出 `isize::MAX`（改 `from_size_align_unchecked` 安全条件）。
- `PollFn` 仅当闭包 `Unpin` 时才实现 `Unpin`（不再 blanket 实现）。
- `std::char::EscapeAscii` 移除 `ExactSizeIterator` 实现。
- 单个重复生命周期不再参与返回类型省略（撤销 1.64.0 的意外改动）。
- 重新启用早期语法门为 future-incompatibility lint。
- 最低外部 LLVM 更新到 13。
- 不再把文件描述符复制到 stdio fds；RLS 退役。
- `#![cfg_attr(..., crate_type = ...)]` 被 deny（`deprecated_cfg_attr_crate_type_name` 强化）。
- `llvm-has-rust-patches` 选项；三种以上语言（如 ObjC+C+++Rust）合并为单二进制时用 lld 可能撞链接器限制（#102754）。

## Internal Changes
- 新增 `x.sh`/`x.ps1` 构建脚本；compiletest 用 target cfg；用 object 库读 rlib bitcode；启用 MIR inlining（优化编译提速 3–10%）。
