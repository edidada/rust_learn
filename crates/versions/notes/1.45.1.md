# Rust 1.45.1（2020-07-30）

> 来源：[releases.rs/docs/1.45.1](https://releases.rs/docs/1.45.1/)；演示：无（patch 版仅 bugfix，不配演示）

## 说明
patch 版本，无语言/库稳定化内容，仅以下修复项。

## Patch Fixes
- 修复带引用的常量传播（const propagation with references）。
- rustfmt 再次接受 `cfg_attr` 中的 `rustfmt_skip`。
- 避免虚假的隐式 region bound。
- `x.py install` 时安装 clippy。

## 演示对照
patch 版无新增稳定 API，不提供演示。
