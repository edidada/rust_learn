# Rust 1.28.0（2018-08-02）

> 来源：[releases.rs/docs/1.28.0](https://releases.rs/docs/1.28.0/)；演示：`cargo run -p versions --bin rustc_1_28_0`

## Language
- **`#[repr(transparent)]` 稳定**：newtype 包装（`struct NewType<T>(T);`）在 FFI 边界保持与内部类型相同表示。
- 关键字 `pure`、`sizeof`、`alignof`、`offsetof` 解除保留，可用作标识符。
- **全局分配器 `GlobalAlloc` trait 与 `#[global_allocator]` 属性稳定**：可指定整个程序使用的分配器。
- `#[test]` 函数可返回 `Result<(), E: Debug>`。
- `macro_rules!` 的生命周期捕获稳定。

## Compiler
- 优化等级 `s`/`z` 稳定（面向小体积；`z` 不向量化循环，通常更小）。
- `--error-format=short` 稳定；重复 `macro_export` 警告；宏解析器分配减少（平均提速 5%）。

## Libraries
- `&mut str` 实现 `Default`；所有整型实现 `From<bool>`；`()` 实现 `Extend`。
- `time::Duration` 的 Debug 改为人读格式（`1s`，以前是 `Duration { secs: 1, nanos: 0 }`）。
- 一大批 `From` 实现（`Cow<str>`、`Cow<[T]>`、`Cow<CStr>` 等）；`Wrapping<u128/i128>` 实现 `Shl/Shr`。
- `DirEntry::metadata` 用 fstatat 替代 lstat，最多提速 40%。

## Stabilized APIs
- `Iterator::step_by`、`Path::ancestors`
- **`SystemTime::UNIX_EPOCH`**
- 全局分配器族：`alloc::GlobalAlloc`、`alloc::Layout`、`alloc::LayoutErr`、`alloc::System`、`alloc::alloc`、`alloc::alloc_zeroed`、`alloc::dealloc`、`alloc::realloc`、`alloc::handle_alloc_error`
- `btree_map::Entry::or_default`、`hash_map::Entry::or_default`
- `fmt::Alignment`、`iter::repeat_with`
- `num::NonZeroU8/U16/U32/U64/U128/Usiz`（页面上 Usiz 为 Usize）
- `ops::RangeBounds`、`slice::SliceIndex`、`slice::from_mut`、`slice::from_ref`
- `{Any + Send + Sync}::downcast_mut/downcast_ref/is`

## Cargo
- 禁止发布会修改 `src` 目录的 build-script crate（src 视为不可变）。

## Misc
- rustc JSON 输出的 `suggestion_applicability` 字段稳定。

## Compatibility Notes
- trait object 的重复约束（`Trait + Send` 与 `Trait + Send + Send`）视为同类型，重复实现会编译失败。
