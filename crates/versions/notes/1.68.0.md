# Rust 1.68.0（2023-03-09）

> 来源：[releases.rs/docs/1.68.0](https://releases.rs/docs/1.68.0/)；演示：`cargo run -p versions --bin rustc_1_68_0`

## Language
- **default_alloc_error_handler 稳定化**：stable 上可直接使用 `alloc`，不再要求自定义分配失败 handler（自定义 handler 仍是 unstable）。
- **`efiapi` 调用约定稳定化**：UEFI ABI。
- 移除带 drop glue 类型的隐式 promotion。

## Compiler
- `bindings_with_variant_name` 变为默认 deny。
- 允许 `..` 作为 let 初始化式解析。
- 新 tier 3 目标：`armv7-sony-vita-newlibeabihf`。
- 编译期 const 求值始终检查对齐；默认禁用 split dwarf inlining；Fuchsia target triple 加 vendor；s390x-linux 启用 sanitizer。

## Libraries
- `Weak` 的 `Debug` 实现放宽 bound。
- `std::task::Context` 改为 `!Send`、`!Sync`。
- `PhantomData` 布局保证。
- `OnceWith`/`RepeatWith` 不再 derive `Debug`。
- `PathBuf` 实现 `DerefMut`。
- **`Vec` -> `VecDeque` 转换获得 O(1) 保证**。
- `peek_mut()` 的 leak amplification：确保 BinaryHeap 不变量始终成立。

## Stabilized APIs
- `{core,std}::pin::pin!` — 栈上固定（pin）一个值，免手动 `Pin::new_unchecked`。
- `impl From<bool> for {f32,f64}` — `1.0f64 * (true as f64)` 之外的新途径。
- `std::path::MAIN_SEPARATOR_STR` — 主路径分隔符的字符串常量（配合 Windows 多字符路径前缀等场景）。
- `impl DerefMut for PathBuf`。
- 以下 API 现在可在 const 上下文使用：`VecDeque::new`。

## Cargo
- **crates.io sparse（稀疏）registry 支持稳定化**：`cargo` 可用 `registry.crates-io protocol = "sparse"`，索引更新大幅提速（1.70 起默认 sparse）。
- `cargo build --verbose` 输出更多重编译原因。
- 即使启用 net.git-fetch-with-cli 也显示 crates.io 索引更新进度。

## Compatibility Notes
- 仅支持 Android NDK 25 及更新版本。
- `SEMICOLON_IN_EXPRESSIONS_FROM_MACROS` 加入 future-incompat 报告。
- 仅在 wasm 上默认为 `-Zgcc-ld=lld` 传 `--target`。
- `IMPLIED_BOUNDS_ENTAILMENT` 提升为 Deny + Report。
- `std::task::Context` 不再实现 `Send`/`Sync`。

## Internal Changes
- span 相对所在 item 编码；AstConv 不再 normalize；ThinLTO 用于 windows-msvc 与 apple-darwin 的 rustc 构建等。
