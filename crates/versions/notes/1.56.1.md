# Rust 1.56.1（2021-11-01）

> 来源：[releases.rs/docs/1.56.1](https://releases.rs/docs/1.56.1/)；演示：`cargo run -p versions --bin rustc_1_56_1`

## Changes（此为补丁版本）
- 新增一批 lint 以检测编译源码中是否出现**双向覆盖类 Unicode 码点**（CVE-2021-42574，"Trojan Source"）：
  - 例如 U+202E（RTL override）、U+202A-D、U+2066-9 等可在源代码显示层面隐藏真实控制流的可疑字符，编译期会告警，防范通过视觉欺骗植入恶意代码。
  - 官方同时给出了处理方式（如报错/用 `cargo fix` 之外的转义形式）。
