# Rust 1.33.0（2019-02-28）

> 来源：[releases.rs/docs/1.33.0](https://releases.rs/docs/1.33.0/)；演示：`cargo run -p versions --bin rustc_1_33_0`

## Language
- `cfg(target_vendor)` 条件可用，如 `#[cfg(target_vendor="apple")]`。
- **整数模式可穷尽**：`u8` 上匹配 `0..=255` 全覆盖后不再需要 `_ => unreachable!()`。
- **`if let`/`while let` 支持多模式（`|`）**；也允许不可反驳（irrefutable）模式（默认告警）。
- const fn 中可用 `let` 绑定、赋值、表达式语句、不可反驳解构；可调用 unsafe const fn。
- `#[cfg_attr(all(), must_use, optimize)]` 可一次给多个属性。
- **`#[repr(packed(N))]`**：指定最小对齐，如 `#[repr(packed(2))] struct Foo(i16, i32);`。
- `use ... as _`：只导入 trait 的 impl 而不占用命名空间。
- `Rc`、`Arc`、`Pin` 可作方法接收者（method receiver）。

## Compiler
- `-Clinker-flavor`；最低 LLVM 6.0；PowerPC64 FreeBSD；SGX 目标升 tier 2；`x86_64-unknown-uefi`；thumbv7neon 目标。

## Libraries
- 大批算术方法 const fn 化：`overflowing_{add,sub,mul,shl,shr,neg}`、`rotate_left/right`、`wrapping_*`、`count_ones` 等；`NonZero*::get` const；`Ipv4Addr::new` const。

## Stabilized APIs
- `unix::FileExt::read_exact_at`、`unix::FileExt::write_all_at`
- `Option::transpose`、`Result::transpose`
- `convert::identity`、`pin::Pin`、`marker::Unpin`、`marker::PhantomPinned`
- `Vec::resize_with`、`VecDeque::resize_with`
- `Duration::as_millis`、`Duration::as_micros`、`Duration::as_nanos`

## Cargo
- `cargo publish --features`/`--all-features`；初建期间修改过的文件会触发重建。

## Compatibility Notes
- `str::{trim_left,trim_right,trim_left_matches,trim_right_matches}` 弃用 → 改用 `trim_start`/`trim_end` 族。
- `Error::cause` 弃用，改用支持向下转型的 `Error::source`。
- libtest 在 `--test-threads=1` 时不再为每个测试开新线程，且顺序确定。
