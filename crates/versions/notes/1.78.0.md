# Rust 1.78.0（2024-05-02）

> 来源：[releases.rs/docs/1.78.0](https://releases.rs/docs/1.78.0/)；演示：`cargo run -p versions --bin rustc_1_78_0`

## Language
- **稳定 `#[cfg(target_abi = ...)]`**：可按目标 ABI（如 `eabihf`、`softfloat`、`llvm`）做条件编译。
- **稳定 `#[diagnostic]` 命名空间与 `#[diagnostic::on_unimplemented]`**：为 trait 自定义"未实现"错误提示，编译器不认识的 `#[diagnostic::…]` 属性只会警告而不会报错（该命名空间向前兼容）。
- **async fn in trait 支持具体签名实现**：trait 里的 `async fn` / RPITIT 方法现在可以在 impl 中给出具体（手动 desugar）签名实现，为 AFIT 更广可用性铺路。
- **对 NaN 做匹配改为硬错误**：移除其余非法浮点字面量模式（`illegal_floating_point_literal_pattern`），浮点模式只能用通配符Binding兜底。
- **`static mut` 允许取任意类型的可变引用**：不限于 slice/array（注意：仍是 unsafe 且被后续 `static_mut_refs` lint 盯上）。
- **`invalid_reference_casting` 扩大**：引用转型到更大内存布局也纳入该 UB 检查。
- 新 lint：`non_contiguous_range_endpoints`（排他区间后的单点空洞）、`wasm_c_abi`（旧 wasm-bindgen ABI，仅 Cargo 下生效）。
- 更新 `indirect_structural_match` / `pointer_structural_match` 到 RFC 语义；非 `PartialEq` 类型 const 作模式改为硬错误。
- `refining_impl_trait` lint 拆分为 `_reachable` 与 `_internal` 变体。
- trait 上界自动 trait 上转型：`dyn Trait` → `dyn Trait + Auto`（trait object upcasting 第一阶段，从 dyn 上抹掉不能再加回？不——是允许上转型加 auto trait）。

## Compiler
- `INVALID_DOC_ATTRIBUTES` 默认 deny。
- Windows tier 1 目标至少要求 Windows 10（启用 CMPXCHG16B、SSE3 等）。
- 新 tier 3 目标：wasm32-wasip2、arm64ec-pc-windows-msvc、armv8r-none-eabihf、loongarch64-unknown-linux-musl 等；wasm32-wasip1 为 tier 2。

## Libraries
- Unicode 升级到 15.1.0；`align_offset`/`align_to` 全场景良定义；pthread RwLock 换自实现；`Condvar` 全平台 unwind 安全。

## Stabilized APIs
- `impl Read for &Stdin`
- 多个 `std::error::Error` 相关实现接受非 `'static` 生命周期
- `impl<Fd: AsFd> ...` 接受 `?Sized`
- `impl From<TryReserveError> for io::Error`
- 以下可用于 const 上下文：`Barrier::new()`

## Cargo
- 稳定 lockfile v4；生成 lockfile 时尊重 `rust-version`；`charset` 自动检测；正式支持 `target.<triple>.rustdocflags`；稳定全局缓存数据跟踪。

## Compatibility Notes
- 开 debug assertions 时，许多 unsafe 前置条件检查也会作用于用户代码（帮助捕获 UB，检查范围不稳定）。
- riscv 暂只支持 `split_debuginfo=off`。
- 对被隐藏的 impl Trait 具体类型一致地检查边界；higher-ranked 类型的相等判断不再依赖子类型；调用时额外检查归一化后返回类型边界。
- 扩大 `arithmetic_overflow` lint 覆盖面；修复 const 初始化器中内部可变性检测（此前意外接受的代码可能开始报错）。

## Internal Changes
- LLVM 18；Windows 使用 futex 实现 condvar/mutex/rwlock；run-make V2 基础设施。
