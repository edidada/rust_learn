# Rust 1.69.0（2023-04-20）

> 来源：[releases.rs/docs/1.69.0](https://releases.rs/docs/1.69.0/)；演示：`cargo run -p versions --bin rustc_1_69_0`

## Language
- packed 结构体 derive 内建 trait 现在支持 Copy 字段。
- x86/x86_64 上稳定 `cmpxchg16b` target feature。
- 改进关联类型 trait bound 的分析。
- **允许关联类型用作 union 字段**。
- **允许 `Self: Autotrait` bound 出现在 dyn-safe trait 方法上**（如 `Self: Send` 不再破坏 dyn 兼容）。
- 为 auto trait 目的把 `str` 视为包含 `[u8]`。

## Compiler
- CI 上 `*-pc-windows-gnu` 升级 mingw-w64 v10 与 GCC 12.2。
- member constraints 的 min_choice 算法重做。
- 编译器参数支持 `true`/`false` 布尔旗标。
- **`repr(C)` 枚举默认使用 `c_int` 大小**。

## Libraries
- 为 cell 类型实现 unstable `DispatchFromDyn`（供下游试验自定义方法接收者）。
- 文档注明 `fmt::Arguments::as_str()` 优化后可能返回 `Some(_)`。
- **为 `Rc` 实现 `AsFd`/`AsRawFd`**。

## Stabilized APIs
- `CStr::from_bytes_until_nul` — 从以 NUL 结尾的字节切片构造 `&CStr`，无 NUL 时报错。
- `core::ffi::FromBytesUntilNulError` — 上述错误类型。
- 以下 API 现在可在 const 上下文使用：`SocketAddr::new`、`SocketAddr::ip`、`SocketAddr::port`、`SocketAddr::is_ipv4`、`SocketAddr::is_ipv6`、`SocketAddrV4::{new,ip,port}`、`SocketAddrV6::{new,ip,port,flowinfo,scope_id}`。

## Cargo
- 编译警告可自动修复时建议 `cargo fix` 或 `cargo clippy --fix`。
- 尝试安装库 crate 时建议 `cargo add`。
- 对 binary examples 也设置 `CARGO_BIN_NAME` 环境变量。

## Rustdoc
- trait bound 竖向紧凑排版；`rustdoc::all` 组只包含稳定 lint；基于查询计算最大 Levenshtein 距离；移除不一致的侧边栏 tooltip；以 `!` 结尾的查询按宏搜索。

## Compatibility Notes
- rustup 的 rust-analysis 组件只含警告占位（RLS 遗产），编译器移除 `-Zsave-analysis`。
- **对 packed 字段的非对齐引用成为硬错误**（1.53 警告、1.62 默认 deny 转正）。
- 最低外部 LLVM 更新到 14。
- Cargo 对 registry token 中的非法字符报错。
- workspace 依赖 default-features=false 与成员继承 default-features=true 组合时启用默认 feature。
- Cargo 拒绝在 `[env]` 配置表中设置 `CARGO_HOME`。
- 构建依赖默认关闭 debuginfo（加快构建）。
- 若 bootstrap.toml 的 tools 列表中没有 rustdoc，则分发包不再总包含 rustdoc（默认仍包含）。

## Internal Changes
- `format_args!()` 移入 AST（AST lowering 期间展开）。
