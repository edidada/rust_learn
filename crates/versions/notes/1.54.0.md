# Rust 1.54.0（2021-07-29）

> 来源：[releases.rs/docs/1.54.0](https://releases.rs/docs/1.54.0/)；演示：`cargo run -p versions --bin rustc_1_54_0`

## Language
- **内置属性中可用宏取值**：主要是可在 `#[doc]` 里调用宏。例如把外部 README 作为 crate 文档：`#![doc = include_str!("README.md")]`。
- const fn 中可以对 unsized slice 类型（及含 unsized slice 的类型）做 cast。
- `impl Trait<'a, 'b>` 可使用多个互不显式 outlive 的生命周期（之前要求 `'b: 'a`）。

## Compiler
- rustc 在 `/lib/rustlib/<target-triple>/target.json`（sysroot 下）搜索自定义 JSON 目标。
- WebAssembly 平台把 `wasm` 作为 `target_family`；`#[target_feature]` 可用于 wasm 平台的 safe 函数。
- Windows MSVC 枚举调试输出改进。
- 新增 tier 3：`bpfel-unknown-none`、`bpfeb-unknown-none`。
- LLVM 12 及以上默认启用 `-Zmutable-noalias=yes`。

## Libraries
- `panic::panic_any` 加 `#[track_caller]`。
- `io::ErrorKind` 新增 `OutOfMemory` 变体。
- `proc_macro::Literal` 实现 `FromStr`。
- `core::arch` 厂商 intrinsics 大重构：libcore.rlib 体积减 50%，intrinsics 常量操作数校验更严（技术上 breaking）。

## Stabilized APIs
- `BTreeMap::into_keys` / `BTreeMap::into_values` — 消费 map 得 keys/values 迭代器
- `HashMap::into_keys` / `HashMap::into_values`
- `core::arch::wasm32` — wasm32 内建函数稳定
- `VecDeque::binary_search` / `binary_search_by` / `binary_search_by_key` / `partition_point`

## Cargo
- `cargo tree` 新增 `--prune <spec>`（从依赖图删掉包）、`--depth`、`--edges no-proc-macro`。
- 新环境变量 `CARGO_TARGET_TMPDIR`：integration tests / benches 可用的临时目录。

## Compatibility Notes
- 闭包中不再允许通过 `?` 混用 `Option` 与 `Result`（推断类型时）。
- 不同分支的构造器要求不同生命周期时的 unsound 代码不再允许。
- `core::arch` intrinsics 常量检查更严格（如上）。
- Cortex M0+ 平台 `codegen-units = 1` 时 i128 乘法无条件溢出。
