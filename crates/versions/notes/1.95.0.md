# Rust 1.95.0（2026-04-16）

> 来源：[releases.rs/docs/1.95.0](https://releases.rs/docs/1.95.0/)；演示：`cargo run -p versions --bin rustc_1_95_0`

## Language
- **match 臂的 `if let` guard 稳定**（可写 `if let PAT = expr` 守卫）。
- `irrefutable_let_patterns` 不再对 let chains 触发。
- 支持以重命名方式导入路径段关键字（如 `use foo::crate as crate_` 类）。
- PowerPC / PowerPC64 inline assembly 稳定。
- const-eval：typed copy 的 padding 行为一致化；const block 不再参与 fallible 操作的隐式常量提升。
- 模式匹配的运算语义与 crate/module 无关（跨 crate 一致化）。

## Compiler / Platform Support
- `--remap-path-scope` 稳定（控制二进制产物中路径重映射的作用范围）。
- 内嵌 musl 打 CVE-2026-6042 / CVE-2026-40200 补丁。
- `powerpc64-unknown-linux-musl` 升 Tier 2（host tools）；tvOS/watchOS/visionOS 系列目标升 Tier 2。

## Libraries
- `thread::scope` 文档说明 join 与 TLS 析构的相互作用；aarch64+neon 下 `str::contains` 提速。

## Stabilized APIs（多，全列）
- `MaybeUninit<[T; N]>` 的 5 个转换 impl：`From<[MaybeUninit<T>; N]>`、`AsRef<[MaybeUninit<T>; N]>`、`AsRef<[MaybeUninit<T>]>`、`AsMut`（同名 2 个）
- `[MaybeUninit<T>; N]: From<MaybeUninit<[T; N]>>`
- `Cell<[T; N]>: AsRef<[Cell<T>; N]> / AsRef<[Cell<T>]>`；`Cell<[T]>: AsRef<[Cell<T>]>`
- `bool: TryFrom<{integer}>`
- **`AtomicPtr/AtomicBool/AtomicI*/AtomicU*::update` 与 `try_update`**（`AtomicIn`/`AtomicUn` 为页面列出写法，即整型原子族）
- `cfg_select!`
- 模块 `core::range`：`core::range::RangeInclusive`、`core::range::RangeInclusiveIter`
- `core::hint::cold_path`
- `<*const T>::as_ref_unchecked`、`<*mut T>::as_ref_unchecked`、`<*mut T>::as_mut_unchecked`
- `Vec::{push_mut, insert_mut}`、`VecDeque::{push_front_mut, push_back_mut, insert_mut}`、`LinkedList::{push_front_mut, push_back_mut}`
- `Layout::dangling_ptr`、`Layout::repeat`、`Layout::repeat_packed`、`Layout::extend_packed`
- const 化（此前已稳定）：`fmt::from_fn`、`ControlFlow::{is_break, is_continue}`

## Rustdoc
- 搜索结果中 unstable items 排序降低；新增"hide deprecated items"设置。

## Compatibility Notes（多，全列）
- 数组强转的推断约束可能变少；`use $crate::{self};`（不移名）不再允许。
- const-eval：typed copy 的 padding 行为一致化（极少数情况报编译错：指针字节落入 const/static 的 padding）。
- future-compat lint `ambiguous_glob_imported_traits` 启用。
- 只提及类型参数的类型检查其生命周期 bound。
- 更多可见性相关的歧义导入报错。
- 弃用 `Eq::assert_receiver_is_total_eq`，对手工 impl 发 future-compat 警告。
- powerpc64 改用 target spec 的 ELF ABI 版本（修 OpenBSD 目标 ABI）。
- `#[non_exhaustive]` 枚举即使单变体也读 discriminant（可能改变闭包捕获）。
- unstable Match Ergonomics 2024 的 `mut ref` / `mut ref mut` 模式在 struct 字段简写处误上稳定，现按 unstable 正确门控。
- 与内建属性冲突的 derive 辅助属性发 future-compat 警告。
- **JSON target specs 已不稳定化**，需 `-Z unstable-options`（Cargo 加 `-Z json-target-spec` 自动传递，见 #150151 等）。
- 无效目标上 `#[feature]` 属性的参数会被检查。

## Internal
- LLVM 升至 22。
