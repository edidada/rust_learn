# Rust 1.90.0（2025-09-18）

> 来源：[releases.rs/docs/1.90.0](https://releases.rs/docs/1.90.0/)；演示：`cargo run -p versions --bin rustc_1_90_0`

## Language
- **允许常量最终值引用可变/外部内存，但拒绝其用作模式**：const 里可以形成此类引用，却不能拿去当 pattern。
- **允许 volatile 访问非 Rust 内存**（包括地址 0）。
- `unknown_or_malformed_diagnostic_attributes` lint 拆分为 4 个更细的 lint 组：`unknown_diagnostic_attributes`、`misplaced_diagnostic_attributes`、`malformed_diagnostic_attributes`、`malformed_diagnostic_format_literals`。

## Compiler
- **x86_64-unknown-linux-gnu 默认使用 lld 链接**。
- Tier 3 musl 目标默认动态链接（mips64/powerpc/riscv32gc/s390x/thumbv7neon 等）。

## Platform Support
- **x86_64-apple-darwin 降级为 Tier 2（with host tools）**。

## Libraries
- 稳定 `u*::{checked,overflowing,saturating,wrapping}_sub_signed`。
- 允许 `CStr` / `CString` / `Cow<CStr>` 之间互相比较。
- 移除不可构造的 unsized tuple impl；`UnixStream` 设置 `MSG_NOSIGNAL`。
- `proc_macro::Ident::new` 支持 `$crate`；`Thread::into_raw` 返回指针保证至少 8 字节对齐。

## Stabilized APIs
- `u{n}::checked_sub_signed` / `overflowing_sub_signed` / `saturating_sub_signed` / `wrapping_sub_signed`
- `impl Copy for IntErrorKind` / `impl Hash for IntErrorKind`
- CStr/CString/Cow\<CStr\> 间 9 个 `PartialEq`（`CStr==&CStr`、`CStr==CString`、`Cow<CStr>` 三个方向各一组）
- 以下此前已稳定 API 现在可用于 const 上下文：`<[T]>::reverse`、`f32::{floor,ceil,trunc,fract,round,round_ties_even}`、`f64::{floor,ceil,trunc,fract,round,round_ties_even}`

## Cargo
- 新增 `http.proxy-cainfo` 代理证书配置。
- `cargo package`/`publish` 改用 gix 实现。
- **稳定多包发布**（一次 `cargo publish` 发布 workspace 多个包）。

## Rustdoc
- Summary 按钮 / `-` 快捷键按住 shift 时可折叠 all impl 块。
- unsafe 属性显示为 `unsafe(...)` 包装形态。

## Compatibility Notes
- x86_64-unknown-linux-gnu 默认 lld（见官方博客 2025-09-01《rust-lld on 1.90.0 stable》）。
- `core::iter::Fuse` 的 `Default` 按文档承诺构造 `I::default()`，而不是恒空。
- `UnixStream` 设置 `MSG_NOSIGNAL`：依赖 SIGPIPE 终止的程序需改为按写错误退出。
- Unix 上 `std::env::home_dir` 在 `HOME` 为空时改用 fallback。
- 一致性地在不支持平台拒绝 `extern "{abi}"`（含函数指针上的 trait 实现场景）。
- const-eval：初始化静态项时写入该 static 本身 → 报错。
- `#[proc_macro_derive]` 用到 crate 根时校验参数。
