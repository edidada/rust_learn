# Rust 1.19.0（2017-07-20）

> 来源：[releases.rs/docs/1.19.0](https://releases.rs/docs/1.19.0/)；演示：`cargo run -p versions --bin rustc_1_19_0`

## Language
- **元组结构体可用数字字段构造**（RFC 1506）：`struct Point(u32, u32); let x = Point { 0: 7, 1: 0 };`。
- 宏递归上限从 64 提到 1024；新增未用宏 lint。
- **`loop` 可用 `break` 返回值**（RFC 1624）：`let x = loop { break 7; };`。
- **C 兼容 `union`**（RFC 1444）：只能含 Copy 类型、不能实现 Drop。
- **不捕获变量的闭包可强转为 `fn` 指针**（RFC 1558）：`let f: fn(u8) -> u8 = |v| v + 1;`。

## Compiler
- Android 上自举编译器；arm-linux-androideabi 对齐官方 armeabi ABI；`-C target-feature=+crt-static`（RFC 1721，CRT 静态链接）；VS 2017 支持；LLVM 4.0.1。

## Libraries
- `String` 实现 FromIterator/Extend\<Cow<str>>；`Vec` 实现 From<&mut [T]>；`Box<[u8]>` 实现 From<Box<str>>；SplitWhitespace 实现 Clone；[u8]::reverse 快 5 倍。
- **`eprint!`/`eprintln!` 加入 prelude**（输出到 stderr 的 print 系宏）。

## Stabilized APIs
- `OsString::shrink_to_fit`
- `cmp::Reverse`（反转排序顺序的新类型）
- `Command::envs`（批量设置子进程环境变量）
- `thread::ThreadId`（线程唯一标识）

## Cargo
- 构建脚本可 `cargo:rustc-env=FOO=bar` 注入环境变量；子命令替换当前进程；工作区成员支持 glob；`cargo bench --all`；`--exclude`；`--features` 接受逗号/空格分隔多值；crates.io 5xx 自动重试；注册表不再本地 checkout。

## Misc
- rust-windbg.cmd（WinDbg 加载 .natvis）；发布包改 XZ 压缩；文档可转义 `#`（写成 `##`）。

## Compatibility Notes
- `MutexGuard<T>` 仅当 `T: Sync` 才 `Sync`。
- **`-Z` flag 在 stable 编译器禁用**（此前已警告一年）；cargo-check 插件失效（用内置 `cargo check`）。
- 浮点字面量 `42._` 成硬错误；私有 extern crate 的模块外使用成硬错误；`use ::self::foo;` 成硬错误；浮点常量与未 derive PartialEq/Eq 的常量入 match 成硬错误；`'_` 生命周期禁用；私有 enum 变体不可 re-export。
