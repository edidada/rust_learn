# Rust 1.89.0（2025-08-07）

> 来源：[releases.rs/docs/1.89.0](https://releases.rs/docs/1.89.0/)；演示：`cargo run -p versions --bin rustc_1_89_0`

## Language
- **`mismatched_lifetime_syntaxes` lint（warn-by-default，新）**：当同一个生命周期在函数参数与返回值间使用了不同的语法类别（省略 `'_` / 显式命名）时告警，可读性差、在 unsafe 代码中尤其易误导；取代旧的 `elided_named_lifetimes` lint。
- **稳定显式推断 const 泛型参数（`generic_arg_infer`）**：数组长度的 const 参数可写 `_` 推断，如 `Self::LEN` / `[T; _]`。
- `#[repr(u128)]` / `#[repr(i128)]` 稳定（repr128）。
- `unpredictable_function_pointer_comparisons` lint 扩展到外部宏里的函数指针比较；`dangerous_implicit_autorefs` 升级为 deny。
- 临时生命周期延长now 也穿过元组结构体/元组变体构造函数（如 `&Foo(…).0`）。
- avx512、kl/widekl、sha512/sm3/sm4、LoongArch（f/d/lasx/lbt/lsx/lvzf 等）target feature 稳定。
- wasm32-unknown-unknown 上的 `extern "C"` 函数改为标准兼容 ABI。

## Libraries
- 指定 `file!` 的基础路径；允许把 `format_args!()` 存进变量。
- `LazyCell`/`LazyLock` 实现 `DerefMut`；`array::IntoIter` 实现 `Default`；`slice::ChunkBy` 实现 `Clone`；`io::Take` 实现 `io::Seek`；`[T; N]::map` 加 `#[must_use]`。

## Stabilized APIs
- `NonZero<char>`
- `File::lock` / `File::lock_shared` / `File::try_lock` / `File::try_lock_shared` / `File::unlock`
- `NonNull::from_ref` / `NonNull::from_mut` / `NonNull::without_provenance` / `NonNull::with_exposed_provenance` / `NonNull::expose_provenance`
- `OsString::leak` / `PathBuf::leak`
- `Result::flatten`
- `std::os::linux::net::TcpStreamExt::quickack` / `set_quickack`
- x86 AVX512、SHA512、SM3、SM4 等 intrinsics（不逐个枚举）
- 以下此前已稳定 API 现在可用于 const 上下文：`<[T; N]>::as_mut_slice`、`<[u8]>::eq_ignore_ascii_case`、`str::eq_ignore_ascii_case`

## Cargo
- `--fix` 与 `cargo clippy --fix` 改为与其他构建命令相同的默认目标选择（不再波及所有 target）；`--edition` 仍作用于全部 target。
- 稳定 doctest 交叉编译（doctest-xcompile），可用 `ignore` 属性按 target 忽略。

## Rustdoc
- 移动端侧栏全宽 + 自动换行。

## Compatibility Notes
- `missing_fragment_specifier` 变为无条件错误。
- Sized Hierarchy Part I：递归类型含关联类型投影 + `?Sized` impl 的极少数情况会有小幅破坏性变化。
- `elided_named_lifetimes` 被 `mismatched_lifetime_syntaxes` 取代。
- 递归 opaque 类型更早在类型检查期报错；数组重复表达式元素类型 Copy 要求的推断副作用推迟。
- 弃用的 `std::intrinsics::{copy, copy_nonoverlapping, write_bytes}` 移除 debug 断言、成为真正的 intrinsic；删除 `std::intrinsics::drop_in_place`。
- 非 x86-32 目标上 lint `stdcall`/`fastcall`/`cdecl` ABI。
- wasm32-unknown-unknown `extern "C"` ABI 变化（同上）。
