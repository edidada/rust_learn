# Rust 1.63.0（2022-08-11）

> 来源：[releases.rs/docs/1.63.0](https://releases.rs/docs/1.63.0/)；演示：`cargo run -p versions --bin rustc_1_63_0`

## Language
- 移除 pre-NLL 错误的 migrate borrowck 模式；修正 `[0usize; 0]` 数组零长度表达式 drop。
- 移除 label/lifetime 遮蔽告警。
- 有 impl Trait 参数时允许显式泛型参数。
- `cenum_impl_drop_cast` lint 变 deny-by-default；`-C panic=abort` 时无论 ABI 一律不 unwind。
- `lub` 修正 empty binders 时的退出。

## Compiler
- 稳定 `bundle` 原生库链接修改器，同时移除已弃用的 `static-nobundle` 链接类型。
- 新增 Apple watchOS 编译 target；rustc 加 Windows application manifest。

## Libraries
- `core::fmt::Alignment` 实现 Copy/Clone/PartialEq/Eq。
- `ptr::null`/`null_mut` 扩展到所有 thin（含 extern）类型。
- **`VecDeque<u8>` 实现 `Read`/`Write`**。
- 3DS 平台 std 支持；float→Duration 转换用四舍五入。
- `write!`/`print!` 宏立即 drop 临时值；`OsStr` 的 join 内部 trait；`Hash for core::alloc::Layout`；`mem::needs_drop` 接受 `?Sized`；`Infallible` 实现 `Termination`（`Result` impl 更泛化）。

## Stabilized APIs
- `array::from_fn` — 按下标函数生成数组
- `Box::into_pin`
- `BinaryHeap::try_reserve` / `try_reserve_exact` / `OsString::try_reserve(_exact)` / `PathBuf::try_reserve(_exact)`
- `Path::try_exists` — 区分"不存在"与"出错"
- `Ref::filter_map` / `RefMut::filter_map` — RefCell 内部值映射
- `NonNull::<[T]>::len`
- `ToOwned::clone_into`
- `Ipv6Addr::to_ipv4_mapped`
- unix `io::{AsFd, BorrowedFd<'fd>, OwnedFd}`；windows `io::{AsHandle, BorrowedHandle, OwnedHandle, HandleOrInvalid, HandleOrNull, InvalidHandleError, NullHandleError, AsSocket, BorrowedSocket, OwnedSocket}` — 文件描述符/句柄的所有权抽象（为 io-safety 铺路）
- **`thread::scope` / `thread::Scope` / `thread::ScopedJoinHandle`** — 作用域线程：spawn 借用栈数据的线程，join 时自动等待
- 以下 API 可用于 const 上下文：`array::from_ref`、`slice::from_ref`、`intrinsics::{copy, copy_nonoverlapping}`、`<*{const,mut} T>::copy_to(_nonoverlapping)`、`<*mut T>::copy_from(_nonoverlapping)`、`str::from_utf8`、`Utf8Error::{error_len, valid_up_to}`、`Condvar::new`、`Mutex::new`、`RwLock::new`

## Cargo
- 稳定 `--config path`；环境暴露 `CARGO_PKG_RUST_VERSION`。

## Compatibility Notes
- `#[link]` 属性检查更严格，以前忽略的非法参数会报错。
- float→Duration 转换改用四舍五入，转换结果可能略有不同。
