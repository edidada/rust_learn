# Rust 1.85.0（2025-02-20）

> 来源：[releases.rs/docs/1.85.0](https://releases.rs/docs/1.85.0/)；演示：`cargo run -p versions --bin rustc_1_85_0`

## Language
- **2024 Edition 正式稳定**（cargo 可 `edition = "2024"`）。
- **稳定 async closures**（RFC 3668）：`async || { … }`，实现 `AsyncFn`/`AsyncFnMut`/`AsyncFnOnce`，与普通闭包不同——返回的 future 可以借用闭包捕获的值。
- 稳定 `#[diagnostic::do_not_recommend]`：让 trait 解析失败时不要推荐该 impl 的 blanket 实现（诊断优化）。
- 新增 `unpredictable_function_pointer_comparisons` lint（函数指针比较告警）；`#[no_mangle]` 与 `#[export_name]` 组合使用时 lint。
- Edition 2024 语言点（详见 edition guide）：`gen` 成为保留关键字（要用写 `r#gen`）；**unsafe 属性必须写 `#[unsafe(…)]`**（`no_mangle`、`link_name`、`export_name` 等）；`unsafe_op_in_unsafe_fn` 默认 warn；RPIT 捕获规则改用 `use<…>`；`static_mut_refs` 硬错误；`handle_profile_exit` 等其余细节见官方页。

## Compiler
- 移除 unstable 的 `-Zpolymorphize`。

## Platform Support
- powerpc64le-unknown-linux-musl 升 tier 2（带 host tools）。

## Libraries
- std 的 panic 路径前缀 `library/`。
- Windows 上 `std::env::home_dir()` 忽略非标准的 `$HOME`（后续版本取消弃用）。
- **`AsyncFn*` 进入所有 edition 的 prelude**。

## Stabilized APIs
- `BuildHasherDefault::new`
- `ptr::fn_addr_eq`
- `io::ErrorKind::QuotaExceeded` / `io::ErrorKind::CrossesDevices`
- `{float}::midpoint` / `Unsigned {integer}::midpoint` / `NonZeroU*::midpoint`
- `impl std::iter::Extend for tuples (arity 1..12)`；`FromIterator<(A, …)> for tuples (arity 1..12)`
- `std::task::Waker::noop`
- 以下可用于 const 上下文：`mem::size_of_val` / `align_of_val`、`Layout::for_value/align_to/pad_to_align/extend/array`、`std::mem::swap`、`std::ptr::swap`、`NonNull::new`、`HashMap::with_hasher`、`HashSet::with_hasher`、`BuildHasherDefault::new`、`{float}::recip/to_degrees/to_radians/max/min/clamp/abs/signum/copysign`、`MaybeUninit::write`

## Cargo
- cfg 关键字的 future-incompatibility 告警 + raw-idents；稳定高优先级尾随 flag；给 build script 传 `CARGO_CFG_FEATURE`。

## Rustdoc
- impl 块的 doc comment 在折叠时也显示第一行。

## Compatibility Notes
- `test` cfg 不再被 rustc 内置为 well-known（由构建系统用 `--check-cfg=cfg(test)` 设置；Cargo 目前仍无条件设置）。
- 平凡与非平凡 where 子句并存时禁用可能错误推断。
- `core::ffi::c_char` 符号性更贴近平台默认 char（多目标 i8/u8 对调，可能引发编译失败）。
- 外部 crate 的嵌套 macro_rules 按外部 crate 的 edition 展开。
- Solaris 基线升至 11.4；`abi_unsupported_vector_types` 出现在 future breakage 报告；dyn Trait 多个 super-trait 实例化要求指定关联类型（只给一个时报错）；AIX 默认 codemodel 改 large。
