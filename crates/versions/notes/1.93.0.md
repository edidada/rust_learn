# Rust 1.93.0（2026-01-22）

> 来源：[releases.rs/docs/1.93.0](https://releases.rs/docs/1.93.0/)；演示：`cargo run -p versions --bin rustc_1_93_0`

## Language
- 稳定 s390x 向量相关 target features 及 `is_s390x_feature_detected!` 宏。
- **稳定 system ABI 的 C 式变参函数声明**（接续 1.91 的 sysv64/win64/efiapi/aapcs）。
- 关键字用作 cfg 谓词直接报错；`asm_cfg` 稳定（inline asm 里写 SVolk 特殊 cfg）。
- const 求值支持逐字节复制指针；LUB 强转正确处理函数项与不同安全性函数。
- **允许 const item 含对 static 的可变引用**（非常 unsafe 但不一定 UB），并新增 `const_item_interior_mutations` lint（warn）。
- `function_casts_as_integer` lint（warn）：函数指针转整数告警。

## Compiler / Platform Support
- `-Cjump-tables=bool` 稳定（原 `-Zno-jump-tables`）。
- `riscv64a23-unknown-linux-gnu` 升 Tier 2（无 host tools）。

## Libraries
- 不再有依赖生命周期的 Copy 特化（部分 std API 可能回退到 `Clone::clone`，存在性能回退可能）。
- 允许分配器使用线程局部存储与 `std::thread::current()`。
- `BTree::append` 追加已存在键时不再更新已有键；`vec::IntoIter<T>: UnwindSafe` 不再要求 `T: RefUnwindSafe`。

## Stabilized APIs
- `<[MaybeUninit<T>]>::assume_init_drop` / `assume_init_ref` / `assume_init_mut` / `write_copy_of_slice` / `write_clone_of_slice`
- **unchecked 系**：`{iN}::unchecked_neg` / `unchecked_shl` / `unchecked_shr`、`{uN}::unchecked_shl` / `unchecked_shr`
- `String::into_raw_parts`、`Vec::into_raw_parts`
- `<[T]>::as_array` / `as_mut_array`、`<*const [T]>::as_array`、`<*mut [T]>::as_mut_array`
- `VecDeque::pop_front_if` / `pop_back_if`
- `Duration::from_nanos_u128`
- `char::MAX_LEN_UTF8` / `char::MAX_LEN_UTF16`
- `std::fmt::from_fn` / `std::fmt::FromFn`

## Cargo
- build script 按 profile 设置 `CARGO_CFG_DEBUG_ASSERTIONS`；`cargo tree --format` 支持长变量名；`cargo clean --workspace`。

## Rustdoc
- 移除 `#![doc(document_private_items)]`；搜索过滤器纳入属性/derive 宏与 extern crate；crate 级 doc 属性用法校验（违规 → deny lint `rustdoc::invalid_doc_attributes`）。

## Compatibility Notes（多，全列）
- 内建属性命名空间引入 `pin_v2`。
- 捆绑 musl 升至 1.2.5。
- Emscripten 的 unwind ABI 从 JS 异常处理改为 wasm 异常处理（链接 C/C++ 需 `-fwasm-exceptions`）。
- `#[test]` 用在无意义位置（trait 方法、类型等）不再忽略，直接报错。
- `CARGO_CFG_DEBUG_ASSERTIONS` 设置范围扩大（static-init 1.0.1~1.0.3 会编译失败）。
- `offset_of!` 中手写类型做 well-formedness 检查。
- `build.build-dir` 未设置时 `cargo publish` 也不再产出 .crate 文件（接 1.91 遗留）。
- `deref_nullptr` lint 升为 deny。
- future-incompat：extern 块之外的 `...` 无模式函数参数。
- future-compat：`repr(C)` 枚举判别值装不进 `c_int`/`c_uint` 告警；`repr(transparent)` 忽略 `repr(C)` 类型告警。
