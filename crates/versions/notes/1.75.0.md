# Rust 1.75.0（2023-12-28）

> 来源：[releases.rs/docs/1.75.0](https://releases.rs/docs/1.75.0/)；演示：`cargo run -p versions --bin rustc_1_75_0`

## Language
- **稳定 trait 中的 `async fn` 与返回位置 impl Trait（RPITIT）**：
  - trait 方法可写 `fn f() -> impl Trait`（RPITIT）与 `async fn f()`（异步 trait 方法）。
  - **注意**：`async fn` in trait 返回的是匿名 `impl Future`，std 没有内置 runtime，不能直接 `spawn`（spawn trait 未来仍 unstable）；要执行需要手动 poll 或外部 runtime。演示用 `std::task` 手动 poll 完成。
- 允许 const 上下文中包含 `&mut T` 的函数指针签名。
- 可用半开区间穷尽匹配 `usize`/`isize`（`0..usize::MAX` 穷尽 + `_` 兜底）。
- 保证 `char` 与 `u32` 大小/对齐相同；文档注明空指针地址为 0。
- match 中允许部分 move 值。
- 记录 32 位 x86 目标非合规 FP 行为的说明；稳定已批准的 RISC-V target features。

## Compiler
- 重做 negative coherence；`COINDUCTIVE_OVERLAP_IN_COHERENCE` 升为 deny；NLL 计算 liveness 时考虑 alias bounds；riscv64-linux-android 目标加 V 扩展；小函数自动跨 crate 内联。
- 新 tier 3 目标：`csky-unknown-linux-gnuabiv2hf`、`i586-unknown-netbsd`、`mipsel-unknown-netbsd`。

## Libraries
- `Waker::clone_from` 覆写避免不必要克隆；`BufRead for VecDeque<u8>`；`DecodeUtf16` 的 FusedIterator。
- 为 IP 地址实现 `Not`/`BitAnd`/`BitOr`（及 Assign）；`ExitCode` 实现 `Default`。
- **保证 NPO（None 的表示为零/不合法位）**；文档化原子读保证只读；递归 TLS 初始化后果放宽。
- Windows 支持亚毫秒 sleep；修正 str::SplitInclusive 的 DoubleEndedIterator bound；修正 cfg(unix) 非 Unix 平台的 exit status。

## Stabilized APIs
- `Atomic*::from_ptr` — 从裸指针构造 `&Atomic*`。
- `FileTimes` / `FileTimesExt` / `File::set_modified` / `File::set_times` — 设置文件时间戳。
- `IpAddr::to_canonical` / `Ipv6Addr::to_canonical` — IPv4 映射地址规范化。
- `Option::as_slice` / `Option::as_mut_slice` — Option 直接切片。
- `pointer::{byte_add, byte_offset, byte_offset_from, byte_sub, wrapping_byte_add, wrapping_byte_offset, wrapping_byte_sub}` — 按字节运算的指针 API。
- 以下 API 现在可在 const 上下文使用：`Ipv6Addr::to_ipv4_mapped`、`MaybeUninit::assume_init_read`、`MaybeUninit::zeroed`、`mem::discriminant`、`mem::zeroed`。

## Cargo
- 自动把新包加入 `[workspace.members]`；允许无版本的 Cargo.toml 清单；HTML 文件路径生成浏览器链接。

## Rustdoc
- 接受更少非法 Rust；文档说明受影响 trait 不具对象安全性；非公共 ABI 时隐藏 `#[repr(transparent)]`；C-like 变体显示枚举判别值。

## Compatibility Notes
- FreeBSD 目标至少要求 12 版本；MIPS tier 2 正式降级 tier 3。
- **const 上下文中未对齐成为硬错误**。
- 修正 packed unsized 字段引用检测；移除编译器插件支持。

## Internal Changes
- librustc_driver.so 用 BOLT 优化；dev/nightly 启用并行前端；nightly 提供 rustc-codegen-cranelift 组件。
