# Rust 1.77.0（2024-03-21）

> 来源：[releases.rs/docs/1.77.0](https://releases.rs/docs/1.77.0/)；演示：`cargo run -p versions --bin rustc_1_77_0`

## Language
- 在定义体内部为穷尽性检查揭示 opaque types。
- **稳定 C 字符串字面量**：`c"hello"` 直接得到 `&'static CStr`。
- 稳定 THIR unsafeck；新增 `static_mut_refs` lint（对可变 static 的引用发警告，为未来硬错误铺路）。
- 支持 async 递归调用（只要带间接层如 `Box`）。
- 取消弃用 `unstable_features` lint 并在编译器内使用。
- coherence 中的归纳循环一律视为歧义；const-eval interning 取消类型驱动遍历（仅 future 兼容 lint）。
- **let-else 中 deny 大括号宏调用**（`let X = macro!{} else ...` 不再允许）。

## Compiler
- `soft_unstable` lint 进 future breakage 报告；x86 目标上 i128/u128 按 16 字节对齐；诊断输出用 `--verbose`；改进打印 token 间距。
- `unused_tuple_struct_fields` 合并进 `dead_code`。
- well-formedness 检查中错误的隐式 bound 报错（Bevy 临时豁免）；修复 fn/const item 的隐式 bound 与 well-formedness 检查；修复非 ASCII 源码的 coverage。
- `riscv32{im|imafc}-unknown-none-elf` 升 tier 2；新增 tier 3：`aarch64-unknown-illumos`、`hexagon-unknown-none-elf`、`riscv32imafc-esp-espidf`、`riscv32im-risc0-zkvm-elf`。

## Libraries
- `From<&[T; N]> for Cow<[T]>`。
- 移除 `vec.split_off(0)` 的特殊处理路径。

## Stabilized APIs
- `array::each_ref` / `array::each_mut` — 数组逐元素引用视图（`&[T; N]` -> `[&T; N]` 类似物：实际返回 `ArrayView`，可 `.as_array()` 等）。
- `core::net` — core 下的网络基础类型模块（IpAddr 等，供 no_std）。
- `f32::round_ties_even` / `f64::round_ties_even` — "ties to even" 舍入。
- `mem::offset_of!` — 取结构体字段偏移量的宏。
- `slice::{first_chunk, first_chunk_mut, split_first_chunk, split_first_chunk_mut, last_chunk, last_chunk_mut, split_last_chunk, split_last_chunk_mut}` — 定长首/尾块（`Option<(&[T; N], &[T])>`）。
- `slice::{chunk_by, chunk_by_mut}` — 按条件分块。
- `Bound::map` — 转换 `Bound<T>` 内的值。
- `File::create_new` — 仅当文件不存在时创建（原子性）。
- `Mutex::clear_poison` / `RwLock::clear_poison` — 清除毒化状态。

## Cargo
- build script 指令扩展为 `cargo::` 新语法（可携带键值对）；稳定 metadata id 格式（PackageIDSpec）；抽出 cargo-util-schemas crate；未请求 debuginfo 时全部剥离；所有 runner 从环境继承 jobserver；弃用 cargo 中 rustc 插件支持。

## Rustdoc
- markdown 标题中的链接；按类型搜索元组/单元（用 `()`）；清理源码侧边栏隐藏按钮；防止 localStorage 的 JS 注入。

## Misc
- 风格指南建议所有排序使用版本排序（version-sorting）。
