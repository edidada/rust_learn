# Rust 1.50.0（2021-02-11）

> 来源：[releases.rs/docs/1.50.0](https://releases.rs/docs/1.50.0/)；演示：`cargo run -p versions --bin rustc_1_50_0`

## Language
- **数组重复表达式可用 const 值**：`[x; N]` 中的 `x` 现在可以是具名 `const` 常量（如 `const NAN: u8 = 3; let a = [NAN; 10];`）。技术上自 1.38.0 起就已无意稳定可用，本版正式确认。
- 给 `ManuallyDrop<T>` union 字段赋值现在视为安全操作。

## Compiler
- 新增 tier 3 支持：`armv5te-unknown-linux-uclibceabi`、`aarch64-apple-ios-macabi`。
- `x86_64-unknown-freebsd` 现在用完整工具集构建。
- 移除所有 cloudabi 目标的支持。

## Libraries
- `proc_macro::Punct` 实现 `PartialEq<char>`。
- `ops::{Index, IndexMut}` 现在对任意长度的定长数组实现。
- Unix 平台上 `std::fs::File` 现在有 -1 这个"niche"值（不是合法 fd），使 `Option<File>` 占用与 `File` 相同空间。

## Stabilized APIs
- `bool::then` — 按布尔条件短路求值返回 `Option`
- `btree_map::Entry::or_insert_with_key` — 空位时按 key 计算插入值
- `f32::clamp` / `f64::clamp` — 区间钳制
- `hash_map::Entry::or_insert_with_key` — 同上（哈希表版）
- `Ord::clamp` — 数值/有序值区间钳制
- `RefCell::take` — 取出内部值并把 cell 替换为默认值
- `slice::fill` — 用一个值填充切片
- `UnsafeCell::get_mut`
- 以下既有方法变为 const：`IpAddr::is_ipv4/is_ipv6/is_unspecified/is_loopback/is_multicast`、`Ipv4Addr::octets/is_loopback/is_private/is_link_local/is_multicast/is_broadcast/is_documentation/to_ipv6_compatible/to_ipv6_mapped`、`Ipv6Addr::segments/is_unspecified/is_loopback/is_multicast/to_ipv4`、`Layout::size/align/from_size_align`、所有整型的 `pow/checked_pow/saturating_pow/wrapping_pow`、无符号整型的 `next_power_of_two/checked_next_power_of_two`

## Cargo
- 新增 `[build.rustc-workspace-wrapper]` 选项：仅对 workspace 成员用包装命令替代 rustc。
- `cargo:rerun-if-changed` 给出目录时会扫描整个目录内容。
- `cargo update` 新增 `--workspace` 标志。

## Misc
- rustdoc 搜索结果标签页和帮助按钮可键盘聚焦。
- 跑测试现在会打印总耗时。

## Compatibility Notes
- 原子类型的 `compare_and_swap` 被弃用，推荐 `compare_exchange` / `compare_exchange_weak`。
- TokenStream 检查方式变化，修掉了一些可写出非卫生 `macro_rules!` 宏的情况。
- `#![test]` 内部属性与其他内部宏属性一样视为 unstable，默认经 `soft_unstable` lint 报错。
- 在与设置时相同级别覆盖 `forbid` lint 现在是硬错误。
- 无法再用自定义同名宏拦截 `panic!` 调用；自定义实现请用 `#[panic_handler]`。
- item 语句后的分号（如 `struct Foo {};`）现在会产生警告。
