# Rust 1.58.0（2022-01-13）

> 来源：[releases.rs/docs/1.58.0](https://releases.rs/docs/1.58.0/)；演示：`cargo run -p versions --bin rustc_1_58_0`

## Language
- **inline format args（格式串捕获标识符）**：format 字符串里直接写 `{ident}` 即可捕获同名变量，适用于所有接受格式串的宏（`format!`/`println!`/`write!` 等）。注意：`panic!("{ident}")` 形式需要 2021 edition。
- `*const T` 现在可以在 const 上下文解引用。
- 泛型 struct 实现 `Unsize` 的规则放宽。

## Compiler
- 新增 LLVM CFI 支持；`-Z strip` 稳定为 `-C strip`（可去掉 std 自带 debug 符号以减小发布体积，本版仅 rustc 支持，cargo 尚未直接支持）。
- 支持 LLVM coverage mapping 格式 5/6；`-Cremark` 输出优化 remark；最低 LLVM 升至 12。
- 新增 tier 3：`x86_64-unknown-none`；musl dist 构建带 debuginfo（建议配合 strip）。
- lint 报错后不再立刻中止编译；错误更精确指向 trait bound obligation 的来源。

## Libraries
- **std 剩余函数全面加 `#[must_use]`**。
- Windows 上受支持操作会自动 canonicalize 路径。
- `copy` / `copy_nonoverlapping` 重新启用 debug 检查。
- `Rc<T>` 实现 `RefUnwindSafe`；`RSplit<T, P>: Clone` 不再要求 `T: Clone`。
- `Result<Infallible, E>` 实现 `Termination`：可写 `fn main() -> Result<Infallible, ErrorType>`（成功路径不返回 main 的程序用）。

## Stabilized APIs
- `Metadata::is_symlink` / `Path::is_symlink` — 软链接判断
- `{integer}::saturating_div` — 溢出时向最值钳制除法
- `Option::unwrap_unchecked` / `Result::unwrap_unchecked` / `Result::unwrap_err_unchecked` — 前提已保证时的无检查解包（unsafe）
- `File::options` — 等价 `OpenOptions::new()` 的快捷入口
- 以下 API 可用于 const 上下文：`Duration::new`、`Duration::{checked_add, saturating_add, checked_sub, saturating_sub, checked_mul, saturating_mul, checked_div}`

## Cargo
- `install` 命令支持 `--message-format`；别名遮盖外部子命令时告警。

## Rustdoc
- rustdoc 递归展示 Deref 实现；使用计算的可见性。

## Compatibility Notes
- 方法解析先尝试全部稳定候选再试 unstable 类候选（新增 nightly-only 方法不再破坏外部 trait 同名方法调用）。
- Windows 上 `std::process::Command` 不再搜索当前目录。
- 所有 proc-macro 后向兼容 lint 变 deny-by-default。
- `proc_macro` 会向无后缀浮点 token 补 `.0`（否则会误判成 int token）。
- std::sys::unix 弱符号重构（不再 dlopen；不提高 glibc 最低版本要求，但做符号版本分析的发行包可能误报依赖新版 glibc）。
- rustdoc doctest 拒绝某些多余分号。
