# Rust 1.24.1（2018-03-01）

> 来源：[releases.rs/docs/1.24.1](https://releases.rs/docs/1.24.1/)；演示：`cargo run -p versions --bin rustc_1_24_1`

## Changes
- **发布补丁版**：
  - 不再在 unwinding 穿越 FFI 时 abort（放宽 1.24.0 引入的过严行为）。
  - Windows 上为链接器参数生成 UTF-16 文件。
  - 修复 error index 生成器。
  - Windows 7 上 Cargo 会在需要更新时发出警告。
