# Rust 1.15.1（2017-02-09）

> 来源：[releases.rs/docs/1.15.1](https://releases.rs/docs/1.15.1/)；演示：`cargo run -p versions --bin rustc_1_15_1`

补丁版本（patch release），仅两项修复。

## 修复项
- **修复 `IntoIter::as_mut_slice` 的签名**（1.15.0 中该 API 签名有误，补丁纠正）。
- 32 位平台上以 `-fPIC` 编译 compiler builtins。

## 演示对照
| 节 | 主题 |
|---|---|
| 1 | vec::IntoIter 的 as_slice / as_mut_slice（签名修复后可用） |
| 2 | builtins -fPIC 修复讲解 |
