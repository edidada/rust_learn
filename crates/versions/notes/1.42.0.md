# Rust 1.42.0（2020-03-12）

> 来源：[releases.rs/docs/1.42.0](https://releases.rs/docs/1.42.0/)；演示：`cargo run -p versions --bin rustc_1_42_0`

## Language
- **slice pattern 支持子切片**：`[\"Hello\", \"World\", ..]` 之外还能用子切线模式（`rest` 捕获剩余），如 `match words { [\"Hello\", .., rest] => ... }`。
- 单变体（univariant）enum 可用 `#[repr(transparent)]`，与所含类型的布局/ABI 完全一致。
- inline module 上可用 outer attribute 过程宏。
- **语法仅变更**（语义仍拒绝，但可被过程宏/条件编译解析）：trait 定义里 item 前可写 `default`；impl 内 item 可省略函数体只写 `;`；impl 内关联类型可写约束（`type Foo: Ord;`）；C-variadic `...` 可作为任意函数参数类型。

## Compiler
- armv7a-none-eabi、riscv64gc-unknown-linux-gnu 升为 tier 2。
- `Option::{expect,unwrap}` 与 `Result::{expect,expect_err,unwrap,unwrap_err}` 的 panic 消息指向调用者位置。

## Libraries
- `iter::Empty<T>` 对任意 T 实现 `Send`/`Sync`。
- `Pin::{map_unchecked, map_unchecked_mut}` 不再要求返回类型实现 `Sized`。
- `io::Cursor` derive `PartialEq`/`Eq`。
- `Layout::new` 成为 const。
- riscv64gc-unknown-linux-gnu 获标准库支持。

## Stabilized APIs
- `CondVar::wait_while` — 带谓词地等待（阻塞直到条件真）
- `CondVar::wait_timeout_while` — 同上，带超时
- `DebugMap::key` — Debug map 条目取 key
- `DebugMap::value` — Debug map 条目取 value
- `ManuallyDrop::take` — 取值并绕过 Drop
- `matches!` — **宏**：表达式与模式一行的断言
- `ptr::slice_from_raw_parts_mut` — 由裸指针+长度构造 `*mut [T]`
- `ptr::slice_from_raw_parts` — 不可变版本

## Cargo
- 2018 edition 无需再写 `extern crate proc_macro;` 即可使用 proc_macro。

## Compatibility Notes
- `Error::description` 弃用，使用会产生警告；建议 `Display`/`to_string`。
