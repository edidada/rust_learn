# Rust 1.38.0（2019-09-26）

> 来源：[releases.rs/docs/1.38.0](https://releases.rs/docs/1.38.0/)；演示：`cargo run -p versions --bin rustc_1_38_0`

## Language
- `#[global_allocator]` 属性可用于子模块。
- `#[deprecated]` 可用于宏。

## Compiler
- 流水线编译（pipelined compilation）改进编译时间。
- 新增若干 tier 3 目标（UWP 系列、armv7 gnueabi/musleabi、hexagon、riscv32i）。
- 升级 LLVM 9。

## Libraries
- `ascii::EscapeDefault` 实现 `Clone`/`Display`。
- **derive 宏与 trait 同路径可用**：`std::clone::Clone` 既是 trait 也是 derive 宏，内置宏全部可在 `std`/`core` 根下使用（如 `std::include_bytes!`）。
- `str::Chars` 实现 `Debug`。
- `slice::{concat, connect, join}` 接受 `&[T]`（原来只接受 `&T`）。
- `*const T` / `*mut T` 实现 `marker::Unpin`。
- `Arc<[T]>` / `Rc<[T]>` 实现 `FromIterator<T>`。
- **欧几里得除法/取余**：所有数字原始类型新增 `div_euclid` / `rem_euclid`，整数另有 checked/overflowing/wrapping 版本。
- `thread::AccessError` 实现 `Clone`/`Copy`/`Eq`/`Error`/`PartialEq`。
- `iter::{StepBy, Peekable, Take}` 实现 `DoubleEndedIterator`。

## Stabilized APIs
- `<*const T>::cast` — 裸指针类型转换
- `<*mut T>::cast` — 同上（可变）
- `Duration::as_secs_f32` — 时长→秒（f32）
- `Duration::as_secs_f64` — 时长→秒（f64）
- `Duration::div_f32` / `div_f64` — 时长除以数
- `Duration::from_secs_f32` / `from_secs_f64` — 秒→时长
- `Duration::mul_f32` / `mul_f64` — 时长乘以数
- `any::type_name` — 取类型名字符串（调试利器）

## Cargo
- Cargo 也启用流水线编译。
- `--features` 可多次传入以启用多个 feature。

## Rustdoc
- `pub use` 语句上的文档会前置到被重导出项的文档里。

## Misc
- rustc 对 `mem::{uninitialized, zeroed}` 中已知会导致 UB 的用法开始发出警告。

## Compatibility Notes
- `x86_64-unknown-uefi` 无法用 1.38.0 构建。
- `armv7-unknown-linux-gnueabihf` 与 libc 等部分 crate 存在已知问题。
