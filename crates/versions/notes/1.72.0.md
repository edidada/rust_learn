# Rust 1.72.0（2023-08-24）

> 来源：[releases.rs/docs/1.72.0](https://releases.rs/docs/1.72.0/)；演示：`cargo run -p versions --bin rustc_1_72_0`

## Language
- **const 求值上限从硬错误改为 lint**，并新增指数退避警告（避免极端循环卡死编译）。
- `#![cfg(FALSE)]` 在 crate 根上的行为改变（expand 侧）。
- LoongArch64 上稳定 inline asm。
- **从 Clippy 上提多个 lint**：
  - `undropped_manually_drops`
  - `invalid_from_utf8_unchecked` / `invalid_from_utf8`（原 `invalid_utf8_in_unchecked`）
  - `invalid_reference_casting`（原 `cast_ref_to_mut`：把 `&T` 强转成 `&mut T` 是 UB）
  - `invalid_nan_comparisons`（原 `cmp_nan`：与 NaN 比较永远 false）
- **移除人为的 import 歧义错误**（resolve）。
- dyn Trait 对象不再要求带 `Self: Sized` bound 的关联类型出现。

## Compiler
- 诊断可提及 cfg 掉条目的名字；支持原生 WASM 异常；支持 NetBSD/aarch64-be。
- 输出文件为 `-` 时写 stdout；链接静态二进制时原生库全部静态链接。
- 新 tier 3 目标 `loongarch64-unknown-none*`；`-C panic=abort` 不再生成 `.eh_frame`；debuginfo 支持 128 位枚举变体；solaris/illumos 启用 tsan。

## Libraries
- 文档化 `thread::{park,unpark}` 的内存序。
- 放宽 `io::Write::write` 的"至多一次写尝试"要求；指明 `HashSet::insert` 行为。
- `BufReader<T>`/`BufWriter<T>`/`LineWriter<T>` 的隐式 `T: Sized` bound 放宽。
- 更新 `select_nth_unstable` 的运行时保证；进程已退出时 `kill` 返回 Ok。
- 为不同分配器的 Vec 实现 `PartialOrd`。
- **`TypeId` 哈希用 128 位**。
- 各集合的 `DrainFilter` 不再 drain-on-drop。
- `{Arc,Rc,Weak}::ptr_eq` 忽略指针元数据（比较数据地址，`&&T`/切片长度不再影响结果）。

## Rustdoc
- 允许空格作为路径分隔符（如 `Vec new`）；搜索结果显示项类型；可用 `[]` 按类型搜索切片/数组；清理类型统一与"unboxing"逻辑。

## Stabilized APIs
- `impl<T: Send> Sync for mpsc::Sender<T>` — 发送端可共享引用跨线程发送。
- `impl TryFrom<&OsStr> for &str` — 路径串转 UTF-8 `&str`，失败返回错误。
- `String::leak` — 泄漏字符串得到 `&'static mut str`。
- 以下 API 现在可在 const 上下文使用：`CStr::from_bytes_with_nul`、`CStr::to_bytes`、`CStr::to_bytes_with_nul`、`CStr::to_str`。

## Cargo
- 默认启用 `-Zdoctest-in-workspace`：每个 doctest 的工作目录设为其所属包根目录。
- build.jobs 支持 "default" 关键字恢复默认并行度。

## Compatibility Notes
- **`Ipv6Addr` 的 Display 对 IPv4 兼容地址改变**。
- Cargo feature 名校验从警告变为硬错误（1.49 的警告转正；只影响非 crates.io registry 用户）。
- `mips*-unknown-linux-gnu*` 目标从 host tier 2 降为 target tier 3。
