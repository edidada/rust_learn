# Rust 1.92.0（2025-12-11）

> 来源：[releases.rs/docs/1.92.0](https://releases.rs/docs/1.92.0/)；演示：`cargo run -p versions --bin rustc_1_92_0`

## Language
- `&raw [mut | const]` 取 union 字段在**安全代码**中允许：为 union 字段建裸指针本身无 UB，不再需要进 unsafe 块（读取仍需 unsafe）。
- 文档化 `MaybeUninit` 的表示与有效性约定。
- auto-trait 与 `Sized` 推导时，关联类型的 item bounds 优先于 where-bounds。
- 不再为 `[X; 0]` 物化 unsizing 常量 `X`。
- 支持 `#[track_caller]` 与 `#[no_mangle]` 组合（要求每处声明都带 `#[track_caller]`）。
- never type 相关 lint `never_type_fallback_flowing_into_unsafe`、`dependency_on_unit_never_type_fallback` 提升为 deny-by-default。
- trait 定义允许对同一关联条目写多个 bound（trait object 中除外）。
- coherence 中高阶区域处理略加强。
- **`unused_must_use` 不再对 `Result<(), Uninhabited>`（如 `Result<(), !>`）或 `ControlFlow<Uninhabited, ()>` 告警**——错误不可能发生，无需强制检查。

## Compiler
- `mips64el-unknown-linux-muslabi64` 改为动态链接。
- 移除向 PDB 嵌入命令行参数的代码：调试工具通常不需要，且即使在不使用 PDB的目标上也会拖慢增量构建。

## Libraries
- `Iterator::eq{_by}` 对 `TrustedLen` 迭代器特化（更快）。
- 简化元组的 `Extend` 实现。
- 为 `EncodeWide` 的 `Debug` 输出补充细节。
- `iter::Repeat::last` / `count` 改为 panic（原先无限循环）。

## Stabilized APIs
- `NonZero<u{N}>::div_ceil` — NonZero 上的向上取整除法
- `Location::file_as_c_str` — 以 C 字符串取文件名
- **`RwLockWriteGuard::downgrade`** — 原子降级为读锁
- **`Box::new_zeroed` / `Box::new_zeroed_slice`** — 零值分配（对应 MaybeUninit 形态）
- **`Rc::new_zeroed` / `Rc::new_zeroed_slice`**
- **`Arc::new_zeroed` / `Arc::new_zeroed_slice`**
- **`btree_map::Entry::insert_entry`、`btree_map::VacantEntry::insert_entry`** — 插入并返回 `OccupiedEntry`
- `TokenStream: Extend<Group/Literal/Punct/Ident>`（4 项）
- const 化：`<[_]>::rotate_left` / `rotate_right`

## Cargo
- Cargo book 新增"Optimizing Build Performance"一章。

## Rustdoc
- 搜索结果中 trait 条目隐藏对应 impl 条目（搜 "last" 不再同时列出 `std::vec::IntoIter::last` 等）。
- 放宽搜索标识符规则：只需是标识符的一部分（如可以以数字开头搜索）。

## Compatibility Notes
- Linux 上 `-C panic=abort` 默认生成 unwind 表以修复回溯（保持旧行为用 `-C force-unwind-tables=no`）。
- future-compat lint `invalid_macro_export_arguments` 升为 deny-by-default，且会在依赖里报告。
- 最低外部 LLVM 升至 20。
- 阻止为 `Pin<LocalType>` 实现 `DerefMut`。
- 非扩展形态的 `pin!` 与格式化宏的参数不再应用临时生命周期延长规则。
