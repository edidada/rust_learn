# Rust 1.27.1（2018-07-10）

> 来源：[releases.rs/docs/1.27.1](https://releases.rs/docs/1.27.1/)；演示：`cargo run -p versions --bin rustc_1_27_1`

## Security Notes
- **rustdoc 插件目录漏洞（CVE-2018-1000622）**：rustdoc 运行时会执行 `/tmp/rustdoc/plugins` 目录中的插件，可被本机其他用户利用执行代码；本版修复。感谢 Red Hat 负责任披露。

## Compatibility Notes
- 借用检查器再修两处 match ergonomics 潜在 unsoundness（#51415、#49534）。
