# Rust 1.36.0（2019-07-04）

> 来源：[releases.rs/docs/1.36.0](https://releases.rs/docs/1.36.0/)；演示：`cargo run -p versions --bin rustc_1_36_0`

## Language
- **NLL（非词法生命周期）在 2015 edition 启用**：1.36 起旧 edition 也用 NLL 借用检查器。
- **trait object 的 trait 顺序不再影响语义**：`dyn Send + fmt::Debug` 与 `dyn fmt::Debug + Send` 等价。

## Libraries
- `HashMap` 内部实现改为 hashbrown 实现（更快）。
- `TryFromSliceError` 实现 `From<Infallible>`。
- `mem::needs_drop` 成为 const fn。
- `alloc::Layout::from_size_align_unchecked` 成为 const fn。
- `String` 实现 `BorrowMut<str>`。
- `io::Cursor` 实现 `Default`。
- `NonNull::{dangling, cast}` 成为 const fn。
- **`alloc` crate 稳定**：`#![no_std]` 环境有堆时可使用 `Vec`/`Box`/`Arc` 等。
- `String` 实现 `From<&String>`。
- `dbg!` 支持多参数（多参数时返回元组）。
- `Result::{is_err, is_ok}` 标记 `#[must_use]`，未使用会产生警告。

## Stabilized APIs
- `VecDeque::rotate_left` — 左旋转
- `VecDeque::rotate_right` — 右旋转
- `Iterator::copied` — 迭代 `&T` 时复制为 `T`
- `io::IoSlice` — 聚合写缓冲
- `io::IoSliceMut` — 聚合读缓冲
- `Read::read_vectored` — 向量读
- `Write::write_vectored` — 向量写
- `str::as_mut_ptr` — 字符串可变裸指针
- `mem::MaybeUninit` — 取代 `mem::uninitialized` 的安全初始化抽象
- `pointer::align_offset` — 调整指针对齐
- `future::Future` — **Future trait 进入标准库**（1.36 稳定入库，为后来 async/await 铺路）
- `task::Context` — 异步任务上下文
- `task::RawWaker` — 底层 waker
- `task::RawWakerVTable` — waker vtable
- `task::Waker` — 唤醒任务
- `task::Poll` — `Poll<T>`（Ready/Pending）

## Cargo
- 依赖名作为 feature 名使用时报错。
- 新增 `--offline` 旗标，可离线构建。

## Clippy
- 大量新增与修复，见 Clippy 1.36.0 release notes。

## Compatibility Notes
- 随着 `mem::MaybeUninit` 稳定，`mem::uninitialized` 不再被推荐，将在 1.39.0 弃用。
