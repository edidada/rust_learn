# Rust 1.14.0（2016-12-22）

> 来源：[releases.rs/docs/1.14.0](https://releases.rs/docs/1.14.0/)；演示：`cargo run -p versions --bin rustc_1_14_0`

## Language
- **`..` 可匹配多个元组字段**（RFC 1492）：枚举变体、结构体、元组中的"其余字段"。
- 安全 fn 项可强转为 unsafe fn 指针；`use *` 与 `use ::*` 均从 crate 根 glob 导入。
- `Vec<Box<Fn()>>` 调用无需显式解引用。

## Compiler
- 非 0 discriminant 枚举标记非零；`static mut` 小写名 lint；目标规格加 panic-strategy 字段；`--version --verbose` 带 LLVM 版本。

## Compile-time Optimizations
- 宏展开提速；BLAKE2b 取代 SHA-256；SmallVector/ArrayVec 减少堆分配；写元数据优化等。

## Libraries
- **`println!()` 无参数即打印换行**（此前必须写 `println!("")`）。
- `Wrapping` 实现标准二元/一元运算符及 Sum/Product。
- `From<Cow<str>> for String`、`From<Cow<[T]>> for Vec<T>`。
- 迭代器 fold 性能（chain/cloned/map/VecDeque）提升；zip 特化扩展到 map/cloned；新增 `TrustedLen` trait（内部）。
- `io::Error` 实现 `From<io::ErrorKind>`；裸指针 Debug 对非 Sized 数据可用。
- **HashMap 内存布局更缓存友好**（显著提速），32 位架构省内存，不再复用随机种子。

## Cargo
- 构建脚本可读 rustc cfg；只读 CARGO_HOME；工作区单 profile；lock 文件 replace 段等。

## Tooling / Misc
- **rustup 成为推荐安装方式**；新增 MIPS/PowerPC/S390x 主机构建；ARM Linux MUSL std；实验性 WebAssembly（wasm32-unknown-emscripten）。

## Compatibility Notes
- 一批前向兼容 lint 转 deny：浮点常量入模式、`'_` 生命周期、重叠固有 impl、`super`/`self` 全局路径开头等。
- trait 方法禁止无名模式；`Ordering` 不可穷尽匹配（保留扩展余地）；枚举禁止非 Sized；RFC 1560 阴影限制启用等。
