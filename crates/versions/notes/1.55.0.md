# Rust 1.55.0（2021-09-09）

> 来源：[releases.rs/docs/1.55.0](https://releases.rs/docs/1.55.0/)；演示：`cargo run -p versions --bin rustc_1_55_0`

## Language
- **开放起点范围模式（`X..`）**：range-to 性质 pattern，从 X 开始到整型最大值。
- 可在不同 edition 间显式导入 prelude：`use std::prelude::rust_2021::*;`。

## Compiler
- 新增 tier 3：`powerpc64le-unknown-freebsd`。

## Libraries
- std 的浮点解析改用 Eisel-Lemire 算法：字符串转浮点更快、不再拒绝部分合法浮点值、代码体积变小。
- `string::Drain` 实现 `AsRef<str>` 与 `AsRef<[u8]>`。

## Stabilised APIs
- `Bound::cloned` — 把 `Bound<&T>` 镜像成 `Bound<T>`（`T: Clone`）
- `Drain::as_str` — 取 drain 元素剩余字符串
- `IntoInnerError::into_error` / `into_parts` — 拆出写入错误与 writer
- `MaybeUninit::assume_init_mut` / `assume_init_ref` — 取未初始化数据的可变/共享引用
- `MaybeUninit::write` — 写入值（覆盖旧内容所以使其处于初始化状态）
- `array::map` — 数组逐元素映射
- `ops::ControlFlow` — 早退控制流枚举稳定
- x86 的 `_bittest` / `_bittestandcomplement` / `_bittestandreset` / `_bittestandset` / `_bittestand*_64` 系列
- 以下既有函数变 const：`str::from_utf8_unchecked`

## Cargo
- 并行编译时终端诊断去重（如 `cargo test`）。
- cargo metadata 的包定义增加 `default_run` 字段。
- `cargo d` 作为 `cargo doc` 别名；`cargo tree` 新增 `{lib}` 格式化项。

## Rustdoc
- 搜索框"精确匹配时跳转"行为；trait 实现默认展开显示。
- 实现列表去除冗余方法定义；`#[doc(hidden)]` trait 不再出现在实现列表。
- intra-doc link 能通过 type alias 解析关联条目。

## Compatibility Notes
- std 返回 `io::Error` 的函数不再使用 `ErrorKind::Other`（改用更具体的 Kind 或 `Other` 内部语义收紧）。
- Windows 上 `process::Command` 的环境变量名不再被 ASCII 大写化。
- Rustdoc 对未加 `rustdoc::` 前缀的 rustdoc lint 告警。
- `RUSTFLAGS` 不再传给 build 脚本；改用 `CARGO_ENCODED_RUSTFLAGS`。
