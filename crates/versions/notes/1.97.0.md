# Rust 1.97.0（2026-07-09）

> 来源：[releases.rs/docs/1.97.0](https://releases.rs/docs/1.97.0/)；演示：`cargo run -p versions --bin rustc_1_97_0`

## Language
- `Result<T, !>`、`ControlFlow<!, T>` 在 must_use lint 中视同 `T`（不可能的错误无需检查）。
- 新增 allow-by-default `dead_code_pub_in_binary` lint：二进制 crate 里未用的 `pub` item。
- 稳定 div32、lam-bh、lamcas、ld-seq-sa、scq target features。
- 稳定 `cfg(target_has_atomic_primitive_alignment)`。
- 更多场景允许 import 里尾随 `self`。

## Platform Support
- `nvptx64-nvidia-cuda` 放弃旧架构/旧 ISA。

## Stabilized APIs
- `Default for RepeatN`（重复 N 次的迭代器实现 Default）
- `Copy for ffi::FromBytesUntilNulError`
- `Send for std::fs::File`（UEFI 平台）
- `{integer}::{isolate_highest_one, isolate_lowest_one, highest_one, lowest_one, bit_width}`
- `NonZero<{integer}>::{isolate_highest_one, isolate_lowest_one, highest_one, lowest_one, bit_width}`
- const 化（此前已稳定）：`char::is_control`

## Cargo
- 稳定 `build.warnings` 配置（控制本地包 lint 告警处理，CI 无告警可替代 -Dwarnings）。
- 稳定 `resolver.lockfile-path`（指定 lockfile 路径，只读源码目录友好）。
- `cargo clean --target-dir` 对"不像 Cargo target 目录"的路径报错（防误删）。
- 新增 `-m` 短参数（`--manifest-path`）。
- crates-io crate 移除 curl 依赖。

## Rustdoc
- 稳定 `--emit` flag；稳定 `--remap-path-prefix`。

## Compatibility Notes（全列）
- 依赖 `f32: From<{float}>` 来约束 float 的代码发 future-compat 警告。
- **默认启用 v0 符号重整（mangling）方案**：老版本调试器/性能分析器可能无法 demangle；backtrace 文本格式可能变化。
- **禁止 `pin!` 内的 deref 强转**（修 unsoundness）：`pin!(x)`（x: &mut T）现在恒定产生 `Pin<&mut &mut T>`，1.88.0 起被错误允许的强转被移除。
- **弃用 std::char 常量与函数**（如 `std::char::REPLACEMENT_CHARACTER`；改用 `char::` 内在路径）。
- 链接器输出默认转为警告（warn on linker output）。
- 移除 1.0 起已弃用的隐藏 f64 方法。
- 依赖中报告 `varargs_without_pattern` lint。
- 禁止给"模块路径段"传泛型参数（即使模块 reexport 了泛型枚举变体）。
- 无效 macho `link_section` 描述符报错；`#[export_name = ""]` 空名报错。
- 无 layout 保证的枚举编码算法变了（非破坏性，但依赖布局假设者受影响）。
- struct 模式里的元组索引简写语法拒绝。
- 校验 `#[link_name]` / `#[link(name)]` 参数。
- Windows：socket 写端 shutdown 后再写返回 `BrokenPipe`（WSAESHUTDOWN 映射到 io::ErrorKind::BrokenPipe，原先是 Other）。
