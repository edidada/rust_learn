# Rust 1.86.0（2025-04-03）

> 来源：[releases.rs/docs/1.86.0](https://releases.rs/docs/1.86.0/)；演示：`cargo run -p versions --bin rustc_1_86_0`

## Language
- **稳定 trait 对象向 supertrait 上转型（upcasting）**：`&dyn Sub` 可直接当 `&dyn Super` 用（`trait Super {}`、`trait Sub: Super {}`），此前要手写 AsSuper 之类的转发。
- 允许**安全函数**标注 `#[target_feature]`（调用方须具备相应特性，安全函数加特性后内部仍安全）。
- `missing_abi` lint 默认 warn（省略 ABI 的 extern 块/函数要写 `"C"`）。
- 新增 `double_negations` lint（clippy::double_neg uplift）：`--x`、`!!b` 这类双重否定告警。
- const eval 时更多指针因对齐可判定"必然非空"。
- 空 `repr()` 属性用于非法项报错；`#![test]`、`#![rustfmt::skip]` 内属性接受范围收窄。

## Compiler
- 原始指针访问在 debug-assert 下断言非空。
- **`-O` 改为 `-C opt-level=3`**（与 Cargo 默认一致，此前是 2）。
- 修复某些宏环境下的 `overflowing_literals` 发射。

## Platform Support
- i686-unknown-redox → i586-unknown-redox；i686-unknown-hurd-gnu 基线升至 Pentium 4；新增 QNX、win7-windows-gnu、amdgcn、cygwin、mips、m68k、Nuttx 等 tier 3 目标。

## Libraries
- `CStr::from_bytes_with_nul` 的错误类型 `FromBytesWithNulError` 从 opaque struct 变为 enum（可检查失败原因）。
- 移除 `RustcDecodable`/`RustcEncodable`。
- 弃用 libtest `--logfile`。
- 新版 Windows 上 `std::fs::remove_file` 可删除只读文件。

## Stabilized APIs
- `{float}::next_down` / `next_up`
- `<[_]>::get_disjoint_mut` / `get_disjoint_unchecked_mut` / `slice::GetDisjointMutError`
- `HashMap::get_disjoint_mut` / `get_disjoint_unchecked_mut`
- `NonZero::count_ones`
- `Vec::pop_if`
- `sync::Once::wait` / `Once::wait_force` / `OnceLock::wait`
- 以下可用于 const 上下文：`hint::black_box`、`io::Cursor::get_mut/set_position`、`str::is_char_boundary/split_at/split_at_checked/split_at_mut/split_at_mut_checked`

## Cargo
- 合并时替换（而非组合）程序路径+参数类配置键；`--package`/`--workspace` 缺失包时报错；弃用 `cargo login` 的 token 参数（防 shell history 泄漏）；SourceID 比较简化。

## Rustdoc
- 新增无衬线字体设置。

## Compatibility Notes
- **`wasm_c_abi` future-incompat 警告变硬错误**（wasm-bindgen 需 ≥0.2.89）。
- 移除 no-op 属性 `#![no_start]`/`#![crate_id]`。
- `cenum_impl_drop_call` 相关：**无字段枚举实现 Drop 后 cast 到整数是硬错误**。
- i686 32 位 x86 hard-float 目标强制要求 SSE2（pre-SSE2 用 i586 目标）。
