# Rust 1.62.0（2022-06-30）

> 来源：[releases.rs/docs/1.62.0](https://releases.rs/docs/1.62.0/)；演示：`cargo run -p versions --bin rustc_1_62_0`

## Language
- **枚举支持 `#[derive(Default)]` + `#[default]` 变体**：给某个变体标 `#[default]`，枚举即可 derive Default。
- 流敏感检查：明显 uninhabited 的调用表达式被视为绝不返回。
- 修 diverging 表达式中常量不被 drop 的 bug。
- 支持单元 struct/枚举变体在 destructuring assignment 中使用。
- 移除 `mutable_borrow_reservation_conflict` lint 并放行该写法。
- **const fn 可指定 `extern "C"` / `extern "Rust"` 调用约定**。
- （注：常被记成 1.62 的 "`#[must_use]` on `.await`" 实际属于本版前后 must_use 标注扩展的后续；1.62 的主要亮点是枚举 `#[default]`、`bool::then_some`、`total_cmp`、Linux futex 同步原语与 `cargo add`）

## Compiler
- linker：dylib 依赖不再使用 whole-archive。
- `unaligned_references` lint 变 deny-by-default（未来将硬错误）。
- 非 static 项拒绝 `#[thread_local]`；新增 tier 3 `aarch64-pc-windows-gnullvm` / `x86_64-pc-windows-gnullvm`；检测未使用的宏规则；`x86_64-unknown-none` 提升为 Tier 2。

## Libraries
- Windows：管道中继链管道。
- **Linux 的 Mutex/Condvar 改为 futex 实现**；`RwLock` 在 Linux 上也改 futex（更快、更小）。
- std UNIX parker 直接用 pthread。

## Stabilized APIs
- `bool::then_some` — `v.then_some(x)` 直接给值（非闭包）
- `f32::total_cmp` / `f64::total_cmp` — 总序比较（NaN 处理一致，可用于排序）
- `Stdin::lines`
- `windows::CommandExt::raw_arg`
- `impl<T: Default> Default for AssertUnwindSafe<T>`
- `From<Rc<str>> for Rc<[u8]>` / `From<Arc<str>> for Arc<[u8]>`
- `FusedIterator for EncodeWide`
- aarch64 RDM intrinsics

## Clippy
- 新增 match scrutinee 临时值过迟 drop 的 lint。

## Cargo
- **`cargo add` 稳定**：命令行加依赖；包 ID 支持 `name@version`；`~/.cargo` 的 git/registry 目录标记为缓存目录；超长命令行自动转 @ argfile。

## Compatibility Notes
- `cargo test` 同宿主目标时传 `--target` 给 rustdoc。
- doctest 运行未导出的 `macro_rules!` 宏。
- 移除 `.woff` 字体文件。
- 重复元素在 Copy bound 强制时考虑生命周期。
- Windows：File 同步读写无法完成时 abort（修潜在 unsoundness）。
