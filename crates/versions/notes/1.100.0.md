# Rust 1.100.0（nightly，未正式发布）

> 来源：[releases.rs/docs/1.100.0](https://releases.rs/docs/1.100.0/)；演示：`cargo run -p versions --bin rustc_1_100_0`
>
> 页面状态：**Unreleased, branched from master（nightly）**；Branched from master on: 25 September, 2026；Will be stable on: 12 November, 2026。以下为页面列出的已合入 PR（尚未定稿的 release notes），照实记叙。

## Language
- **稳定 never type（`!`）**——历代从未类型化工作的里程碑（"stabilize never type"）。
- 移除 `From<!> for T` 保留 impl。
- 闭包按 `MaybeDangling` 处理（soundness 加强）。
- 修闭包中 `if let` 的捕获行为。

## Libraries
- **stabilise `Allocator`**（alloc 核心 trait 终于稳定）。
- 泛化（大部分）`Box` 上的 impl。
- **稳定 `bool::toggle`**。
- `Iterator::{min,max}(_by_key)` 使用被覆写的 min/max/lt。
- 新增整数 minimum/maximum intrinsics。
- 修 `std::sys::pal::sgx::waitqueue::unsafe_list` 的 soundness 问题。

## Platform / Compiler
- `wasm32-wasip3` 升 **Tier 2**。
- 新 Tier 3 目标：`powerpc64-sony-ps3`。
- x86：要求 SSE 的目标改用 SSE 寄存器做 ABI。
- 32 位 Arm 目标移除 `d32` feature；aarch64 fuchsia 默认 `+fix-cortex-a53-835769`。
- windows-gnullvm 静态链接 libunwind；从 x86_64 交叉编译 i686-pc-windows-gnu std。
- Xtensa ABI 要求 `windowed`（及 exception）。
- 保留子 trait 方法选择时的 ambiguous glob lint（#157968）。
- src 安装构建步骤改名 `rust-src`。
