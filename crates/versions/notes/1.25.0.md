# Rust 1.25.0（2018-03-29）

> 来源：[releases.rs/docs/1.25.0](https://releases.rs/docs/1.25.0/)；演示：`cargo run -p versions --bin rustc_1_25_0`

## Language
- **`#[repr(align(x))]` 属性稳定**（RFC 1358）：为类型指定自定义对齐。
- **嵌套导入组**：`use std::{fs::File, io::Read, path::{Path, PathBuf}};`
- **match 分支允许以 `|` 开头**：竖排的多分支枚举更整齐。
  ```rust
  match x {
      | Foo::A
      | Foo::B => println!("AB"),
      | Foo::C => println!("C"),
  }
  ```
- **泛型参数位置的 `impl Trait` 首次稳定**：`fn open(path: impl AsRef<Path>)` 这类"参数位置"的抽象类型可用（返回位置的 `impl Trait` 在 1.26 才稳定）。

## Compiler
- LLVM 升级到 6；新增 `-C lto=val` 选项、`i586-unknown-linux-musl` 目标。

## Libraries
- Unix 上 `process::Command` 实现 `Send`。
- `UnsafeCell::into_inner` 改为安全函数（去掉 unsafe）。
- `Float::{from_bits,to_bits}` 进入 libcore；`Duration` 移入 libcore；为 `Component` 实现 `AsRef<Path>`；为 `Cursor<&mut Vec<u8>>` 实现 `Write`；提供 CloudABI 的 libstd。

## Stabilized APIs
- `Location::column` — 报错定位列号（1 起）。
- `ptr::NonNull` — 非 null 指针的正确抽象（此后逐步成为 API 标准件）。
- 可作常量表达式：`Duration::new`、`Duration::from_secs`、`Duration::from_millis`。

## Cargo
- `cargo new` 不再移除名字中的 rust/rs 前后缀；默认创建二进制 crate（以前默认库 crate）。

## Misc
- Rust by Example 随发行版附带。

## Compatibility Notes
- `net::lookup_host` 弃用。
- rustdoc 默认 markdown 渲染器切换为 pulldown。
- 借用检查修复：索引操作附近曾错误允许重叠借用（#47349），现已修正。
- 移除弃用的 unstable 属性 `#[simd]`。
