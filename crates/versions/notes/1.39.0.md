# Rust 1.39.0（2019-11-07）

> 来源：[releases.rs/docs/1.39.0](https://releases.rs/docs/1.39.0/)；演示：`cargo run -p versions --bin rustc_1_39_0`（外部 crate tokio 仅限本版演示 async/await）

## Language
- **async/await 稳定**：`async fn`、`async move {}`、`async {}` 与 `.await` 一并稳定——Rust 异步编程进入语言层面（`Future` 1.36 已入库，本版补上语法）。
- 函数/闭包/函数指针参数上可使用某些属性（`cfg`、`cfg_attr`、`allow`、`warn`、`deny`、`forbid` 等）。
- `match` 卫语句（if guard）中可对按 move 绑定的模式取共享引用（如 `nums` 被 move 绑定后 `nums.iter()` 隐式取引用）。

## Compiler
- 新增 tier 3 目标：`i686-unknown-uefi`、`sparc64-unknown-openbsd`。
- rustc 诊断代码片段会按终端宽度裁剪。
- 测试二进制新增 `--show-output` 参数，可打印成功测试的输出。

## Libraries
- `Vec::new` / `String::new` 成为 const fn。
- `LinkedList::new` 成为 const fn。
- `str::len`、`[T]::len`、`str::as_bytes` 成为 const fn。
- `abs`、`wrapping_abs`、`overflowing_abs` 成为 const。

## Stabilized APIs
- `Pin::into_inner` — 由 `Pin<P>` 取回 `P`
- `Instant::checked_duration_since` — 检查的时长差
- `Instant::saturating_duration_since` — 饱和的时长差

## Cargo
- 提供 version 的 git 依赖可发布。
- `--all` 改名为 `--workspace`，`--all` 被弃用。

## Misc
- rustdoc 可用 `-Clinker` 控制 doctest 编译用的链接器。

## Compatibility Notes
- 旧借用检查器能接受、NLL 拒绝的代码在 Rust 2018 成为硬错误（1.40 亦适用于 2015 edition）。
- rustdoc 运行测试现在要求 rustc 已安装且在同一目录。
- `try!` 宏发出弃用警告，推荐用 `?` 运算符。
- `asinh(-0.0)` 现在正确返回 `-0.0`。
