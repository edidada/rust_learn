# Rust 1.71.0（2023-07-13）

> 来源：[releases.rs/docs/1.71.0](https://releases.rs/docs/1.71.0/)；演示：`cargo run -p versions --bin rustc_1_71_0`

## Language
- **raw-dylib、`link_ordinal`、`import_name_type` 与 `-Cdlltool` 稳定化**：链接 Windows DLL 时无需导入库文件，且可直接指定导出序号。
- 把 Clippy 的 `drop_ref`/`forget_ref`/`drop_copy`/`forget_copy` lints 上提。
- 围绕 constrained vars 的类型推导更保守。
- **用 fulfillment 检查 Drop impl 兼容性**（对 `T: Drop` 的 impl 一致性判断更精确）。

## Compiler
- PlaceMention 中求值 place 表达式，`let _ =` 模式的借用检查更一致。
- Apple 目标新增 `--print deployment-target`。
- **稳定 `extern "C-unwind"` 等调用约定**：跨语言 unwind 明确 ABI；现有 `extern "C"` 在未来版本可能改变跨语言 unwind 行为。
- *-linux-musl 升级 musl 1.2.3（32 位系统启用 time64）。
- **稳定 `debugger_visualizer`**：嵌入 Natvis 等调试器可视化元数据。
- 默认启用 flatten-format-args；`Self` 尊重元组构造器隐私；niche 放置采用两策略择优。
- aarch64-apple-darwin 目标 CPU 改为 apple-m1；新增 tier 3 `x86_64h-apple-darwin`；`loongarch64-unknown-linux-gnu` 升 tier 2（含 host tools）。

## Libraries
- **重做递归 panic 处理**：unwinding 期间允许额外 panic（只要在 Drop impl 结束前被捕获），但 panic hook 内 panic 立即 abort。
- `From<&[T]> for Box<[T]>` 的 bound 放宽为 `T: Clone`。
- 移除 `mpsc::SendError<T>`/`TrySendError<T>` 的 `Error` impl 中多余的 `T: Send` bound。
- 修正 `alloc::realloc` 文档（size 不得超过 `isize::MAX`）。
- **文档化 `std::thread_local` 的 `const {}` 语法**（该语法 1.59 已稳定，但此前未在 release notes 提及）。

## Stabilized APIs
- `CStr::is_empty` — C 字符串是否为空（仅含 NUL）。
- `BuildHasher::hash_one` — 用给定 hasher 一次性哈希一个值，无需手写 Hasher 往返。
- `NonZeroI*::is_positive` / `NonZeroI*::is_negative`。
- `NonZeroI*::{checked_neg, overflowing_neg, saturating_neg, wrapping_neg}`。
- `Neg for NonZeroI*` / `Neg for &NonZeroI*` — 带符号非零整数取负。
- `From<[T; N]> for (T, ...)` — 数组转 N 元组（N ≤ 12）。
- `From<(T, ...)> for [T; N]` — N 元组转数组（N ≤ 12）。
- `windows::io::{AsHandle, AsSocket} for Box<T>/Rc<T>/Arc<T>`。
- 以下 API 现在可在 const 上下文使用：`<*const T>::read`、`<*const T>::read_unaligned`、`<*mut T>::read`、`<*mut T>::read_unaligned`、`ptr::read`、`ptr::read_unaligned`、`<[T]>::split_at`。

## Cargo
- Cargo.toml 中允许命名 debuginfo 选项；`cargo metadata` 输出 `workspace_default_members`；`cargo new`/`cargo init` 自动继承 workspace 字段。

## Rustdoc
- 新增 `rustdoc::unescaped_backticks` lint（行内代码的反引号未转义）；支持单波浪线删除线（`~new~` vs `~~old~~`）。

## Compatibility Notes
- **移除 `TypeId` 的 structural match**：在模式中使用常量 `TypeId` 的代码可能被破坏（log crate 用户需 ≥ v0.4.18）。
- 新增 `sysroot` crate 表示标准库 crates（不影响 stable 用户）。
- Cargo 在 rustup 下优化：检测到会运行 rustup 代理时直接使用底层二进制。
- 查询包名时只尝试原名、全连字符、全下划线三种拼写（不再逐组合尝试，减少 crates.io 请求）。
- Cargo 拒绝在 `[env]` 配置表中设置 `RUSTUP_HOME`/`RUSTUP_TOOLCHAIN`。
