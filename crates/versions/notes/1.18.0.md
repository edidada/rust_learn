# Rust 1.18.0（2017-06-08）

> 来源：[releases.rs/docs/1.18.0](https://releases.rs/docs/1.18.0/)；演示：`cargo run -p versions --bin rustc_1_18_0`

## Language
- **`pub(restricted)` 稳定**（RFC 1422）：`pub(crate)`、`pub(in path)` 限定可见性。
- `#![windows_subsystem]` 属性稳定（RFC 1665）：Windows 上隐藏控制台窗口等。
- trait 对象类型解析重构：宏内 `ty` 接受 `Write + Send`；支持尾部 `+`。
- `0e+10` 成为合法浮点字面量。
- 给生命周期参数绑定 `'static` 会警告。
- **无 repr 属性（或 #[repr(Rust)]）的结构体/元组/枚举变体字段自动重排以减小填充**。

## Compiler
- `--emit mir`；trivial 函数 LLVM IR 改进；编译提速 15%~20%；panic 回溯格式改进。

## Libraries
- `Vec::from_iter` 对未消费的 `vec::IntoIter` 特化（原 Vec 免重分配重组）；HashMap 桶接口简化提速；`Vec::from_elem` 走 calloc；插入排序优化；`AtomicBool::fetch_nand` 优化；修复 `fs::create_dir_all` 竞态。

## Stabilized APIs
- `Child::try_wait`（非阻塞等待子进程）
- `HashMap::retain` / `HashSet::retain`
- `PeekMut::pop`
- `TcpStream::peek` / `UdpSocket::peek` / `peek_from`

## Cargo
- Pijul VCS 支持（`cargo new --vcs pijul`）；`cargo build --bins`/`--tests`；Android 构建支持；haiku 支持。

## Misc
- rustdoc 可用 pulldown-cmark；rustdoc 接受行首 `#`。

## Compatibility Notes
- format! 的 0 旗标行为变化（零在符号后、# 前缀后）。
- 结构体字段重排使对无 repr 结构体 transmute 更可能出事（本就 UB）。
- 重叠固有 impl 成硬错误；PartialOrd 与 Ord 必须一致；`--emit=asm,llvm-ir` 输出两个文件；返回 Self 且大小不定的函数不再可用；MinGW 换 pthreads 版带来的链接顺序/本机库变化。
