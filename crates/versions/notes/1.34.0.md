# Rust 1.34.0（2019-04-11）

> 来源：[releases.rs/docs/1.34.0](https://releases.rs/docs/1.34.0/)；演示：`cargo run -p versions --bin rustc_1_34_0`

## Language
- `#[deprecated = "reason"]`（简写形式，等价 `#[deprecated(note="reason")]`）。
- 过程宏可在 `#[attr()]`/`#[attr[]]`/`#[attr{}]` 中接收 token 流。
- `extern crate self as foo;` 可把自身 crate 根导入 extern prelude。

## Compiler
- 新增 riscv64 目标；`-C linker-plugin-lto`（跨 C/C++ FFI 边界的 LLVM LTO）；powerpc64-unknown-freebsd。

## Libraries
- `HashMap<K,V,S>`/`HashSet<T,S>` 基本方法移除 trait bound（无 `Hash` 也能建迭代器）；`BinaryHeap<T>` 同理移除 `Ord` bound。
- `overflowing_neg`、`wrapping_neg` const fn 化；`str` 索引泛型化为 `SliceIndex<str>`；`str::trim_*` 加 `#[must_use]`。
- `checked_pow/saturating_pow/wrapping_pow/overflowing_pow` 全数型可用。

## Stabilized APIs
### std & core
- `Any::type_id`、`Error::type_id`、`atomic::AtomicI8/I16/I32/I64/U8/U16/U32/U64`
- `convert::Infallible`、`convert::TryFrom`、`convert::TryInto`
- `iter::from_fn`、`iter::successors`
- `num::NonZeroI8/I16/I32/I64/I128/Isize`
- `slice::sort_by_cached_key`
- `str::escape_debug`、`str::escape_default`、`str::escape_unicode`
### std
- `Instant::checked_add/checked_sub`、`SystemTime::checked_add/checked_sub`

## Cargo
- 可使用替代（alternative）registries。

## Misc
- 文档测试可用 `?` 而不用手写 `fn main() -> Result<(), _>`。

## Compatibility Notes
- `Command::before_exec` 将被 unsafe 的 `Command::pre_exec` 替换（1.37 弃用）。
- **`ATOMIC_{BOOL,ISIZE,USIZE}_INIT` 弃用**（static 中已可用 const fn 构造）。
