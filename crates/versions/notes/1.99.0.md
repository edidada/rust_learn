# Rust 1.99.0（beta，未正式发布）

> 来源：[releases.rs/docs/1.99.0](https://releases.rs/docs/1.99.0/)；演示：`cargo run -p versions --bin rustc_1_99_0`
>
> 页面状态：**Unreleased, branched from master（beta）**；Branched from master on: 14 August, 2026；Will be stable on: 1 October, 2026。以下为页面列出的已合入 PR（尚未定稿的 release notes），照实记叙。

## Language
- 稳定 **c-variadic 函数定义**（`c_variadic_naked_functions` 相关；接续 1.91/1.93 的变参声明路线，这次是定义）。
- 稳定 `fs_set_times`。
- 稳定 `String::from_utf8_lossy_owned`。
- `PinSafePointer` trait 引入，泛化 `PinCoerceUnsized`。
- 允许不经过 `get()` 直接访问 `UnsafeCell` 内容（`invalid_reference_casting` lint 相应放宽）。
- `#[diagnostic::opaque]` 属性：隐藏宏的 backtrace。
- 全局 target feature 附加到 module-level assembly。
- Step 新增 `forward/backward_overflowing`（使 RangeInclusive 循环可优化）。
- `IntoIterator for [&[mut]] Box<[T; N], A>`。
- `Iterator` 源：`core` 为 `StepBy` 实现 `FusedIterator`。
- `Type = Type`/`Type == Type` where-bound 等同的后续清理不在本列（略）。

## Compiler
- 把 `-Ctarget-cpu` 转成 AVR、AMDCGN、NVPTX 的 target-modifier。
- GNU 目标全部启用 `static_position_independent_executables`。
- 对无效 POSIX 符号定义 lint（延续 1.98 的 runtime symbol lints）。
- 浅解析 ty/const vars 到 root vars（类型求解器优化）。
- 泛型参与的 const-eval 查询提前 abort。
- semicolon lint 拆分：`semicolon_in_expressions_from_macros` 也对非本地宏 lint。
- 升级到 **LLVM 23**。
- `riscv64-unknown-linux-musl` 升 Tier 2（with host tools）。
- hermit/fs 返回 `unsupported()` 而非 `from_raw_os_error(22)`。
- 为 compiler-builtins 做 beta backport（#162820）。

## Rustdoc / rustfmt
- 新 `unused_footnote_definition` rustdoc lint。
- doctest 过滤不再考虑 `doc(cfg())`。
- 无效 doc 属性用在宏调用上也告警。
- rustfmt 格式化 `cfg_select!`。

## Libraries / 文档
- NonNull 布局保证文档化；分配可只读的文档化；`Box::leak` 提醒避免 "unleak"。
- runtime symbols：`() ` 仅在期望 `!` 时算可疑（#159513）。

> ⚠ 本版尚未发布（beta），且本仓库工具链为 1.98，演示代码仅记叙不调用任何超期 API。
