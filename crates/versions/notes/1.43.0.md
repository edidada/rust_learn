# Rust 1.43.0（2020-04-23）

> 来源：[releases.rs/docs/1.43.0](https://releases.rs/docs/1.43.0/)；演示：`cargo run -p versions --bin rustc_1_43_0`

## Language
- 修复 `&{number}`（如 `&1.0`）二元运算时类型推断不正确的问题。
- `#[cfg()]` 等属性可用于 if 表达式。
- **语法仅变更**（语义仍拒绝）：`type Foo: Ord;` 语法允许；关联/extern item 的默认性（defaultness）可与声明合并解析；所有 fn 上下文允许 `self`；合并 fn 语法；`item` 宏片段可插入 traits/impls/extern block（如 `mac_trait! { fn foo() {} }` 可展开为 `trait T { fn foo() {} }` 的 item 段）。
- 无稳定的新语言特性。

## Compiler
- 多个 lint 旗标可互相覆盖：`-D unused -A unused-variables` 允许列出的除外全部拒绝（后传的覆盖前者）。
- windows-gnu 下优先用系统 MinGW 库而非捆绑库。
- rustc JSON 输出的错误/警告有缓冲。

## Libraries
- `Arc<[T; N]>`/`Box<[T; N]>`/`Rc<[T; N]>` 实现 `TryFrom<Arc<[T]>>` 等（仅 N 在 0..=32 时可用）。
- **关联常量直接用**：浮点/整数可直接写 `u32::MAX`、`f32::NAN`，无需 `use std::u32;`。
- `u8::is_ascii` 成为 const。
- `String` 实现 `AsMut<str>`。
- `std`/`core` 新增 `primitive` 模块，re-export 原始类型（宏里避免被遮蔽）。
- 放宽了 `HashMap`/`HashSet` 的 trait 约束。
- `string::FromUtf8Error` 实现 `Clone` + `Eq`。

## Stabilized APIs
- `Once::is_completed` — 初始化是否已发生
- `f32::LOG10_2` / `f32::LOG2_10` — 常量 log10(2)、log2(10)
- `f64::LOG10_2` / `f64::LOG2_10` — 同上（f64）
- `iter::once_with` — 按需调用一次闭包元素

## Cargo
- `.cargo/config` 可配置 `[profile]`（或环境变量）。
- 运行集成测试/基准时设 `CARGO_BIN_EXE_<name>` 为对应二进制路径。

## Misc
- `const_err` lint 中与 const 求值无关的检查移到 `unconditional_panic` 和 `arithmetic_overflow`。

## Compatibility Notes
- `assert!` 尾随多余语法成为硬错误（1.36 起是警告）。
- 修复 `Self` 类型推断问题：原有一些错误接受的代码现在报错。

## Internal Only
- rustc 内部性能提升（各组件 `opt-level=3` 错改善 drop 代码生成等）；对用户无直接可见收益。
