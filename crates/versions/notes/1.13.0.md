# Rust 1.13.0（2016-11-10）

> 来源：[releases.rs/docs/1.13.0](https://releases.rs/docs/1.13.0/)；演示：`cargo run -p versions --bin rustc_1_13_0`

## Language
- **`?` 运算符稳定化**（RFC 0243）：错误传播的简洁写法，取代 `try!` 宏。
- 宏可用于类型位置（RFC 873）；语句上的属性稳定化（RFC 0016）。
- 修复空元组结构体/变体的 `#[derive]`；修复 `if` 条件中的生命周期规则；不加载/解析被 cfg 排除的非内联模块。

## Compiler
- `-C link-arg`；移除旧 AST 后端；armv7 Linux 默认不开 NEON；RLib 元数据格式改进显著缩小体积；默认 `RUST_MIN_STACK` 16MiB；`#[repr]` 冲突警告等。

## Diagnostics
- 宏回溯替换为带标注的本地使用；lifetime 错误明确指出临时值；`use self` 建议；类型参数遮蔽基本类型时更具体。

## Compile-time Optimizations
- HIR 哈希预计算；`#[inline]` 函数只被引用到的 codegen 单元实例化（导出大量 inline 函数的 crate 收益大）；默认 HashSet 创建零分配等。

## Stabilized APIs
- `i32::checked_abs` / `wrapping_abs` / `overflowing_abs`（以及其他原始整型）
- `RefCell::try_borrow` / `try_borrow_mut`

## Libraries
- **`assert_ne!` / `debug_assert_ne!`** 新增。
- `AsRef<[T]>` 实现于 `slice::Iter`；`CoerceUnsized` 实现于 Cell/RefCell/UnsafeCell；char 的转换 trait；`DirEntry`/path 组件实现 Debug；`ErrorKind` 补齐 trait 实现。
- **SipHasher 弃用，改用 `DefaultHasher`**。
- FreeBsd 用 arc4rand；条件变量改用单调时钟；CString 去除多余 0 终止增长等。

## Cargo
- curl/OpenSSL 安全修复；`cargo --all-features`；`--message-format`；per-target rustflags 等。

## Tooling / Misc
- rustdoc `--sysroot`；s390x 支持；compiler-rt crate 化（compiler-builtins）。

## Compatibility Notes
- SipHasher 弃用；**fn item 类型 transmute 到指针宽度类型默认拒绝**（RFC 401）；对 extern static 的安全访问发弃用警告；`sum`/`product` 继承溢出检查；禁止自定义名为 `macro_rules` 的宏。
