# Rust 1.57.0（2021-12-02）

> 来源：[releases.rs/docs/1.57.0](https://releases.rs/docs/1.57.0/)；演示：`cargo run -p versions --bin rustc_1_57_0`

## Language
- `#[derive]` 之后可以放宏属性，它们看到的是未展开 cfg 时的原始输入。
- 表达式里允许花括号宏：`m!{ .. }.method()`、`m!{ .. }?`。
- **常量求值中允许 panic**：const fn 可在（编译期）失败时 panic（为 const panic::! 铺路）。
- dead-code 分析忽略 derive 出来的 Clone / Debug 实现。

## Compiler
- vtable debuginfo 更准确。
- 新增 tier 3：`armv6k-nintendo-3ds`、`armv7-unknown-linux-uclibceabihf`、`m68k-unknown-linux-gnu`、SOLID 系列（aarch64-kmc-solid_asp3 等）。

## Libraries
- `Vec::leak` 减少分配与拷贝。
- `Ordering` 加 `#[repr(i8)]`。
- 优化 `File::read_to_end` / `read_to_string`。
- 更新到 Unicode 14.0。
- **大量函数标 `#[must_use]`**：忽略返回值会产生告警，帮助发现"以为就地修改其实是返回新值"的错误。

## Stabilised APIs
- `[T; N]::as_mut_slice` / `[T; N]::as_slice` — 数组到切片（注意 `[T]::as_flattened` 早已有）
- `collections::TryReserveError`
- `HashMap::try_reserve` / `HashSet::try_reserve` / `String::try_reserve` / `String::try_reserve_exact` / `Vec::try_reserve` / `Vec::try_reserve_exact` / `VecDeque::try_reserve` / `VecDeque::try_reserve_exact` — 预留容量失败得 Err 而非 abort
- `Iterator::map_while` / `iter::MapWhile` — 按谓词短路 map，遇 None 结束
- `proc_macro::is_available` — 判断是否在 proc-macro 上下文运行
- `Command::get_program` / `get_args` / `get_envs` / `get_current_dir` / `CommandArgs` / `CommandEnvs`
- 以下 API 可用于 const 上下文：`hint::unreachable_unchecked`

## Cargo
- 稳定 custom profiles（自定义 profile，如 `[profile.web]`）。

## Compatibility notes
- dead-code 分析忽略 derive Clone/Debug 会让设置 `#![deny(dead_code)]` 的构建 break。
