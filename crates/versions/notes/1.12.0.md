# Rust 1.12.0（2016-09-29）

> 来源：[releases.rs/docs/1.12.0](https://releases.rs/docs/1.12.0/)；演示：`cargo run -p versions --bin rustc_1_12_0`

## Highlights
- **rustc 改经自家中间表示 MIR 翻译到 LLVM IR**：翻译层大幅简化，为直接在 MIR 上做新优化铺路。
- **全新更可读的错误格式**，并提供机器可读的 JSON 错误输出（`--error-format=json`）供 IDE 使用。

## Compiler
- MIR 翻译落地；`--print target-list` 显示 Rust 目标名；`--print target-cpus/target-features/relocation-models/code-models`；mips-linux-gnu 默认硬件浮点；新增三个 ARM MUSL 目标。

## Diagnostics
- 引用类型在错误信息中以自然语言描述（不再叫 "&-ptr"）；未知数值类型显示为 `{integer}`/`{float}`。

## Language
- `macro_rules!` 可嵌套调用；元变量卫生化；`tt` 匹配器可正确重解析；`stmt` 匹配器修复；cfg_attr 作用于 path 属性。

## Stabilized APIs
- `Cell::as_ptr` / `RefCell::as_ptr`
- `IpAddr::is_unspecified` / `is_loopback` / `is_multicast`；`Ipv4Addr::is_unspecified`；`Ipv6Addr::octets`
- `LinkedList::contains` / `VecDeque::contains`
- `ExitStatusExt::from_raw`
- `Receiver::recv_timeout` 与 `RecvTimeoutError`
- `BinaryHeap::peek_mut` 与 `PeekMut`
- `iter::Product` / `iter::Sum`（trait 本体）
- `OccupiedEntry::remove_entry` / `VacantEntry::into_key`

## Libraries
- `format!` 等宏允许同一参数以多种风格格式化（如 `{0} {0:x}`）。
- `Option` 实现 `From`（从内部类型）；`Cell`/`RefCell`/`UnsafeCell` 同样。
- `RwLock` 读计数溢出会 panic；各类 Drain 协变化；`Cow<str>` 实现 FromIterator。
- Entry 系列实现 Debug；`String` 实现 `AddAssign`；变参 extern fn 指针实现常用 trait；Unicode 更新到 9.0；env 迭代器实现 DoubleEndedIterator。

## Cargo
- 本地 registry 镜像；命令别名；`opt-level="s"/"z"`；`RUSTDOCFLAGS`；`cargo new --lib` 等。

## Performance
- `panic::catch_unwind` 优化且入口不再访问 TLS。

## Tooling / Misc
- 测试二进制支持 `--test-threads`；超过 60 秒的测试发警告；发布包含 rust-src 源码组件；可构建于 LLVM 3.9。

## Compatibility Notes
- Windows OsStr 未配对代理转义改小写；指定 precision 时 fill/align/width 不再被忽略；字符串 Debug 不再转义所有非 ASCII。
