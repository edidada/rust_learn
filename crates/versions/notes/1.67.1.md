# Rust 1.67.1（2023-02-09）

> 来源：[releases.rs/docs/1.67.1](https://releases.rs/docs/1.67.1/)；演示：`cargo run -p versions --bin rustc_1_67_1`

Patch 版本，内容很少，全部照实记录。

## Changes
- 修复与 thin archives（稀疏归档）的互操作问题。
- 修复编译器构建过程中的一个内部错误。
- 把 `clippy::uninlined_format_args` 降级到 pedantic 级别（不再默认提示 `format!("{}", x)` 改写成内联 `{x}`）。
