# Rust 1.22.0（2017-11-22）

> 来源：[releases.rs/docs/1.22.0](https://releases.rs/docs/1.22.0/)；演示：`cargo run -p versions --bin rustc_1_22_0`

## Language
- `non_snake_case` lint 允许 extern no-mangle 函数。
- Unicode 转义中允许下划线（如 `\u{1_F_600}` 这类分组写法）。
- **数字类型支持 `T op= &T`**：如 `let mut x = 2; x += &8;`（算出值即可，不必先解引用）。
- 实现 `Drop` 的类型现在可用于 `const`/`static` 的类型中。

## Compiler
- 调试构建默认 16 个 codegen units，且 debug 时不跨 codegen 单元内联——缩短编译时间。
- ARMv6 启用严格内存对齐；移除 PNaCl 目标 `le32-unknown-nacl`。

## Libraries
- `Box<dyn Error>` 实现 `From<Cow<str>>`。
- `std::mem::Discriminant` 保证 `Send + Sync`。
- `fs::copy` 在 NTFS 上返回主流长度；正确检测 `Instant += Duration` 溢出。
- 为 `&mut H`、`Box<H>` 实现 `Hasher`；为 `SplitWhitespace` 实现 `Debug`。
- **`Option<T>` 实现 `Try`**：`Option` 类型现在可以用 `?` 传播（之前只支持 `Result`）。

## Stabilized APIs
- （本版无 Stabilized APIs 条目；核心语言变化为 `T op= &T` 与 `Option` 上的 `?`。）

## Cargo
- `examples` 子目录中的多文件示例（含 `main.rs`）也会被构建。
- `Cargo.lock` 中 `[root]` 改为 `[package]`，旧格式仍可读并可用 `cargo update` 升级。
- 支持 vendoring git 仓库。

## Misc
- Apple 平台可用 libbacktrace；doc-comment 代码围栏的 `compile_fail` 属性正式稳定。

## Compatibility Notes
- rustc 能针对的最低 Android 版本从 2.3 提高到 4.0。
- `T op= &T` 破坏了部分类型推断场景。
