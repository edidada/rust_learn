> 来源：[releases.rs/docs/1.31.1](https://releases.rs/docs/1.31.1/)；演示：`cargo run -p versions --bin rustc_1_31_1`

## Changes
- 修复 powerpc-unknown-netbsd 上 Rust 构建失败的问题。
- 修复 RLS 的跳转定义（go-to-definition）失效。
- 修复 RLS 悬停（hover）时的无限循环。
