# Rust 1.8.0（2016-04-14）

> 来源：[releases.rs/docs/1.8.0](https://releases.rs/docs/1.8.0/)；演示：`cargo run -p versions --bin rustc_1_8_0`

## Language
- **复合赋值运算符可重载**（RFC 953）：实现 `AddAssign`/`SubAssign`/`MulAssign`/`DivAssign`/`RemAssign`/`BitAndAssign`/`BitOrAssign`/`BitXorAssign`/`ShlAssign`/`ShrAssign` 即可用 `+=` 等。
- 空结构体可用花括号定义：`struct Foo { }`（RFC 218）。

## Libraries
- **时间 API 稳定化**：`time::Instant`（`now`/`duration_since`/`elapsed`）、`time::SystemTime`（`now`/`duration_since`/`elapsed`、各种 Add/Sub impl）、`SystemTimeError`（`duration`）、`UNIX_EPOCH`。`duration_since` 改名自 `duration_from_earlier`。
- `Ref::map` / `RefMut::map`（RefCell 内容的投影）。
- `str::encode_utf16`（改名自 utf16_units）、`EncodeUtf16`。
- `ptr::drop_in_place`。
- 上述算术赋值 trait 全部稳定。
- `write!`/`writeln!` 对无法格式化的参数正确报错。
- 32 位 Linux 上 I/O 函数支持大文件。
- Unix `os::raw::unix` 等平台原始模块弃用（建议 libc crate）；`MetadataExt` 返回加宽整型。
- btree_set 迭代器协变化；原子 load/store 不再 volatile；mpsc 类型实现 Debug。

## Performance
- 哈希函数内联带来 3% 编译提速；jemalloc 符号去前缀（rustc 编译提速 6%）。

## Misc
- 32 位 MSVC 实现展开（unwinding）；`--print targets`/`--print cfg`；错误格式列缺失变体等。

## Cargo
- `cargo init` 在当前目录建项目；`[term]` 的 verbose/color 配置键；环境变量可覆盖配置（如 `CARGO_BUILD_JOBS`）；target 特定依赖支持 cfg 语法（RFC 1361）；`build.target` 配置。

## Compatibility Notes
- `-Z` 不稳定 flag 逐步退出 stable 通道。
- 空枚举不能用 `Variant(..)` 匹配（1.6 警告后转错误）。
- `MetadataExt` 返回加宽整型；文件系统来源的模块不能出现在任意块中；`--cfg` 严格按标识符解析。
- Unix 栈溢出改为 abort 而非 SIGSEGV；命令行参数含内嵌 NUL 时报错。
- 元组/单元枚举变体归入类型命名空间；Windows staticlib 产物改为 `.lib`。
