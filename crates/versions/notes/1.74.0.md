# Rust 1.74.0（2023-11-16）

> 来源：[releases.rs/docs/1.74.0](https://releases.rs/docs/1.74.0/)；演示：`cargo run -p versions --bin rustc_1_74_0`

## Language
- 规定 `std::mem::Discriminant<T>` 不依赖 T 中的任何生命周期。
- **用 `private_interfaces` 和 `private_bounds` 替换 `private_in_public` lint**（RFC 2145）。
- **允许显式 `#[repr(Rust)]`**。
- 闭包字段捕获：不依赖 packed 字段的对齐。
- async blocks 启用 MIR-based drop-tracking。
- 稳定 `impl_trait_projections`（`impl Trait` 关联类型的类型内定义）。

## Compiler
- 稳定 `+bundle` 与 `+whole-archive` 链接修饰符的组合；稳定 `--print KIND=PATH` 的 PATH 选项。
- 为 *-apple-ios-macabi 启用 ASAN/LSAN/TSAN；`loongarch64-unknown-none*` 升 tier 2；新增 tier 3 `i686-pc-windows-gnullvm`。

## Libraries
- `From<OwnedFd/OwnedHandle>` for ChildStdin/out/err。
- `From<{&,&mut}[T; N]> for Vec<T> where T: Clone`；`From<[T; N]> for Rc<[T]>`/`Arc<[T]>`。
- 为 IP 地址实现 `Step`（可用于 Range 迭代）。
- `impl TryFrom<char> for u16`。
- **稳定 `io_error_other`（`io::Error::other`）**。
- **稳定 `Saturating` 类型**。
- **稳定 `const_transmute_copy`**。
- OsString/OsStr 的编码字节访问（`as_encoded_bytes` 等）。

## Stabilized APIs
- `core::num::Saturating` — 饱和运算包装整数类型。
- `impl From<io::Stdout> for std::process::Stdio` / `impl From<io::Stderr> for std::process::Stdio` — 把当前进程句柄作为子进程 stdio。
- `impl From<OwnedHandle> for std::process::Child{Stdin,Stdout,Stderr}`。
- `impl From<OwnedFd> for std::process::Child{Stdin,Stdout,Stderr}`。
- `std::ffi::OsString::from_encoded_bytes_unchecked` / `OsString::into_encoded_bytes`。
- `std::ffi::OsStr::from_encoded_bytes_unchecked` / `OsStr::as_encoded_bytes`。
- `std::io::Error::other` — 构造"其他错误"包装任意 E。
- `impl TryFrom<char> for u16` — 码点转 u16（BMP 内才能成功）。
- `impl<T: Clone, const N: usize> From<&[T; N]> for Vec<T>` / `From<&mut [T; N]> for Vec<T>`。
- `impl<T, const N: usize> From<[T; N]> for Arc<[T]>` / `for Rc<[T]>`。
- 以下 API 现在可在 const 上下文使用：`core::mem::transmute_copy`、`str::is_ascii`、`[u8]::is_ascii`。

## Cargo
- **Cargo.toml 稳定 `[lints]` 表**：项目级统一配置 lint 级别。
- 稳定 `credential-process` 与 `registry-auth`；稳定 `--keep-going` 构建旗标。
- `--help` 输出着色；`cargo clean` 新增 `--dry-run`（别名 `-n`）与汇总行；`cargo update --package` 支持位置参数，`--aggressive` 更名 `--recursive`；pkgid 允许版本前缀消歧；`.cargo/config.toml` 按优先级合并列表；支持 `target.'cfg(..)'.linker`。

## Rustdoc
- 支持警告块（`<warning>` 等)；搜索支持类型参数；具体类型定义中显示内部 enum/struct。

## Compatibility Notes
- 提高最低支持的 Apple OS 版本。
- **`Cell::swap` 在 Cells 部分重叠时 panic**。
- `--extern` 拒绝非法 crate 名。
- 不再解析可能被 dyn 内建 impl 遮蔽的泛型 impl。
- 新的 `From<{&,&mut}[T; N]> for Vec<T>` 可能引起过度泛型代码的推断失败（需显式类型标注）。
