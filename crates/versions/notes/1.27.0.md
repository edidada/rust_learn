# Rust 1.27.0（2018-06-21）

> 来源：[releases.rs/docs/1.27.0](https://releases.rs/docs/1.27.0/)；演示：`cargo run -p versions --bin rustc_1_27_0`

## Language
- `proc` 从保留关键字列表移除，可作普通标识符。
- **`dyn Trait` 语法稳定**：裸 trait 语法的新名字，`&Trait == &dyn Trait`、`Box<Trait> == Box<dyn Trait>`；与 `impl Trait` 对照可读性更好。
- 泛型参数上的属性稳定：`fn foo<#[lifetime_attr] 'a, #[type_attr] T: 'a>() {}`。
- **`#[must_use]` 可用于函数**：返回值被丢弃时警告。

## Compiler
- 新增 `armv5te-unknown-linux-musleabi` 目标。

## Libraries
- **x86/x86_64 的 SIMD（`std::arch` intrinsics）稳定**，含 `is_x86_feature_detected!` 宏与 `#[target_feature(enable="")]`。
- `[u8]/f32/f64` 的大量方法下放 libcore；`ops::{Shl,ShlAssign,Shr}` 的泛型 `Rhs` 默认为 `Self`。
- `str::replace` 加 `#[must_use]`；`Clone::clone`、`Iterator::collect`、`ToOwned::to_owned` 也加 `#[must_use]`。

## Stabilized APIs
- `DoubleEndedIterator::rfind`、`DoubleEndedIterator::rfold`、`DoubleEndedIterator::try_rfold`
- `Duration::from_micros`、`Duration::from_nanos`、`Duration::subsec_micros`、`Duration::subsec_millis`
- `HashMap::remove_entry`
- `Iterator::try_fold`、`Iterator::try_for_each`
- `NonNull::cast`
- `Option::filter`
- `String::replace_range`、`Take::set_limit`
- `hint::unreachable_unchecked`
- `os::unix::process::parent_id`
- `ptr::swap_nonoverlapping`
- `slice::rsplit_mut`、`slice::rsplit`、`slice::swap_with_slice`

## Cargo
- cargo-metadata 增补字段；新增 `--target-dir`；预告 2018 edition 的目标自动推断（可提前用 `autobins=false` 等关闭）；缓存 rustc 信息（`CARGO_CACHE_RUSTC_INFO=0` 可禁）。

## Misc
- 《The Rustc book》加入官方文档；doc.rust-lang.org 全部书籍可搜索。

## Compatibility Notes
- 不能再直接调用 `core` 上的 `CharExt/StrExt`（`"".is_empty()` 照常）。
- 原子类型的 Debug 输出只打印内部值（`AtomicBool::new(true)` → `true`）。
- `repr(align(N))` 上限改为 2²⁹；`Error::description()` 软弃用。
