# Rust 1.66.1（2023-01-10）

> 来源：[releases.rs/docs/1.66.1](https://releases.rs/docs/1.66.1/)；演示：`cargo run -p versions --bin rustc_1_66_1`

Patch 版本，内容很少，全部照实记录。

## Changes
- **Cargo 对 git URL 的 SSH host key 增加校验（CVE-2022-46176）**：修复 MITM 攻击者可截获/篡改凭据的安全漏洞——此前 Cargo 通过 SSH 拉取依赖时未校验主机密钥。
