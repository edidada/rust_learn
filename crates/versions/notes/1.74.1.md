# Rust 1.74.1（2023-12-07）

> 来源：[releases.rs/docs/1.74.1](https://releases.rs/docs/1.74.1/)；演示：`cargo run -p versions --bin rustc_1_74_1`

Patch 版本，内容很少，全部照实记录。

## Changes
- 解决 LLVM 中偶发的 `STATUS_ACCESS_VIOLATION`（虚假访问违例）。
- 澄清 `std::mem::discriminant` 的保证。
- 修复若干与子类型（subtyping）相关的回归。
