# Rust 1.44.1（2020-06-18）

> 来源：[releases.rs/docs/1.44.1](https://releases.rs/docs/1.44.1/)；演示：无（patch 版仅 bugfix，不配演示）

## 说明
patch 版本，无语言/库稳定化内容，仅以下修复项。

## Patch Fixes
- rustfmt 再次接受 `cfg_attr` 中的 `rustfmt_skip`。
- Apple 平台不再对可执行文件名做哈希，修复 backtrace 无法对应。
- 修复 macOS 上查找 backtrace 时的崩溃。
- Clippy 将 lint 等级正确应用至不同文件。

## 演示对照
patch 版无新增稳定 API，不提供演示。
