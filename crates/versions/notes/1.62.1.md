# Rust 1.62.1（2022-07-19）

> 来源：[releases.rs/docs/1.62.1](https://releases.rs/docs/1.62.1/)；演示：`cargo run -p versions --bin rustc_1_62_1`

## Patch（此为补丁版本）
- 修编译器与标准库若干近期回归，并缓解 Intel SGX CPU 漏洞：
  - 编译器修复涉及 `impl Trait` 返回类型的**不健全函数强转**（unsound coercions）。
  - 编译器修复 async fn 生命周期的增量编译 bug。
  - Windows 同步读写在同步文件上有 fallback（重叠 I/O fail 时退到同步）。
  - `x86_64-fortanix-unknown-sgx` 目标缓解 MMIO 旧数据漏洞（advisory INTEL-SA-00615）。
