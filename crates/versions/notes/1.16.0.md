# Rust 1.16.0（2017-03-16）

> 来源：[releases.rs/docs/1.16.0](https://releases.rs/docs/1.16.0/)；演示：`cargo run -p versions --bin rustc_1_16_0`

## Language
- `dead_code` lint 覆盖类型别名；不可栖息枚举（无变体）不再允许通配匹配。

## Compiler
- **`--emit=metadata`**：只产出 .rmeta 元数据文件（供 Rust Language Service 等做元数据级构建）。
- 基于 Levenshtein 的拼写建议覆盖大多数场景（配合解析错误大修，诊断系统性提升）；transmute 对齐修复；不再给出"考虑显式生命周期"的不准确建议。

## Stabilized APIs
- `VecDeque::truncate` / `resize`
- `String::insert_str` / `split_off`
- `Duration::checked_add` / `checked_sub` / `checked_div` / `checked_mul`
- `str::replacen` / `repeat`
- `SocketAddr::is_ipv4` / `is_ipv6`；`IpAddr::is_ipv4` / `is_ipv6`
- `Vec::dedup_by` / `dedup_by_key`
- `Result::unwrap_or_default`
- `<*const T>::wrapping_offset` / `<*mut T>::wrapping_offset`
- `CommandExt::creation_flags`、`File::set_permissions`

## Libraries
- `[T]::binary_search(_by_key)` 参数改按 `Borrow` 传入。
- std 全部公开类型实现 Debug；`IpAddr` 实现 From<Ipv4Addr>/From<Ipv6Addr>；`Ipv6Addr` 实现 From<[u16; 8]>。
- Windows 控制台 Ctrl-Z 结束 Stdin 读；LineWriter 部分写修复；&str 切片越界 panic 信息更具体。
- `TcpListener::set_only_v6` 弃用（std 无法实现该功能）。
- `writeln!()` 同 `println!()` 一样可无参换行；Result 实现 Sum/Product。
- `Duration` 实现 Sum；`String` 实现 ToSocketAddrs。

## Cargo
- **`cargo check`**：只做类型检查不产二进制（大版本常用功能）。
- crates.io 显示 CI badge 与分类；profile 的 debug 接受整数（映射 `-C debuginfo`）；`build --all`/`doc --all`；dep-info 输出。

## Misc
- rustdoc `--sysroot`；armv7-android 关 NEON；Redox OS 可编译 std；SPARC/PTX 三级支持。

## Compatibility Notes
- 不可栖息枚举通配匹配移除；1.15 意外允许的不可栖息类型引用匹配移除；dead_code 覆盖类型别名；Windows Ctrl-Z 行为变化；`self` 导入语义清理；**生命周期省略（elision）重新实现**（几乎全兼容，封堵若干漏洞）。
