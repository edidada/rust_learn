# Rust 1.5.0（2015-12-10）

> 来源：[releases.rs/docs/1.5.0](https://releases.rs/docs/1.5.0/)；演示：`cargo run -p versions --bin rustc_1_5_0`

约 700 处变更。

## Highlights
- **大波稳定化 API**（几乎全部为 Path / Formatter / Iterator / BinaryHeap / VecDeque / slice 系列），其中教学上常用者：
  - `BinaryHeap::from`、`into_sorted_vec`、`into_vec`
  - `Path::canonicalize`/`exists`/`is_dir`/`is_file`/`metadata`/`read_dir`/`read_link`/`symlink_metadata`
  - `Iterator::cmp/eq/ge/gt/le/lt/ne/partial_cmp`
  - `Formatter` 的 width / precision / sign / fill / alternate 等格式控制
  - `Vec::resize`、`VecDeque::insert`、`as_slices`、`shrink_to_fit`、`swap_remove_*`
  - `slice::split_first(_mut)`、`split_last(_mut)`
  - `char::from_u32_unchecked`、`Utf8Error::valid_up_to`、`str::match_indices`/`rmatch_indices`、`fs::canonicalize`
  - `Condvar::wait_timeout`
  - `string::ParseError`
- `cargo install` 落地：crates.io 上的二进制可安装到 `~/.cargo/bin`，`cargo-foo` 可作为 `cargo foo` 子命令运行。
- 通配符依赖发布开始警告（1.6 起拒绝）。

## Breaking Changes
- dropck 不再依赖 parametricity 的规则调整。
- `Box`/`Rc`/`Arc` 新增 `AsRef`/`AsMut` 实现，与内部类型同名方法可能产生解析冲突。
- Rc/Arc、方法 well-formedness、超 trait 含 Self 的对象安全等若干健全性修复。
- `#[derive(Show)]` 移除；`#[inline]`/`#[repr]` 位置限制；`#[no_debug]`/`#[omit_gdb_pretty_printer_section]` 特性门控。
- 无符号取负从警告/提示转为错误（需 feature gate）。
- enum 变体不能带可见性修饰符；use 不能导入不稳定特性。

## Language
- const 上下文之外的溢出/过长移位改为警告 + 运行时报错，未常量化的溢出推迟到运行期评估。
- `improper_ctypes` lint 不再对 `isize`/`usize` 报警。

## Libraries
- `Arc<T>`/`Rc<T>` 对 T 变为协变。
- `Default` 实现于可变切片。
- `AsMut` 实现于 `Vec`。
- 无损场景下的整型↔浮点 `From` 转换（如 u8→f32、i64→f64、f32→f64；32位整型→f32 不实现）。
- `FromStr` 实现于 `SocketAddrV4`/`V6`；`fs::Metadata` 实现 Clone。
- `parse` 允许前导 "+"；`clone_from` 优化；`extern fn` 类型实现 Clone/Eq/Ord/Hash/Debug 等。
- 未优化构建下无 Drop 元素的 Vec 析构更快；VecDeque 零大小 bug 修复；切片 PartialOrd 更快。

## Miscellaneous
- crate 元数据缩小 20%；libcore 缩 3.3MB；rustc 内存省 18MB。
- 初步支持 rumprun / NetBSD-amd64。
