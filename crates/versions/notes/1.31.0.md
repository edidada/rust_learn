# Rust 1.31.0（2018-12-06）

> 来源：[releases.rs/docs/1.31.0](https://releases.rs/docs/1.31.0/)；演示：`cargo run -p versions --bin rustc_1_31_0`

## Language
- **🎉 Rust 2018 Edition 正式发布 🎉**
- **新生命周期省略规则**：函数与 impl 头可省略生命周期——`impl<'a> Reader for BufReader<'a>` 可写作 `impl Reader for BufReader<'_>`（struct 定义处仍需命名）。
- **`const fn` 稳定**：可定义并调用常量函数（初期仅 RFC 的最小子集）。
- **tool lints**：外部工具的 lint 可被属性圈定，如 `#[allow(clippy::filter_map)]`。
- `#[no_mangle]`、`#[export_name]` 可放在 crate 任何位置；模式匹配允许括号。

## 模块路径变化（2018 edition 核心，教学重点）
- `use` 默认从 **crate 根或外部 crate** 解析，不再默认从当前模块解析（旧版 `use foo::bar` 优先找当前模块里的 `foo`）。
- 引用 crate 根用 `crate::foo`；引用外部 crate 直接写名字（`serde_json::...`），无需 `extern crate`，也无需 `::` 前缀。
- `extern crate` 不再需要（仅特殊场景保留，如 `extern crate alloc`）。

## Compiler
- musl 更新至 1.1.20。

## Libraries
- `num::NonZero*` 到原始类型的 `From` 转换（如 `u8` 实现 `From<NonZeroU8>`）。
- `&Option<T>` → `Option<&T>`、`&mut Option<T>` → `Option<&mut T>` 的 `From` 转换。
- `time::Duration` 可与 `u32` 相乘。

## Stabilized APIs
- `slice::align_to`、`slice::align_to_mut`
- `slice::chunks_exact`、`slice::chunks_exact_mut`
- `slice::rchunks`、`slice::rchunks_mut`、`slice::rchunks_exact`、`slice::rchunks_exact_mut`
- `Option::replace`

## Cargo
- 用 HTTP/2 并行下载 crates；Cargo.toml 可重命名依赖包（`package` key）。
