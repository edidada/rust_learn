# Rust 1.66.0（2022-12-15）

> 来源：[releases.rs/docs/1.66.0](https://releases.rs/docs/1.66.0/)；演示：`cargo run -p versions --bin rustc_1_66_0`

## Language
- **允许对 `repr(Int)` 枚举的带数据变体显式指定判别值**：`#[repr(u8)] enum Foo { A(u8) = 0, B(i8) = 1, C(bool) = 42 }`。
- **允许仅生命周期不同的相同类型之间 transmute**。
- **常量求值错误从 deny-by-default lint 变为硬错误**。
- **supertrait 上的 `#[must_use]` 对 impl Trait 也触发**：实现 `ExactSizeIterator` 会尊重 `Iterator` 上已有的 must_use。
- **模式中允许 `..=X`**（开放式范围模式）。
- 把 Clippy 的 `for_loops_over_fallibles` lint 上提到 rustc。
- 内联汇编的 `sym` 操作数稳定化；更新到 Unicode 15。
- **Opaque types 不再隐含生命周期 bound**（健全性修复，可能破坏错误依赖此行为的代码）。

## Compiler
- 新 tier 3 目标：`armv5te-none-eabi`、`thumbv5te-none-eabi`。
- 支持链接 macOS universal libraries。

## Libraries
- 修复泛型 `#[default]` 枚举上 `#[derive(Default)]` 添加多余 Default bound 的问题。
- 更新到 Unicode 15。

## Stabilized APIs
- `proc_macro::Span::source_text` — 取该 span 的源码文本。
- `uX::{checked_add_signed, overflowing_add_signed, saturating_add_signed, wrapping_add_signed}` — 无符号数与带符号数相加的一族方法。
- `iX::{checked_add_unsigned, overflowing_add_unsigned, saturating_add_unsigned, wrapping_add_unsigned}`。
- `iX::{checked_sub_unsigned, overflowing_sub_unsigned, saturating_sub_unsigned, wrapping_sub_unsigned}`。
- `BTreeSet::{first, last, pop_first, pop_last}` — 最小/最大元素及其弹出。
- `BTreeMap::{first_key_value, last_key_value, first_entry, last_entry, pop_first, pop_last}`。
- 为 WASI 的 stdio lock 类型添加 `AsFd` 实现。
- `impl TryFrom<Vec<T>> for Box<[T; N]>` — Vec 转 Box 数组（长度不匹配则失败）。
- `core::hint::black_box` — 防编译器优化的黑盒提示。
- `Duration::try_from_secs_{f32,f64}` — 从浮点秒构造 Duration（可能失败）。
- `Option::unzip` — `Option<(A, B)>` 拆成 `(Option<A>, Option<B>)`。
- `std::os::fd` — 平台无关的 fd 类型模块（`BorrowedFd`/`OwnedFd` 等）。

## Rustdoc
- 对文档中的无效 HTML 标签添加警告。

## Cargo
- 新增 `cargo remove` 从 Cargo.toml 移除依赖。
- `cargo publish` 现在等到新版本可下载后再退出。

## Compatibility Notes
- ProceduralMasquerade hack 仅应用于旧版 rental。
- wasm32-wasi 不再导出 `__heap_base`/`__data_end`；WebAssembly 不再导出 `__wasm_init_memory`；wasm32-unknown-unknown 仅导出 `__tls_*`。
- libstd 在 Darwin 上不再链接 libresolv；libc 升到 0.2.135（Darwin 不再拉入 libiconv.dylib）。
- Opaque types 不再隐含生命周期 bound（健全性修复）。
- `order_dependent_trait_objects` 出现在 future-breakage 报告中。
- `std::process::Command` 派生子进程默认继承父进程的信号掩码。

## Internal Changes
- LLVM 编译启用 BOLT；rustc_driver.so 启用 LTO。
