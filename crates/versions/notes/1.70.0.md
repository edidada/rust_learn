# Rust 1.70.0（2023-06-01）

> 来源：[releases.rs/docs/1.70.0](https://releases.rs/docs/1.70.0/)；演示：`cargo run -p versions --bin rustc_1_70_0`

## Language
- 放宽 `asm!` 操作数的顺序规则。
- 正确允许宏展开后的 `format_args!` 使用内联捕获（`{x}`）。
- 模糊（ambiguous）glob re-export 发 lint。
- **对 `let _ = expr` 位置的 const 求值与 unsafe 检查**（之前被跳过）。

## Compiler
- `-Cdebuginfo` 新选项与命名别名（如 `line-tables-only`）。
- `unused_allocation` 也对 `Box::new` 触发。
- const eval 尽早发现 uninhabited 类型；{arm,thumb}v4t-none-eabi 默认用 LLD 链接。
- 新 tier 3 目标：`loongarch64-unknown-linux-gnu`、`i586-pc-nto-qnx700`。
- **指针解引用插入对齐检查（debug assertions）**：运行时捕获 UB，可能使既有代码失败。

## Libraries
- NonZeroXxx 布局保证文档化。
- Windows: `Command` 优先用非 verbatim 路径。
- 为部分 alloc/core 迭代器实现 `Default`；修复 `str::lines` 对行尾裸 CR 的处理。
- `concat!` 中允许负数字面量；Cell 内存布局文档化。
- 用 `partial_cmp` 实现元组的 lt/le/ge/gt。
- **稳定 `atomic_as_ptr`（`Atomic*::as_ptr`）**。
- 稳定 `NonNull::slice_from_raw_parts`。
- **部分稳定化 `once_cell`**：`std::cell::OnceCell`。
- 稳定 `nonzero_min_max`（`NonZero*::MIN/MAX`）。
- **`std::io::IsTerminal` 稳定**：判断句柄是否连接到终端。
- `std::os::linux::net::SocketAddrExt`；UnixDatagram/UnixListener 的 `bind_addr`/`connect_addr`/`send_to_addr`。
- `Path::as_mut_os_str`；`std::sync::OnceLock`。
- 内置 unstable `FnPtr` trait 扩展函数指针的 Debug/Hash/Ord 等实现。

## Stabilized APIs
- `NonZero*::MIN/MAX` — 非零整数的最小/最大值。
- `BinaryHeap::retain` — 按条件保留堆元素。
- 一大批迭代器类型的 `Default` 实现（`std::vec::IntoIter`、`std::slice::{Iter,IterMut}`、`std::iter::{Chain,Cloned,Copied,Enumerate,Flatten,Fuse,Rev}`、BTreeMap/BTreeSet/LinkedList/二叉堆的迭代器等）——`Default::default()` 得到空迭代器。
- `Rc::into_inner` — `Option<Rc>` 拆出 `Option<T>`（引用计数为 1 时返回 Some）。
- `Arc::into_inner` — 同上（原子版）。
- `std::cell::OnceCell` — 单线程延迟初始化单元。
- `Option::is_some_and` — `Option<T>` 带 `T -> bool` 谓词判断。
- `NonNull::slice_from_raw_parts` — 从裸指针与长度构造 `NonNull<[T]>`。
- `Result::is_ok_and` / `Result::is_err_and` — 谓词判断。
- `std::sync::atomic::Atomic*::as_ptr` — 取内部裸指针。
- `std::io::IsTerminal` — trait：`stdout().is_terminal()`。
- `std::sync::OnceLock` — 可跨线程的一次性初始化单元。
- 其余：`std::os::linux::net::SocketAddrExt`、`std::os::unix::net::UnixDatagram::{bind_addr,connect_addr,send_to_addr}`、`std::os::unix::net::UnixListener::bind_addr`、`std::path::Path::as_mut_os_str`。

## Cargo
- 新增 `CARGO_PKG_README` 环境变量。
- **crates.io 默认使用 sparse 协议**（1.68 稳定、1.70 成为默认）。
- 降级依赖时准确显示状态；login/logout 使用 registry.default。
- 稳定 `cargo logout`。

## Misc
- 稳定 `rustdoc --test-run-directory`。

## Compatibility Notes
- stable libtest 不再支持 `-Zunstable-options`。
- `let _ = expr` 位置的 const/unsafe 检查开始执行。
- WebAssembly 目标在 codegen 中启用 sign-ext 与 mutable-globals 特性（可能与旧执行环境不兼容）。
- 指针解引用插入对齐检查（debug assertions）。

## Internal Changes
- 升级 LLVM 16；StableHasher 改用 SipHash-1-3。
