# Rust 1.17.0（2017-04-27）

> 来源：[releases.rs/docs/1.17.0](https://releases.rs/docs/1.17.0/)；演示：`cargo run -p versions --bin rustc_1_17_0`

## Language
- **字段初始化简写**（RFC 1682）：结构体字段可省略重复变量名 `S { x }`。
- static/const 的生命周期默认 `'static`（RFC 1623）。
- `Self` 可出现在 impl 的 where 子句中（RFC 1647）。
- Unsize 强转要求生命周期相等（健全性修复）；索引运算符参数自动强转；static 可引用其他 static。

## Compiler
- 按需（on-demand）类型检查重构；vtable 加载优化；`-C overflow-checks` 直接控制溢出检查；更清晰的 `&str + &str` 错误提示等。

## Stabilized APIs
- `Arc::into_raw` / `from_raw` / `ptr_eq`；`Rc::into_raw` / `from_raw` / `ptr_eq`
- `Ordering::then` / `then_with`
- `BTreeMap::range` / `range_mut`；`collections::Bound`
- `process::abort`
- `ptr::read_unaligned` / `write_unaligned`
- `Result::expect_err`
- `Cell::swap` / `replace` / `into_inner` / `take`

## Libraries
- **Cell 可存非 Copy 类型**（RFC 1651）。
- BTreeMap/BTreeSet 支持范围迭代。
- `String` 实现 FromIterator<&char>。
- `Box` 一大批转换实现：`From<Box<str>> for String`、`From<Box<[T]>> for Vec<T>`、Box<CStr/OsStr/Path> 与对应 owned 类型互转、`Default for Box<str/CStr/OsStr>`、`From<&CStr/&OsStr/&Path>` 等。
- `IpAddr` 实现多种数组 From；`SocketAddr` 实现 From<(I, u16)>。
- HashMap 自适应扩容防 DOS/劣质哈希；format! 预估容量。

## Cargo
- `cargo check --all`；`cargo run --package`；required_features。

## Misc
- 文档改用 mdbook；rustc 在 Windows MSVC 静态链接（无需装运行时）；TypeId 实现 PartialOrd/Ord；libcollection 结构体补 Debug。

## Compatibility Notes
- 1.17 无法识别 MSVC 2017 链接器（用 2015 或 vcvars.bat）。
- format!/to_string 对内部错误改 panic（此前静默忽略）。
- fn item transmute 到指针宽度类型成为硬错误；若干解析/可见性/inference 修复与收紧。
