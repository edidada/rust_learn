# Rust 1.87.0（2025-05-15）

> 来源：[releases.rs/docs/1.87.0](https://releases.rs/docs/1.87.0/)；演示：`cargo run -p versions --bin rustc_1_87_0`

## Language
- **稳定 `asm_goto`**：`asm!` 支持 `label` 分支目标（类似 C 的 goto asm），让内联汇编在平台相关场景直接跳转到 Rust 代码标签。演示受限平台，见 rs 注释讲解。
- 允许在 `!`、`-`、`*` 一元运算符之后解析开放区间（`..EXPR`，如 `match y { -1..x => … }` 形式）。
- 不要求给不定长类型 impl 中 `Self: Sized` 的方法提供实现。
- **稳定 `feature(precise_capturing_in_traits)`：trait 方法的 RPITIT 可写 `use<…>` 边界**（重点：`fn f(&self) -> impl Iterator<Item = u32> + use<Self>`）。

## Compiler
- x86：i686 目标强制要求 SSE2 并用它传 SIMD 类型。

## Platform Support
- 移除 i586-pc-windows-msvc 目标。

## Libraries
- **稳定匿名管道 API**（`io::pipe`/`PipeReader`/`PipeWriter` 及 `From` 转换）。
- 支持无界的左右移位操作（`unbounded_shl`/`unbounded_shr`）。
- 裸指针的 Debug 输出打印指针元数据。
- `Vec::with_capacity` 保证按请求量分配。
- 大多数不接收指针参数的 `std::arch` intrinsics 可在安全代码中调用（调用方需已启用相应特性）。
- 取消弃用 `env::home_dir`；`ControlFlow` 标 `#[must_use]`；`assert_eq!`/`vec!` 等宏支持 `const {}` 表达式。

## Stabilized APIs
- `Vec::extract_if` / `vec::ExtractIf`；`LinkedList::extract_if` / `linked_list::ExtractIf`
- `<[_]>::split_off` / `split_off_mut` / `split_off_first` / `split_off_first_mut` / `split_off_last` / `split_off_last_mut`
- `String::extend_from_with`
- `os_str::Display` / `OsString::display` / `OsStr::display`
- `io::pipe` / `io::PipeReader` / `io::PipeWriter`（及 `From` 实现：OwnedHandle/Stdio/OwnedFd）
- `Box<MaybeUninit<T>>::write`
- `impl TryFrom<Vec<u8>> for String`
- `<*const T>::offset_from_unsigned` / `byte_offset_from_unsigned`（及 `*mut T`、`NonNull` 版）
- `<uN>::cast_signed` / `NonZero::<uN>::cast_signed` / `<iN>::cast_unsigned` / `NonZero::<iN>::cast_unsigned`
- `<uN>::is_multiple_of` / `unbounded_shl` / `unbounded_shr`（含 iN 版）
- `<iN>::midpoint`
- `<str>::from_utf8` / `from_utf8_mut` / `from_utf8_unchecked` / `from_utf8_unchecked_mut`
- 以下此前已稳定 API 现可用于 const 上下文：`core::str::from_utf8_mut`、`<[T]>::copy_from_slice`、`SocketAddr::set_ip` 系列、`char::is_digit` / `is_whitespace`、`<[[T; N]]>::as_flattened(_mut)`、`String::into_bytes/as_str/capacity/as_bytes/len/is_empty/as_mut_str/as_mut_vec`、`Vec::as_ptr/as_slice/capacity/len/is_empty/as_mut_slice/as_mut_ptr`

## Cargo
- ANSI OSC 9;4 终端集成（进度条）；openssl 升 v3；`package --exclude-lockfile` flag。

## Compatibility Notes
- `#![crate_name]` 属性内的宏调用报错；unstable 字段总被视为 inhabited；一元运算符后开放区间的宏参数匹配可能变化。
- 裸指针 Debug 输出变化；依赖里不支持 ABI 字符串的函数指针告警。
- **dyn 类型上的关联类型不再去重**；struct 模式中 `..` 上的属性禁止（`let Struct { #[attribute] .. }`）。
- `ptr_cast_add_auto_to_object` 变硬错误。
- 许多 `std::arch` intrinsics 在部分场景变 safe → 已有代码可能出现新的 `unused_unsafe` 警告。
- 格式化的宽度/精度选项限制为 16 位；order dependent trait objects 警告变硬错误；`ControlFlow` 标 `#[must_use]`。
- Windows：std 不再链接 advapi32（win7 除外）；proc 宏不再观察到展开的 `cfg(true)`；粘贴 token 内部表示变更（部分晦涩的声明宏被正确拒绝）；const 中不允许展平的 `format_args`。
