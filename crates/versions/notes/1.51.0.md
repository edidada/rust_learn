# Rust 1.51.0（2021-03-25）

> 来源：[releases.rs/docs/1.51.0](https://releases.rs/docs/1.51.0/)；演示：`cargo run -p versions --bin rustc_1_51_0`

## Language
- **const generics MVP 稳定**：函数、trait、struct 等条目除类型和生命周期外，可再按**常量值**参数化。目前只允许基础整型、`bool`、`char` 常量参数。典型形态 `struct GenericArray<T, const LENGTH: usize> { inner: [T; LENGTH] }`，impl / 关联 const fn 都能引用 `LENGTH`。

## Compiler
- macOS 平台新增 `-Csplit-debuginfo` 调试信息拆分选项（其他平台尚 unstable）。
- 新增 tier 3：`aarch64_be-unknown-linux-gnu`、`aarch64-unknown-linux-gnu_ilp32`、`aarch64_be-unknown-linux-gnu_ilp32`、`i386-unknown-linux-gnu`、`i486-unknown-linux-gnu`。
- `target-cpu=native` 现在能识别 CPU 的单条特性。

## Libraries
- `Box::downcast` 对 `dyn Any + Send + Sync` 也可用。
- `str` 实现 `AsMut<str>`；`u64`/`u128` 实现 `From<char>`；`&T: Error` 实现 `Error`（当 `T: Error`）。
- `Poll<Option<Result<T, E>>>` 实现 `Poll::{map_ok, map_err}`。
- 所有有符号整型实现 `unsigned_abs`；`io::Empty` 实现 `io::Seek`。
- `rc::Weak<T>` / `sync::Weak<T>` 的 `as_ptr` 等方法支持 `T: ?Sized`。
- 无符号整数对 `NonZero` 变体的 `Div` / `Rem`。

## Stabilized APIs
- `Arc::decrement_strong_count` / `Arc::increment_strong_count` — 手动增减 Arc 强引用计数
- `Once::call_once_force` — 即使内部已毒化也强制执行一次
- `Peekable::next_if` / `Peekable::next_if_eq` — 条件式取走下一个元素
- `Seek::stream_position` — 返回流内偏移（seek 0(End) 对 seekNORMAL 友好）
- `array::IntoIter` — 定长数组按值迭代器（对应 `IntoIterator for [T; N]` 的铺垫版）
- `panic::panic_any` — 用 `&dyn Any` 直接 panic 非字符串值
- `ptr::addr_of!` / `ptr::addr_of_mut!` — 生成裸指针而不创建中间引用
- `slice::fill_with` — 用函数生成值填充切片
- `slice::split_inclusive` / `split_inclusive_mut` / `str::split_inclusive` — 分组分隔符留在段尾
- `slice::strip_prefix` / `slice::strip_suffix` — 去掉前后缀的子切片
- `sync::OnceState` — `call_once_force` 里访问毒化状态
- `task::Wake` — 手写 executor 的唤醒 trait
- `VecDeque::range` / `VecDeque::range_mut` — 范围内元素的双端迭代

## Cargo
- `Cargo.toml` 新增 `split-debuginfo` profile 选项。
- 新增 `resolver` 字段启用 v2 特性解析器：避免诸如 build 脚本/proc-macro 走 std 特性、最终二进制走 no-std 时的特征统一（feature unification）。

## Rustdoc
- 文档包含嵌套 `Deref` trait 提供的方法；`--default-theme` 设置默认主题。
- intra-doc link 增强：可链非路径原型（`slice`）、关联条目、带泛型参数如 `Vec<T>`。

## Misc
- 测试可用 `--include-ignored`（如 `cargo test -- --include-ignored`）跑 `#[ignore]` 标记的用例。

## Compatibility Notes
- WASI 平台不再使用 wasm-bindgen ABI，改用 wasm32 ABI。
- rustc 不再把可能失败的除法/取模/索引操作提升到 const。
- 若干平台 glibc 发行物最低版本提升到 2.31。
- `atomic::spin_loop_hint` 弃用，推荐 `hint::spin_loop`。
