# Rust 1.4.0（2015-10-29）

> 来源：[releases.rs/docs/1.4.0](https://releases.rs/docs/1.4.0/)；演示：`cargo run -p versions --bin rustc_1_4_0`

约 1200 处变更。

## Highlights
- **Windows 64位 MSVC ABI 与链接器正式支持并推荐使用**（此前只有 GNU/MinGW）。

## Breaking Changes
- RFC 1214 相关类型健全性改动，多数先警告下一版报错，个别场景立即破坏。
- `lines`（`str::lines` 与 `BufRead::lines`）把 `\r\n` 也视为换行。
- 'static 借用延伸到函数结束。
- **`str::parse` 不再引入可避免的舍入误差**：`f.to_string().parse()` 精确往返；并接受前导 `+` 号。

## Language
- **use 多项导入支持重命名**：`use foo::{bar as kitten, baz as puppy}`。
- 二元运算正确作用于胖指针。
- `pub extern crate` 发出警告。

## Libraries
- 大量 API 稳定化：`Box<str>::into_string`、`Arc::downgrade`/`get_mut`/`make_mut`/`try_unwrap`、`Rc::downgrade`/`get_mut`/`make_mut`/`try_unwrap`、`Box::from_raw`/`into_raw`、`CStr::to_str`/`to_string_lossy`、`Weak::upgrade` 等（完整列表见版本页）。
- 弃用若干 API：`BTreeMap::with_b`、`Option::as_slice`、`f32::from_str_radix` 等。
- 反向字符串搜索也改用 two-way 算法。
- `io::copy` 支持 `?Sized`。
- `Default` 实现到 `[T; 32]` 的数组。
- `Extend<String>` 与 `FromIterator<String>` 实现于 `String`。
- `IntoIterator` 实现于 `&Option` 与 `&Result`。
- `HashMap`/`HashSet` 对 `T: Copy` 实现 `Extend<&T>`（罕见场景会破坏类型推断）。
- `BinaryHeap` 实现 Debug；`Borrow`/`BorrowMut` 实现于数组。
- 字符串比较更快；`&mut T where T: fmt::Write` 也实现 `fmt::Write`。
- 修复 VecDeque 零大小类型的容量变更 panic；函数指针 trait 实现扩展到 12 参数。

## Miscellaneous
- 不再用 morestack 防栈溢出，改用 guard pages / stack probes。
- Cargo `update` 状态输出改进。
