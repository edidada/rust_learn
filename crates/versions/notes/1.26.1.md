# Rust 1.26.1（2018-05-29）

> 来源：[releases.rs/docs/1.26.1](https://releases.rs/docs/1.26.1/)；演示：`cargo run -p versions --bin rustc_1_26_1`

## Tools
- RLS 恢复 Windows 可用。
- Rustfmt 修复部分文本排版严重错乱的问题。

## Compatibility Notes
- **`fn main() -> impl Trait` 不再可用**（对非 Termination trait）——收回一次意外稳定。
- const-fn 上下文中 `NaN > NaN` 不再返回 true。
- 方法参数里的 `impl Trait` 不允许再写 turbofish（`foo::<T>(...)` 形式被禁）。
