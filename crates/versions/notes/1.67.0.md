# Rust 1.67.0（2023-01-26）

> 来源：[releases.rs/docs/1.67.0](https://releases.rs/docs/1.67.0/)；演示：`cargo run -p versions --bin rustc_1_67_0`

## Language
- **Sized 谓词变为 coinductive，允许循环**：trait 求解器可接受 Sized 约束的循环，减少"循环 trait bound"误报。
- **`async fn` 上的 `#[must_use]` 同样作用于 `Future::Output`**。
- 推导闭包签名时具体化（elaborate）supertrait 约束。
- `cfg(FALSE)` 下的无效字面量不再是错误（更宽松的条件编译解析）。
- **取消保留大括号枚举变体在值命名空间中的占用**：以前这类变体名被保留以备将来语法使用，现在可以正常使用。

## Compiler
- 对 C/cdecl 之外的调用约定启用 varargs 支持。
- 新增基于数据流分析的 MIR 常量传播。
- 优化字段排布：把 m*2^n 大小的字段与同等对齐的字段分组。
- 稳定 native library modifier `verbatim`。
- 新 tier 3 目标：`powerpc64-ibm-aix`、`mipsel-sony-psx`、`aarch64-unknown-nto-qnx710`、`x86_64-pc-nto-qnx710`；UEFI 目标（aarch64/i686/x86_64-unknown-uefi）升为 tier 2；移除 tier 3 linuxkernel 目标。

## Libraries
- **crossbeam-channel 合并进 `std::sync::mpsc`**：内部实现换用 crossbeam-channel，`mpsc` 更快更健壮。
- 修复 0.5 格式化为 0 位小数时的舍入不一致。
- `ControlFlow` derive `Eq` 与 `Hash`。
- 不再用 `-C panic=abort` 构建 compiler_builtins。

## Stabilized APIs
- `{integer}::checked_ilog`、`{integer}::checked_ilog2`、`{integer}::checked_ilog10` — 返回 `Option` 的对数（0 或负数输入为 None）。
- `{integer}::ilog`、`{integer}::ilog2`、`{integer}::ilog10` — panic 版对数。
- `NonZeroU*::ilog2`、`NonZeroU*::ilog10`。
- `NonZero*::BITS` — 非零整数类型的位宽。
- 以下 API 现在可在 const 上下文使用：`char::from_u32`、`char::from_digit`、`char::to_digit`、`core::char::from_u32`、`core::char::from_digit`。

## Compatibility Notes
- `repr(Rust)` 类型布局改变（m*2^n 字段分组；enum tag 位置可能使个别类型变大；布局是实现细节）。
- **0.5 格式化为 0 位小数时舍入到 0**：与其余浮点格式化的"ties to even"保持一致。
- **`&&`/`||` 链中子表达式的临时值按从左到右顺序 drop**（以前是"扭曲"的：第一个表达式的临时值最后 drop）。
- **字符串字面量的下划线后缀成为硬错误**（1.20.0 起的 future-compat 警告转正）。
- 不再向 wasm-ld 传 `-export-dynamic`；`main` 在 wasm32-wasi 上改名为 `__main_void`。
- 配置中多个 registry 使用相同 index URL 时 Cargo 报错。

## Internal Changes
- 用 Rust 重写 LLVM 的 archive writer。
