# Rust 1.83.0（2024-11-28）

> 来源：[releases.rs/docs/1.83.0](https://releases.rs/docs/1.83.0/)；演示：`cargo run -p versions --bin rustc_1_83_0`

## Language
- **const 中稳定 `&mut`、`*mut`、`&Cell`、`*const Cell`**：const fn/const 表达式里现在可以拿可变引用与可变指针操作内存（编译期"局部"可变，如 const 块内 `let mut` + `&mut`）。
- 允许在 const 初始化器中创建对 static 的引用。
- 原始生命周期与标签（`'r#type` 等保留字生命周期可用 `r#` 形式）。
- 定义原子读与非原子读竞争时的行为。
- 非 exhaustive 结构体现在可以为空。
- 禁止来自 `!` 类型位置的隐式强转。
- `const extern` 函数可定义其他调用约定。
- 稳定 `expr_2021` 宏片段指示符（全 edition）。
- `non_local_definitions` lint 触发范围收窄且默认 warn。

## Compiler
- 弃用 `-Csoft-float`；新增一批 tier 3 目标（QNX 700、arm64e-apple-tvos、loongarch OHOS、VxWorks、Hurd、Trusty 等）。

## Libraries
- `ExitCode` 实现 `PartialEq`；`catch_unwind` 处理外部异常的文档；HashMap/HashSet 迭代器补 `Default`；Unicode 升至 16.0.0。

## Stabilized APIs
- `BufRead::skip_until`
- `ControlFlow::break_value` / `continue_value` / `map_break` / `map_continue`
- `DebugList::finish_non_exhaustive` / `DebugMap::…` / `DebugSet::…` / `DebugTuple::…`
- `ErrorKind::ArgumentListTooLong` / `Deadlock` / `DirectoryNotEmpty` / `ExecutableFileBusy` / `FileTooLarge` / `HostUnreachable` / `IsADirectory` / `NetworkDown` / `NetworkUnreachable` / `NotADirectory` / `NotSeekable` / `ReadOnlyFilesystem` / `ResourceBusy` / `StaleNetworkFileHandle` / `StorageFull` / `TooManyLinks`
- `Option::get_or_insert_default`
- `Waker::data` / `Waker::new` / `Waker::vtable`
- `char::MIN`
- `hash_map::Entry::insert_entry` / `hash_map::VacantEntry::insert_entry`（`insert_entry` 返回 `OccupiedEntry`，可用 `get_mut` 就地修改）
- 以下可用于 const 上下文（节选，本期 const 能力大扩）：`Cell::into_inner`、`MaybeUninit::as_mut_ptr`、`NonNull::as_mut`、`NonNull::write*`、`OnceCell::into_inner`、`Option::as_mut/expect/replace/take/unwrap/unwrap_unchecked`、`Option::<Option<_>>::flatten`、`Result::as_mut`、`UnsafeCell::get_mut`、`array::from_mut`、`char::encode_utf8`、`{float}::classify/is_finite/is_nan/to_bits/from_bits/to_le_bytes…`、`mem::replace`、`ptr::replace/write…`、`slice::from_mut`、`<[_]>::first_mut/last_mut/split_at_mut…`、`str::as_bytes_mut/from_utf8_unchecked_mut`

## Cargo
- 新环境变量 `CARGO_MANIFEST_PATH`；`package.autolib` 可关闭 [lib] 自动发现。

## Rustdoc
- 侧栏/汉堡菜单目录包含文档注释中的 `#` 标题。

## Compatibility Notes
- 对不支持 ABI 字符串的函数指针告警；fn 指针 cast 检查源签名良构性；类型依赖路径解析用相等而非子类型。
- macOS 链接包含默认 deployment target（可能需 `MACOSX_DEPLOYMENT_TARGET`）。
- `repr(Rust)` 写在非 struct/enum/union 项上现在报错。
- `deprecated_cfg_attr_crate_type_name` 变硬错误（`cfg_attr` 中 `crate_type/crate_name` 不再可用，改用 `--crate-type`/`--crate-name`）。
- rust-src 存在时诊断路径用真实路径替代 `/rustc/$hash`。
- `#[expect(missing_docs)]` 不再在 `--test` 场景失效。
- 最低 LLVM 18；移除 Fuchsia 旧别名；panic 异常类用本机端序编码；MSVC 目标不再支持 VS2013；sysroot 顶层 lib/ 不再含 std 动态库。
