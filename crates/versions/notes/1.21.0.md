# Rust 1.21.0（2017-10-12）

> 来源：[releases.rs/docs/1.21.0](https://releases.rs/docs/1.21.0/)；演示：`cargo run -p versions --bin rustc_1_21_0`

## Language
- **字面量可被 `'static` 引用**：表达式如 `let x: &'static u32 = &0;` 现在合法（字面量提升到静态存储）。
- **放宽路径语法**：`<` 前可选的 `::` 在所有上下文都允许了，如 `Vec::<i32>::new()`。

## Compiler
- jemalloc 升级到 4.5.0；Redox 上启用 unwind panic。
- LLVM 翻译阶段并行执行，降低峰值内存。

## Libraries
- 为所有 `T: Clone` 的数组和元组生成内建 `Clone` 实现。
- `Stdin/Stdout/Stderr` 实现 `AsRawFd`（Unix）。
- `Rc/Arc` 新增 `From<&[T]>`（T: Clone）、`From<str>`、`From<String>`、`From<Box<T>>`（T: ?Sized）、`From<Vec<T>>`。

## Stabilized APIs
- `std::mem::discriminant` — 获取枚举值的判别式，可用于比较两值是否为同一变体。

## Cargo
- `cargo install` 支持一次装多个包。
- 虚拟 workspace 内的 cargo 命令隐式传 `--all`。
- 新增 `[patch]` 段处理未发布依赖（RFC 1969）；`include/exclude` 支持 gitignore 风格模式。
- 新增 `--all-targets` 选项；把必需依赖当 feature 用现在会出现弃用警告。

## Misc
- Cargo 文档迁至 doc.rust-lang.org/cargo；rustdoc book 上线；RLS 预览可 `rustup component add rls-preview`。

## Compatibility Notes
- 高阶类型（higher-ranked types）方法匹配规则变化，亚类型极端情形可能破坏。
- rustc JSON 错误输出的字节位置改为从文件顶部计算（原相对内部 CodeMap）。
- `unused_results` lint 不再忽略布尔值。
