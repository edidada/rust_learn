# Rust 1.60.0（2022-04-07）

> 来源：[releases.rs/docs/1.60.0](https://releases.rs/docs/1.60.0/)；演示：`cargo run -p versions --bin rustc_1_60_0`

## Language
- 稳定 `#[cfg(panic = "unwind" | "abort")]`：按 panic 策略做条件编译。
- 稳定 `#[cfg(target_has_atomic = "...")]`：按整数宽度（8/16/32/64/128）与 `ptr` 判断原子可用性。

## Compiler
- x86_64-unknown-linux-gnu 支持 `+crt-static` 与 `relocation-model=pic` 组合。
- 修 nested/glob public reexport 的 `unreachable_pub` 误报。
- `-Z instrument-coverage` 稳定为 `-C instrument-coverage`（源码覆盖率）。
- `-Z print-link-args` 稳定为 `--print link-args`。
- 新 tier 3：`mips64-openwrt-linux-musl`、`armv7-unknown-linux-uclibceabi`（softfloat）、RustyHermit 的 kernel target。
- 禁止 bin 与 lib crate types 混用；rustc 默认按 `RUST_BACKTRACE=full`。
- LLVM 升级到 14。

## Libraries
- 保证 `sort_by_cached_key` 的调用顺序。
- 提高浮点转 `Duration`（`try_from_secs_f32/f64`）的精度。
- **`Instant::{duration_since, elapsed, sub}` 改为饱和**（不再 panic，欠留时得 0）；移除非单调时钟 workaround；`Instant::now` 时钟回滑保护移除。

## Stabilized APIs
- `Arc::new_cyclic` / `Rc::new_cyclic` — 构造期间拿到 Weak 引用
- `slice::EscapeAscii` / `<[u8]>::escape_ascii` / `u8::escape_ascii`
- `Vec::spare_capacity_mut` — 未初始化余量作 `&mut [MaybeUninit<T>]`
- `MaybeUninit::assume_init_drop` / `assume_init_read`
- 所有整数类型的 `abs_diff`
- `io::ErrorKind` 实现 `Display`
- `From<u8> for ExitCode` — 进程退出码
- `Not` for `!`（never 类型）
- `Wrapping<$t>` 实现 `OpAssign<$t>`
- `arch::is_aarch64_feature_detected!` 宏

## Cargo
- 从 toml-rs 迁移到 toml_edit；`--timings` 稳定；namespaced 和 weak 依赖特性稳定。
- build 脚本输出接受更多 `cargo:rustc-link-arg-*` 类型。
- `cargo-new` 不再在子目录生成 Cargo.lock ignore。

## Misc
- Tier 2 平台复用最接近 Tier 1 平台的文档；移除 rustc-docs；bootstrap llvm flag 整理。

## Compatibility Notes
- Android 移除 compiler-rt 链接 hack。
- 非单调时钟平台上 `Instant::now` 不再保证后值更大。
- `Instant::{duration_since, elapsed, sub}` 不再 panic，饱和为 0（代编程错误检查）。
- 未来版本 Linux kernel 基线将提到 3.2、glibc 2.17（PR 95026）。
