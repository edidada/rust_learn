# Rust 1.76.0（2024-02-08）

> 来源：[releases.rs/docs/1.76.0](https://releases.rs/docs/1.76.0/)；演示：`cargo run -p versions --bin rustc_1_76_0`

## Language
- 文档化多种类型之间的 Rust ABI 兼容性；保证 `char` 与 `u32` ABI 兼容。
- 新增 `ambiguous_wide_pointer_comparisons` lint（取代 clippy 的 `vtable_address_comparisons`：比较宽指针时 vtable 地址可能造成歧义）。

## Compiler
- `unused_must_use` 对被 pin 住的 `#[must_use]` 指针（如 `Box<#[must_use] T>`）触发 lint。
- 健全性修复：packed 结构体中 unsized 字段的偏移计算；带 dyn Trait 尾部的 packed 类型的动态 size/align 计算。
- json 诊断输出增加 `$message_type` 字段；启用 Windows 的 EHCont 安全特性。
- 新 tier 3 目标：`{x86_64,i686}-win7-windows-msvc`、`aarch64-apple-watchos`、`arm64e-apple-ios`、`arm64e-apple-darwin`。

## Libraries
- `dbg!()` 输出加列号。
- **新增 `std::hash::{DefaultHasher, RandomState}` 顶层导出**（以前只能从 `std::collections::hash_map` 取）。
- 修复 fmt 指数舍入问题；`RwLockReadGuard`/`RwLockWriteGuard` 的 Debug impl 加 `T: ?Sized`。
- Windows 上 `File::create` 可用于隐藏文件。

## Stabilized APIs
- `Arc::unwrap_or_clone` — 引用计数为 1 时取出内部值，否则 clone 后取出。
- `Rc::unwrap_or_clone` — 同上（Rc 版）。
- `Result::inspect` / `Result::inspect_err` — 成功/失败路径上透明查看值。
- `Option::inspect` — Some 时查看值。
- `type_name_of_val` — 取任意值的类型名。
- `std::hash::{DefaultHasher, RandomState}` — 顶层导出。
- `ptr::{from_ref, from_mut}` — 从引用构造裸指针（此前仅 `std::ptr::from_ref` 通过 `std` 可用）。
- `ptr::addr_eq` — 只比较地址（忽略 vtable/元数据）的指针相等。

## Cargo
（见 Cargo release notes）

## Rustdoc
- 重导出不合并 cfg 与 doc(cfg) 属性；允许调整侧边栏大小/隐藏顶栏；搜索支持 trait 与关联类型；条目声明中注释高亮。

## Compatibility Notes
- 新增 allow-by-default 的 unit bindings lint（未来会默认警告；某些宏会生成类型为 `()` 的绑定）。
- 移除 `x86_64-sun-solaris`、`asmjs-unknown-emscripten` 目标。
- 报告通过环境变量继承的 jobserver 错误；最低 LLVM 升到 16。
- `print_tts` 改进：依赖 proc macro `.to_string()` 具体格式的手工解析可能被破坏。
- `IMPLIED_BOUNDS_ENTAILMENT` 从 lint 变为硬错误。
- 收集部分迭代器时 `Vec` 的分配行为改变（分配行为本未规定，可能造成意外）。
- 正确拒绝自由 const item 上的 `default`。
