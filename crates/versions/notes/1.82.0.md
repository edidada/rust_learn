# Rust 1.82.0（2024-10-17）

> 来源：[releases.rs/docs/1.82.0](https://releases.rs/docs/1.82.0/)；演示：`cargo run -p versions --bin rustc_1_82_0`

## Language
- 语句非终结符不再匹配模式非终结符（宏卫生修复）。
- 匹配空类型的模式在常见情形下可省略。
- 使用 trait impl 时强制检查 supertrait 的 outlives 义务。
- `addr_of(_mut)!` 宏与 **新稳定的 `&raw (const|mut)`** 对所有 static 项安全可用。
- `size_of_val_raw`：长度为 0 时安全可调。
- trait bound 修饰符排在 `for<...>` binder 之后的重排。
- **稳定 `use<'lt, …>` opaque 类型精确捕获（RFC 3617）**：返回位置 impl Trait 用 `use<…>` 显式列出捕获的参数，其余（尤其生命周期）不再被隐式捕获。
- **稳定 `&raw const` / `&raw mut` 运算符（RFC 2582）**：不用 unsafe、不用宏即可取得裸指针，等价 `&ptr as *const _` 的"新建指针"语义（解引用仍 unsafe）。
- **稳定 `unsafe extern` 块（RFC 3484）**：extern 块标记为 unsafe，声明中的 unsafe 义务一目了然；edition 2024 中 `unsafe` 为强制。
- 稳定 `offset_of!` 嵌套字段访问（`offset_of!(A, b.c)`）。
- `[T; 0]` drop 不要求 T 存活；inline asm 稳定 const 操作数；**const fn 中稳定浮点运算**；稳定显式 opt-in 的 unsafe 属性；文档化 NaN 位模式保证。

## Compiler
- riscv64gc-unknown-linux-musl 升 tier 2；Mac Catalyst 目标升 tier 2；aarch64-apple-darwin 升 tier 1；wasm32-wasip2 升 tier 2。
- 更好的 unreachable 模式诊断；async 函数不发返回的 unreachable 警告正确触发。

## Libraries
- `{Rc,Arc}::make_mut()` 泛化到 `Path`/`OsStr`/`CStr`。

## Stabilized APIs
- `std::thread::Builder::spawn_unchecked`
- `std::str::CharIndices::offset`
- `std::option::Option::is_none_or`
- `[T]::is_sorted` / `is_sorted_by` / `is_sorted_by_key`；`Iterator::is_sorted` / `is_sorted_by` / `is_sorted_by_key`
- `std::future::Ready::into_inner` / `std::iter::repeat_n`
- `impl<T: Clone> DoubleEndedIterator for Take<Repeat<T>>` 等 Repeat 组合
- `Default for` 各集合迭代器（binary_heap::Iter、btree_map::RangeMut、btree_map::ValuesMut、vec_deque::Iter/IterMut）
- `Rc<T>::new_uninit` / `Rc<MaybeUninit<T>>::assume_init` / `Rc<[T]>::new_uninit_slice` / `Rc<[MaybeUninit<T>]>::assume_init`；`Arc<T>`/`Arc<[T]>` 同系列；`Box<T>::new_uninit` / `Box<MaybeUninit<T>>::assume_init` / `Box<[T]>::new_uninit_slice` / `Box<[MaybeUninit<T>]>::assume_init`
- x86/x86_64 intrinsics：`_bextri_u64/_bextri_u32`、`_tzcnt_u16`、`_mm_storeu_si16/32/64`、`_mm_loadu_si16/32` 等（不逐个演示）
- wasm32 relaxed SIMD intrinsics（不演示）
- 以下可用于 const 上下文：`std::task::Waker::from_raw`、`Context::from_waker`、`Context::waker`、`{integer}::from_str_radix`、`ParseIntError::kind`

## Cargo
- 新增 `cargo info` 子命令。

## Compatibility Notes
- 新增 `explicit_builtin_cfgs_in_flags` lint：禁止用命令行 `--cfg` 设置内建 cfg（防不一致状态）。
- **二分查找换新实现**：性能大幅提升，但排序切片中有重复相等值时，`binary_search` 可能返回不同下标。
- illumos/Solaris socket 写入设置 `MSG_NOSIGNAL`。
- 移除测试链接时 `--whole-archive` 的 hack。
- WebAssembly 默认启用 multivalue 与 reference-types 特性（编码变化影响下游工具）。
- union 模式在参数位触发 unsafety 错误。
