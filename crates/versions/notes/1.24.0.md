# Rust 1.24.0（2018-02-15）

> 来源：[releases.rs/docs/1.24.0](https://releases.rs/docs/1.24.0/)；演示：`cargo run -p versions --bin rustc_1_24_0`

## Language
- 新增 `extern "sysv64" fn foo() {}`：System V 64 位调用约定的 FFI 显式声明。

## Compiler
- release 构建默认 16 个 codegen units（追求最快编译可用 `codegen-units=1`）。
- 新增 `armv4t-unknown-linux-gnueabi`、`aarch64-unknown-openbsd` 目标。

## Libraries
- `str::find::<char>` 用 memchr 实现，多数场景性能提升约 10x。
- `OsStr` 的 Debug 实现无损且与 Windows 一致；`{SystemTime, Instant}` 实现 `Hash`。
- `AtomicBool` 实现 `From<bool>`；`{CString,&CStr}/{OsString,&OsStr}/{PathBuf,&Path}` 可 `From` 到对应 `Arc/Rc`。
- `char` 也复制了 `AsciiExt` 方法；`ptr::is_null` 去掉 `T: Sized`；`RecvError` 实现到 `{TryRecvError,RecvTimeoutError}` 的 `From`。
- `f32::{min,max}` 优化为更高效的 x86 汇编；`[u8]::contains` 用 memchr 提速约 3x。

## Stabilized APIs
- `RefCell::replace`、`RefCell::swap`、`atomic::spin_loop_hint`
- 以下可作为常量表达式使用（`const fn` 化）：`AtomicBool::new`、`AtomicUsize::new`、`AtomicIsize::new`、`AtomicPtr::new`、`Cell::new`、`{integer}::min_value`、`{integer}::max_value`、`mem::size_of`、`mem::align_of`、`ptr::null`、`ptr::null_mut`、`RefCell::new`、`UnsafeCell::new`
  - 例：`let buffer: [u8; size_of::<usize>()];`、`static COUNTER: AtomicUsize = AtomicUsize::new(1);`

## Cargo
- 新增 `workspace.default-members` 配置；开发构建默认开启增量编译，且支持按项目/全局禁用。

## Compatibility Notes
- 浮点类型的 `Debug` 输出始终带小数点（`2.0` 不再是 `2`）。
- `Ipv6Addr` 按 RFC 4291 §2.2 拒绝多余的 `::`。
- unwinding 不会再穿越 FFI 边界，而是 abort。
- `Formatter::flags` 弃用（改用 `sign_plus` 等）；元组结构体成员的前导零报错；`column!()` 变为 1 起。
- `fmt::Arguments` 不可再跨线程共享；访问 `#[repr(packed)]` 字段变为 unsafe；Cargo 换了编译器工作目录。
