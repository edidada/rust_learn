# Rust 1.23.0（2018-01-04）

> 来源：[releases.rs/docs/1.23.0](https://releases.rs/docs/1.23.0/)；演示：`cargo run -p versions --bin rustc_1_23_0`

## Language
- **trait object 允许任意 auto trait（arbitrary auto traits）**：`dyn Trait + Send + UnwindSafe` 之类的组合可用。
- 二元运算左侧现在使用子类型化（subtyping），修正部分令人困惑的报错。

## Compiler
- LLVM 启用 `TrapUnreachable`，缓解未定义行为的破坏面。
- 名称冲突时建议重命名导入；正确显示零宽/全角字符的报错与警告。
- 简单绑定的参数不再复制，平均内存占用降低 5–10%；musl 升级到 1.1.17。

## Libraries
- `assert_eq!/assert_ne!` 允许尾逗号；对未定长类型的裸指针实现 `Hash`。
- `AtomicPtr<T>` 实现 `From<*mut T>`；`AtomicUsize/AtomicIsize` 实现 `From<usize/isize>`。
- 移除 `RwLock<T>: Send` 的 `T: Sync` 要求；`{*const T,*mut T}::as_ref/as_mut` 去掉 `T: Sized` 约束。
- `Thread::{park,unpark}` 实现优化；`SliceExt::binary_search` 性能提升；`()` 实现 `FromIterator<()>`。
- **`AsciiExt` 的方法被复制为基本类型的固有方法，`AsciiExt` 用法被弃用**（如 `str::to_ascii_uppercase()` 不再需要 `use std::ascii::AsciiExt`）。

## Stabilized APIs
- （本版无新稳定 API；重点是上面这些 trait 实现/优化与弃用。）

## Cargo
- `cargo uninstall foo bar` 支持一次卸载多个包。
- `cargo check` 现在做单元测试检查。
- `cargo install --version` 可安装指定版本。

## Misc
- 发行版附带 Cargo book；rustdoc 每次运行都打印渲染警告。

## Compatibility Notes
- 类型相等性判定更正，罕见情形可能破坏代码。
- `char::escape_debug` 从 Unicode 9 升到 10。
- Android SDK 升 27、NDK 升 r15c（最低支持 Android 14）；最低 LLVM 提至 3.9。
