# Rust 1.35.0（2019-05-23）

> 来源：[releases.rs/docs/1.35.0](https://releases.rs/docs/1.35.0/)；演示：`cargo run -p versions --bin rustc_1_35_0`

## Language
- **Box<F> 实现 Fn/FnMut/FnOnce**：`Box<dyn FnOnce>` 等闭包装箱类型现在可以直接像函数一样调用（`boxed()`），不再需要先 `(*boxed)(...)`。
- **闭包强制转换为 unsafe fn 指针**：闭包可以直接强转（coerce）为 `unsafe fn()` 指针。

## Compiler
- 新增 `armv6-unknown-freebsd-gnueabihf`、`armv7-unknown-freebsd-gnueabihf` 目标。
- 新增 `wasm32-unknown-wasi` 目标。

## Libraries
- `Thread` 的 Debug 输出会显示线程 ID。
- `StdinLock`/`StdoutLock`/`StderrLock` 实现 `AsRawFd`。
- `alloc::System` 实现 `Default`。
- 结构体的 `Debug` 展开（`{:#?}`）在最后一个字段后带尾逗号。
- `char::{ToLowercase, ToUppercase}` 实现 `ExactSizeIterator`。
- 所有 NonZero 数字类型实现 `FromStr`。
- 移除 `BufReader::{get_ref, get_mut, into_inner}` 的 `Read` trait 约束。
- `dbg!` 宏可以无参数调用，打印调用处的文件和行号。
- 原地 ASCII 大小写转换（如 `str::make_ascii_lowercase`）最高提速 4 倍。
- `hash_map::{OccupiedEntry, VacantEntry}` 实现 `Sync`/`Send`。

## Stabilized APIs
- `f32::copysign` — 复制符号位
- `f64::copysign` — 同上（f64 版）
- `RefCell::replace_with` — 用闭包替换值
- `RefCell::map_split` — 拆分借用
- `ptr::hash` — 对裸指针做 hash
- `Range::contains` — `Range` 是否包含某值
- `RangeFrom::contains` — 同上（`a..`）
- `RangeTo::contains` — 同上（`..b`）
- `RangeInclusive::contains` — 同上（`a..=b`）
- `RangeToInclusive::contains` — 同上（`..=b`）
- `Option::copied` — `Option<&T>` → `Option<T>`

## Cargo
- 可在 build script 里设置 `cargo:rustc-cdylib-link-arg`，构建 cdylib 时传自定义链接参数（高度平台相关）。

## Misc
- Rust 工具链原生支持基于 musl 的发行版。
