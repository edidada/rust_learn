# Rust 1.15.0（2017-02-02）

> 来源：[releases.rs/docs/1.15.0](https://releases.rs/docs/1.15.0/)；演示：`cargo run -p versions --bin rustc_1_15_0`

## Language
- **"macros 1.1" 稳定：基础过程宏（自定义 derive）**（RFC 1681），Serde、Diesel 等代码生成 crate 得以人性使用（需外部 crate，演示仅讲解）。
- 元组结构体可为空；单元/空元组结构体可用花括号实例化（RFC 1506 部分）。
- 名称解析一批小改（RFC 1560）激活，语义更一致。
- `macro_rules!` 中路径片段可解析为类型参数 bound；`?Sized` 可用于 where 子句。
- 单态化类型新增大小上限（`#![type_size_limit]` 可调）。

## Compiler
- Windows 链接 extern 函数应用 dllimport（RFC 1717）；Rust-ABI 符号不再从 cdylib 导出；`#[derive]` 可用于过程宏 crate；`format!` 识别 printf/shell 风格错误格式并给出建议；未用导入只报一条错误。

## Compiler Performance
- 一批类型检查优化（mk_ty 调用减少、small vectors、去掉 scope_auxiliary 省 10% RSS 等）。

## Stabilized APIs
- `Iterator::min_by` / `max_by`（非 key 版）
- `os::*::fs::FileExt`
- `atomic::Atomic*::get_mut` / `into_inner`
- `vec::IntoIter::as_slice` / `as_mut_slice`
- `sync::mpsc::Receiver::try_iter`
- `os::unix::process::CommandExt::before_exec`
- `Rc::strong_count` / `weak_count`、`Arc::strong_count` / `weak_count`
- `char::encode_utf8` / `encode_utf16`
- `cell::Ref::clone`
- `io::Take::into_inner`

## Libraries
- **标准排序算法重写**（类 Timsort 的混合归并排序），性能大涨。
- `Iterator::nth` 去掉 Sized bound；`Extend<&T>` 对 Copy 元素的 Vec 特化；`chars().count()`/`last()` 大幅提速。
- 中文等字符在 fmt::Debug 中正确显示；`Duration` 派生 Default。

## Cargo
- **构建脚本不再能在编译期用 `env!("OUT_DIR")`**，改为运行期 `std::env` 读取（已知破坏性变更）；`cargo test --all`；MSVC CRT 静态链接等。

## Tooling
- 测试二进制支持 `--list` 与 `--exact`；rustdoc `--playground-url`。

## Misc
- 构建系统改写为 Rust；i686-openbsd、MSP430、ARMv5TE 三级支持。

## Compatibility Notes
- RFC 1560 名称解析变更激活；`env!("OUT_DIR")` 破坏；`hr_lifetime_in_assoc_type` 转错误；`legacy_directory_ownership` 警告；Rust-ABI 符号不再导出；`Peekable` peek 到 None 后不再回询底层迭代器。
