# Rust 1.10.0（2016-07-07）

> 来源：[releases.rs/docs/1.10.0](https://releases.rs/docs/1.10.0/)；演示：`cargo run -p versions --bin rustc_1_10_0`

## Language
- **Copy 类型必须平凡实现 Clone**（RFC 1521）：`#[derive(Copy)]` 要求其 Clone 是平凡 memcpy。
- 单变体枚举支持 `#[repr(..)]`。
- `panic!` 可用 `-C panic=abort` 转为运行时中止（RFC 1513）。
- 新 crate 类型 **cdylib**：可供非 Rust 宿主加载的动态库（RFC 1510；Cargo 尚未直接支持）。

## Stabilized APIs（精选）
- `panic::set_hook` / `take_hook` / `PanicInfo`（`payload`/`location`）、`Location`（`file`/`line`）
- `ffi::CStr::from_bytes_with_nul` / `from_bytes_with_nul_unchecked` / `FromBytesWithNulError`
- `fs::Metadata::modified` / `accessed` / `created`
- `sync::atomic::Atomic{Usize,Isize,Bool,Ptr}::compare_exchange` / `compare_exchange_weak`
- `sync::Weak::new` 与 `Default`
- `{BTree,Hash}Map::values_mut`
- `<[_]>::binary_search_by_key`
- `{BTree,Hash}_map` 的 Occupied/Vacant `Entry::key`
- `os::unix::net` 全家（UnixStream/UnixListener/UnixDatagram/SocketAddr 及其方法）

## Libraries
- 浮点 `abs_sub` 弃用（语义微妙且不合直觉）。
- `Cell`/`RefCell` 实现 `Ord`（T: Ord）；Wrapping 取负、Display/Hash；VecDeque↔Vec 的 From/Into；`Default` 实现于 UnsafeCell/fmt::Error/Condvar/Mutex/RwLock、`&CStr`/`CString`。
- Linux 上 HashMap 种子 getrandom 不可用时回退 /dev/urandom。

## Cargo
- `profile.*.panic`（unwind/abort，RFC 1513）；网络请求重试；`cargo install --force`；`cargo test --doc`；`cargo doc --lib/--bin` 等。

## Performance
- rustc 内存优化；HashMap 种子缓存；Chain 的 find 2 倍提速；trait 选择提速 15%；Unicode 属性 trie 查找 10 倍。

## Usability / Misc
- rustdoc 列出 blanket impl；索引类型错误更可读；`rust-gdb`/`rust-lldb` 全 Unix 分发；改用上个 release 自举。

## Compatibility Notes
- `AtomicBool` 由字长改为 bool 大小；Linux ARM 的 `target_env` 统一为 gnu。
- `Duration::new` 溢出一律 panic；`String::truncate` 减少 panic 场景。
- 宏 follow-set 规则（RFC 550 修正）启用；类型推断的 fallback/歧义错误被抑制等。
