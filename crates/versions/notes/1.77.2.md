# Rust 1.77.2（2024-04-09）

> 来源：[releases.rs/docs/1.77.2](https://releases.rs/docs/1.77.2/)；演示：`cargo run -p versions --bin rustc_1_77_2`

Patch 版本，仅一条安全修复，照实记录。

## Changes
- **CVE-2024-24576（"BatBadBut"）**：修复 `std::process::Command` 在 Windows 上对批处理文件（`.bat`/`.cmd`）参数的转义——此前恶意参数可注入任意命令。在 Windows 上传入不可信参数调用批处理文件属于漏洞利用场景。
