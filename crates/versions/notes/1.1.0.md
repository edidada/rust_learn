# Rust 1.1.0（2015-06-25）

> 来源：[releases.rs/docs/1.1.0](https://releases.rs/docs/1.1.0/)；演示：`cargo run -p versions --bin rustc_1_1_0`

约 850 处变更。第一个小版本更新（1.x 承诺不破坏兼容）。

## Highlights
- `std::fs` 扩充：`DirEntry` 支持 `file_type`/`metadata`（部分平台免去系统调用）、新增 `symlink_metadata`；`fs::Metadata` 投影到 OS 原生结构提供底层信息。
- 编译器内含大量错误的扩展解释，出错时提示 `--explain` 阅读说明。
- 类型检查等多项改进，编译器自举时间下降 32%。

## Libraries
- `str::split_whitespace`：按 Unicode 空白切分字符串（1.0 时替代了 `words`）。
- **原始句柄转换 trait**：Unix `FromRawFd`/`AsRawFd`，Windows `FromRawHandle`/`AsRawHandle`，实现于 `File`、`TcpStream`、`TcpListener`、`UdpSocket`。
- Unix `std::os::unix::symlink` 创建符号链接；Windows `symlink_dir`/`symlink_file`。
- `mpsc::Receiver` 实现 `IntoIterator`，可 `into_iter` 迭代消息。
- `Ipv4Addr` 可由 `u32` 通过 `From<u32>` 构造。
- `RangeFull` 的 Debug 输出更一致；`File` 实现 `Debug`。
- `Arc` 的 `Default` 不再要求 `Sync + Send`。
- 切片覆盖 `Iterator::count`/`nth`/`last` 为 O(1)。
- `AtomicPtr` 获得 `Default`。
- debug 断言开启时 `abs` 溢出会 panic（符合溢出策略）。
- `Cloned` 迭代器稳定化（1.0 时意外不稳定）。
- `Incoming`（TCP incoming 连接迭代器）正确导出（1.0 时不可命名）。
- 修复 `BinaryHeap` sift_up/sift_down panic 后自损坏、`LinkedList::split_off` 损坏等问题。

## Misc
- 类型检查性能显著提升；编译器为更多错误建议代码修改。
- rustc/构建系统实验性支持 Linux MUSL；`target_env` cfg 值区分 gnu/musl。
- 新命令 `cargo rustc`：以自定义 flags 构建。
- Android 可执行文件总是位置无关；新 lint `drop_with_repr_extern`。
