# Rust 1.3.0（2015-09-17）

> 来源：[releases.rs/docs/1.3.0](https://releases.rs/docs/1.3.0/)；演示：`cargo run -p versions --bin rustc_1_3_0`

约 900 处变更。

## Highlights
- **对象生命周期默认（object lifetime defaults）正式生效**：`&'a Box<Trait>` 从 `Trait + 'a` 变为解释成 `Trait + 'static`（先警告一版再落地）。
- 新官方文档《The Rustonomicon》（unsafe Rust 指南）。
- **`Duration` API 和 `std::time` 模块稳定化**。

## Breaking Changes
- 对象生命周期默认开启。
- 对象生命周期省略有一条已知回归，解决方案未定。
- 内部属性 `#[prelude_import]` 收回 feature gate。
- `size_of_val`/`align_of_val` 对 DST 行为更合理（旧行为视为损坏代码）。
- **dropck 规则按 RFC 更新**：修复若干健全性漏洞，部分旧 unsafe 代码会开始编译失败。

## Language
- 宏内类型/路径后可跟分号。
- `'static` 变量允许递归引用。
- ref 绑定正确区分 Deref/DerefMut。

## Libraries
- `std::time` 与 `Duration` 稳定。
- `Box<str>`/`Box<[T]>` 实现 `Clone`。
- `CString` 实现 `Borrow`，`CStr` 实现 `ToOwned`。
- `CStr`/`AtomicPtr` 实现 `Debug`。
- **`Error` trait 对象可下转型**：`is`/`downcast`/`downcast_ref`/`downcast_mut`，类似 `Any`。
- 子串搜索改用 **two-way 算法**：`contains`/`find`/`rfind`/`split` 等大幅提速。
- 切片 `PartialEq` 更快。
- `Hash` 新增默认方法 `hash_slice`；`Hasher` 增加 `write_*` 特化方法。
- `io::Error` 新增 `get_ref`/`get_mut`/`into_inner`。
- `process::Child::id` 返回 pid。
- `concat`/`join`：切片 connect 弃用改名为 join。
- `Wrapping` 实现 `Div`；`String` 实现 `DerefMut`；SipHash 对长数据更快。

## Misc
- 可产出 Windows XP 程序（非官方支持）；MSVC 移植继续；i686 FreeBSD 初步支持；`--explain` 错误更多；LLVM 写 archive 减少 ar 依赖；若干 lint 收紧。
