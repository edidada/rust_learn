# Rust 1.44.0（2020-06-04）

> 来源：[releases.rs/docs/1.44.0](https://releases.rs/docs/1.44.0/)；演示：`cargo run -p versions --bin rustc_1_44_0`

## Language
- `#![no_std]` 下可使用 `async`/`.await`。
- 新增 `unused_braces` lint（提示多余花括号）。
- **语法仅变更**：outline module 现在在展开驱动下可先解析，`#[cfg(FALSE)] mod foo { mod bar; }` 里不存在的文件不会立即报错（语义上仍然拒绝）。

## Compiler
- 增量模式下 rustc 尊重 `-C codegen-units`，且增量模式默认 256 codegen 单元。
- `catch_unwind` 在无 unwind 时零开销。
- 新增若干 tier 3 目标（aarch64-none(-softfloat)、apple tvos）。

## Libraries
- 特化 `vec![]` 直接映射 `Vec::new()`，因此 `vec![]` 可用于 const（如 const 环境建空 vec）。
- `convert::Infallible` 实现 `Hash`。
- `OsString` 实现 `DerefMut`/`IndexMut`（返回 `&mut OsStr`）。
- Unicode 升级到 13。
- `String` 实现 `From<&mut str>`。
- `IoSlice` 实现 `Copy`。
- `Vec<T>` 实现 `From<[T; N]>`（N ≤ 32）。
- `proc_macro::LexError` 实现 `fmt::Display`/`Error`。
- 所有整数类型的 `from_le_bytes`/`to_le_bytes`/`from_be_bytes`/`to_be_bytes`/`from_ne_bytes`/`to_ne_bytes` 成为 const。

## Stabilized APIs
- `PathBuf::with_capacity` — 按容量构造
- `PathBuf::capacity` — 当前容量
- `PathBuf::clear` — 清空为空路径
- `PathBuf::reserve` — 预留容量
- `PathBuf::reserve_exact` — 精确预留
- `PathBuf::shrink_to_fit` — 收缩容量
- `f32::to_int_unchecked` — 浮点→整数 unchecked 转换（越界是 UB）
- `f64::to_int_unchecked` — 同上（f64）
- `Layout::align_to` — 对齐提升
- `Layout::pad_to_align` — 尺寸补齐到对齐
- `Layout::array` — 数组布局
- `Layout::extend` — 串联两个布局

## Cargo
- 新增 `cargo tree` 命令：依赖树打印；`cargo tree -d` 显示同 crate 多版本。

## Misc
- rustdoc `--crate-version` 把版本写进侧边栏。

## Compatibility Notes
- Windows GNU 目标静态库正确用 `.a` 扩展（原先错用 `.lib`）。
- 移除 rustc 的 `-C no_integrated_as`。
- JSON 输出里宏错误的 `file_name` 指向真正源文件。
- 最低外部 LLVM 版本提到 LLVM 8。
- `mem::{zeroed, uninitialised}` 用于禁止零初始化的类型（如 `NonZeroU8`）时 panic（原为警告）。
- **预告**：1.45.0 起 `f64 as u32` 等越界转换改为 saturating（此前 UB）；性能敏感场景可改用 `to_int_unchecked`。

## Internal Only
- 内部编译性能改进（dep_graph 小读数分配、JS 大字典改 JSON 解析等）。
