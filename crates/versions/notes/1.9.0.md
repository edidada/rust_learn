# Rust 1.9.0（2016-05-26）

> 来源：[releases.rs/docs/1.9.0](https://releases.rs/docs/1.9.0/)；演示：`cargo run -p versions --bin rustc_1_9_0`

## Language
- **`#[deprecated]` 属性生效**：使用被标注的 API 会产生警告，可用 `#[allow(deprecated)]` 压制（RFC 1270）。
- **fn item 类型零大小**，每个 fn 名对应唯一类型（transmute fn 将先警告后转错误）。
- 字段/方法解析理解可见性，私有成员不再干扰公有成员的使用。
- 解析器把 PATTERN_WHITE_SPACE 类的 Unicode 码点视为空白。

## Stabilized APIs（精选教学常用）
- **`std::panic` 模块**：`catch_unwind`（改名自 recover）、`resume_unwind`（改名自 propagate）、`AssertUnwindSafe`、`UnwindSafe`
- `str::is_char_boundary`
- `<*const T>::as_ref` / `<*mut T>::as_ref` / `as_mut`
- `AsciiExt::make_ascii_uppercase`/`make_ascii_lowercase`
- `char::decode_utf16`、`DecodeUtf16`、`DecodeUtf16Error::unpaired_surrogate`
- `BTreeSet::take`/`replace`/`get`、`HashSet::take`/`replace`/`get`
- `OsString::with_capacity`/`clear`/`capacity`/`reserve(_exact)`、`OsStr::is_empty`/`len`
- `slice::copy_from_slice`
- `ptr::read_volatile`/`write_volatile`
- `OpenOptions::create_new`
- `File::try_clone`
- `SocketAddr*` 系列的 set_ip/set_port 等
- TCP/UDP 大量 socket 选项方法（set_nodelay、set_ttl、set_nonblocking、join_multicast_* 等）
- `HashSet::hasher`/`HashMap::hasher`
- `CommandExt::exec`（Unix）
- （另有 Unix pthread 句柄扩展 `JoinHandleExt` 等）

## Libraries
- `std::sync::Once` 初始化函数失败即毒化。
- `Ref`/`RefMut` 可容纳非 Sized 类型。
- 绝大多数类型实现 `fmt::Debug`。
- `BufReader`/`BufWriter` 默认缓冲区从 64K 降到 8K。
- `Instant`/`SystemTime`/`Duration` 实现 `+=`/`-=`（Duration 还有 `*=`/`/=`）。
- `Skip` 实现 DoubleEndedIterator；`From<[u8; 4]> for Ipv4Addr`；`Chain` 实现 BufRead；HashMap/HashSet 协变化。

## Cargo
- 并发运行；顶层 override 可钉住特定 revision；导出 `CARGO_PKG_AUTHORS`；`RUSTFLAGS` 与 `build.rustflags` 传入 rustc。

## Performance
- 类型合一中变量等价比较复杂度 O(n!)→O(n)；`ToString` 对 str 特化；`Command::output` 不再创建额外线程；C-like enum 的 derive 产出更少代码。

## Misc
- `--quiet` 测试输出精简；新目标 mips musl / i586-msvc 的 std。

## Compatibility Notes
- `Once` 毒化；重叠固有 impl 中同名方法非法；fn item transmute 警告；const 求值改进可能让越界整型字面量报错。
