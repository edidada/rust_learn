# Rust 1.0.0（2015-05-15）

> 来源：[releases.rs/docs/1.0.0](https://releases.rs/docs/1.0.0/)；演示：`cargo run -p versions --bin rustc_1_0_0`

约 1500 处变更。Rust 第一个稳定 1.0 版本。

## Highlights
- 标准库绝大多数 API 标记 `#[stable]`：stable 编译器不再能使用 unstable feature，crates.io 主流 crate 开始能在 stable 通道工作。
- 基本整数类型在 debug 构建下溢出算术会 panic（checker on overflow）。

## Language
- **trait 一致性（coherence）收紧**：防止上游作者改 trait 时弄坏下游代码。
- 二进制/八进制字面量词法更贪：`0b1234` 现在作为一个 token 而不是 `0b1` + `234`。
- **trait bound 恒为 invariant**：移除了 `PhantomFn`/`MarkerTrait` 语言项。
- crate 名不再允许 `-`；`extern crate "foo" as bar` 改为 `extern crate foo as bar`，Cargo 自动把包名里的 `-` 翻译成下划线。
- 生命周期遮蔽（shadowing）变成错误。
- **Send 不再隐含 'static**。
- UFCS 支持 `MyType::default()` 这类不带 trait 的关联路径。
- 基本类型获得固有方法，不再需要 `SliceExt` 之类的扩展 trait。
- `where` 子句里带 `Self: Sized` 的方法视为对象安全，`IteratorExt` 等得以并入核心 trait。
- 可以在 `where` 子句中引用关联类型。
- OIBIT 完全落地：`Send`/`Sync` 现在由标准库定义。
- 引入 `Reflect` trait：`Any` 向下转型实际限定到具体类型，保住"参数性"（parametricity）。
- `unsafe_destructor` feature 弃用，改用新的 dropck。
- Copy 现在继承自 Clone：所有 Copy 类型必然可 Clone。
- Index/IndexMut 改为按值取索引，`hash_map["string"]` 之类可用。
- Fn trait 间建立继承关系并提供 blanket impl。

## Libraries
- `thread_local` 模块改名 `std::thread`。
- `IteratorExt` 方法并入 `Iterator` trait 本身。
- `AsMut`/`AsRef`/`From`/`Into` 定型到 `std::convert`。
- `FromError` 移除，由 `From` 取代。
- sleep 移入 `std::thread::sleep_ms`（Millisecond 版，后来又被 `thread::sleep(Duration)` 取代）。
- `splitn` 的 n 表示产出条数而不是"切几刀"。
- Unix 上所有文件描述符默认 CLOEXEC。
- derive 的 `PartialOrd` 按显式 discriminant 排序枚举。
- 字符串搜索方法泛型化于 Pattern（`&char`、`&str`、`FnMut(char)->bool` 等）。
- 方法解析中对象方法排在固有方法之前。
- `String::from_str` 弃用，用 `String::from` / From impl。
- `io::Error` 实现 `Sync`。
- `&str::words` 被 `split_whitespace` 取代。
- 新的 path/IO 模块完整并 `#[stable]`（本周期库工作重心）。
- 新字符串 Pattern API 落地。
- 泛型数值 trait 全部移除（靠基本类型固有方法）。
- 大量 std API 稳定化：非弃用 API 约 75% 已稳定。

## Misc
- 很多错误带扩展解释，`rustc --explain E0xxx` 可查。
- 标准库文档补充大量示例。
- rustdoc 打磨；元数据调优使二进制缩小 27%。
