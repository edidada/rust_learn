# Rust 1.91.0（2025-10-30）

> 来源：[releases.rs/docs/1.91.0](https://releases.rs/docs/1.91.0/)；演示：`cargo run -p versions --bin rustc_1_91_0`

## Language
- **模式绑定按书写顺序 lowering，drop 顺序基于主绑定顺序**：多模式同一位置绑定时（`Some(a) | Some(b)` 之类），按书写顺序编译、drop 按主绑定。
- **稳定 C 式变参函数声明（sysv64/win64/efiapi/aapcs ABI）**：与 C ABI 一致——可在外部 `extern` 块中*声明* `(...)`，但不能*定义*。
- 新增 `dangling_pointers_from_locals` lint（warn）：局部变量悬垂指针告警。
- `integer_to_ptr_transmutes` lint（warn）：`mem::transmute<整数, 指针>` 告警，应改 `with_exposed_provenance`。
- LoongArch32 inline asm 稳定；sse4a、tbm target features 稳定。
- 新 `cfg(target_env = "macabi" / "sim")`（替代同名 `target_abi`）。

## Compiler / Platform Support
- `aarch64-pc-windows-gnullvm`、`x86_64-pc-windows-gnullvm` 升 Tier 2。
- **`aarch64-pc-windows-msvc` 升为 Tier 1**。
- 不再对 never→any 的 cast 警告 unreachable。

## Libraries
- panic 消息里打印线程 ID；修复 `core::panic::Location::file` 的过严生命周期。
- 保证 `min/max/minmax` 的 `_by()` 变体参数顺序承诺。
- `std::thread` 设置栈大小失败改为返回错误（原库内 panic）。

## Stabilized APIs（条目多，全列）
- `Path::file_prefix`
- `AtomicPtr::{fetch_ptr_add, fetch_ptr_sub, fetch_byte_add, fetch_byte_sub, fetch_or, fetch_and, fetch_xor}`
- `{integer}::strict_*` 全族：`strict_add/sub/mul/div/div_euclid/rem/rem_euclid/neg/shl/shr/pow`
- `i{n}::{strict_add_unsigned, strict_sub_unsigned, strict_abs}`；`u{n}::{strict_add_signed, strict_sub_signed}`
- `PanicHookInfo::payload_as_str`
- `core::iter::chain`、`core::array::repeat`
- `PathBuf::add_extension` / `PathBuf::with_added_extension`
- `Duration::from_mins` / `Duration::from_hours`
- Path/String/str 互转的 8 个 `PartialEq` impl（`PathBuf==str/String`、`Path==str/String`、`String/str == Path/PathBuf`）
- `Ipv4Addr::from_octets` / `Ipv6Addr::from_octets` / `Ipv6Addr::from_segments`
- `impl Default for Pin<Box<T>> / Pin<Rc<T>> / Pin<Arc<T>>`（T: ?Sized 且 Box/Rc/Arc: Default）
- `Cell::as_array_of_cells`
- `u{n}::{carrying_add, borrowing_sub, carrying_mul, carrying_mul_add}`
- `BTreeMap::extract_if` / `BTreeSet::extract_if`
- `str::{floor_char_boundary, ceil_char_boundary}`
- `impl Sum/Product for Saturating<u{n}>`（含 `&Self` 4 项）
- const 化（此前已稳定）：`<[T;N]>::each_ref/each_mut`、`OsString::new`、`PathBuf::new`、`TypeId::of`、`ptr::with_exposed_provenance(+_mut)`

## Cargo
- 🎉 **稳定 `build.build-dir`**：中间构建产物的目录（布局为实现细节，可能变化）。
- `--target` / `build.target` 接受 `"host-tuple"` 字面量，代换为主机三元组。

## Rustdoc
- 搜索结果中 doc alias 排序低于同名非别名条目。
- 裸指针并入类型搜索（如 `*const u8 ->`），签名正常显示。

## Compatibility Notes（条目多，全列）
- 协程（coroutine）捕获必须 drop-live。
- Apple 链接时总是传 SDK root（`SDKROOT`）；`/usr/local/lib` 不一定自动链接，需要时在 build.rs 显式 `cargo::rustc-link-search`。
- 关联类型绑定位置放宽的 bounds（如 `TraitRef<AssocTy: ?Sized>`）禁止。
- 增加（unstable）`#[sanitize(xyz = "on|off")]` 内建属性，遮蔽同名过程宏。
- let-else 绑定的 drop checker 收紧。
- 更严格地解析属性：无效 `#[should_panic]`、无效 `#[link]` 直接报错。
- 名字解析中的弃用 lint 均 deny-by-default 且在依赖中报告。
- `semicolon_in_expressions_from_macros` 升为 deny。
- 固有 impl 中出现 trait impl 修饰符（`unsafe`/`!`/`default`）语法无效。
- `pin!`/`format_args!`/`write!`/`writeln!` 在 2024 edition 的 if let scrutinee 中临时量作用域收紧。
- 元组索引/字段名位置的无效数字字面量后缀被拒绝。
- `static` 闭包语法无效；`--cfg`/`--check-cfg` 参数含 shebang 不再允许。
- 预告：1.92 将有临时生命周期缩短的 future-incompat lint。
- Cargo：`build.build-dir` 设置后 `cargo publish` 不再保留 .crate 压缩包（用 `cargo package` 生成）；Cargo 输出消息风格对齐 rustc（部分颜色变化）。
