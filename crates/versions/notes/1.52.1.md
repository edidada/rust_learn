# Rust 1.52.1（2021-05-10）

> 来源：[releases.rs/docs/1.52.1](https://releases.rs/docs/1.52.1/)；演示：`cargo run -p versions --bin rustc_1_52_1`

## Patch（此为补丁版本）
- **关闭默认增量编译**：除非用户显式通过新加的 `RUSTC_FORCE_INCREMENTAL=1` 环境变量选择加入，否则不再启用增量编译。
  - 原因：1.52.0 新启用的增量编译校验在真实项目里**大面积、高频触发破坏**。
  - 提示：这些 bug 在历史稳定版中同样存在（只是 1.52.0 才被检测出来），且当时任何渠道都未修复；这些问题可导致二进制**误编译（miscompilation）**。用户应升级到 1.52.0 或 1.52.1。
  - 影响范围：仅增量构建受影响；Cargo 的 release（非增量）构建不受影响（除非显式开启增量）。debug 和 check 构建受影响。
  - 详情见 issue 84970。
