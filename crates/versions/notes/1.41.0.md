# Rust 1.41.0（2020-01-30）

> 来源：[releases.rs/docs/1.41.0](https://releases.rs/docs/1.41.0/)；演示：`cargo run -p versions --bin rustc_1_41_0`

## Language
- 对外部（foreign）项实现 trait 时可带类型参数：如 `impl<T> From<Foo> for Vec<T> {}`。
- self 位置的 receiver 类型可任意嵌套：如 `fn foo(self: Box<Box<Self>>)`（此前只允许 `Self`、`&Self`、`&mut Self`、`Arc<Self>`、`Rc<Self>`、`Box<Self>`）。
- `format_args!` 可用任意合法标识符（下划线开头此前不允许）。
- trait 项与枚举变体语法上允许可见性修饰符（`pub`），语义上仍被拒绝（便于过程宏/条件编译感知）。
- Rust 的 `extern \"C\"` 函数可使用 `Box<T>`，C 侧用 `T*` 对应（附带避免在 C 侧声明的函数签名里用 `Box<T>` 的告诫）。

## Compiler
- rustc 对未使用的 loop `label` 发出警告。
- 移除 `i686-unknown-dragonfly` 目标；新增 tier 3 `riscv64gc-unknown-linux-gnu`。
- rustc 支持 `@path` 参数文件；`--extern` 可不带路径。

## Libraries
- `core::panic` 模块稳定（此前经 std 已可稳定使用）。
- NonZero* 类型间可实现 `From` 窄化转换：如 `NonZeroU16` 实现 `From<NonZeroU8>`。
- `MaybeUninit<T>` 实现 `fmt::Debug`。

## Stabilized APIs
- `Result::map_or` — 解包并按值映射（`ok_or` 后 `map` 的合体）
- `Result::map_or_else` — 同上（错误按闭包供给）
- `std::rc::Weak::weak_count` / `strong_count` — 弱/强引用计数
- `std::sync::Weak::weak_count` / `strong_count` — 同上（跨线程版）

## Cargo
- 二进制 crate 默认会文档化所有私有项。
- `cargo-install` 检测到过时会重新安装包。
- `Cargo.lock` 采用更 git 友好的格式，减少合并冲突。
- 可按依赖覆盖构建设置：`[profile.dev.package.image] opt-level = 2`；另有 `[profile.<profile>.build-override]`。

## Misc
- rustdoc 代码块可用 `edition2018` 等指定编译 edition。
- rustdoc `--theme` 自定义主题、`--check-theme` 检查主题。
- `#[cfg(doc)]`：仅在构建文档时编译对应条目。

## Compatibility Notes
- **32 位 Apple 目标降级**：1.41 是 tier 1 支持的最后版本，源码仍可自编译，但项目不再测试及分发这些目标的二进制。
