# Rust 1.47.0（2020-10-08）

> 来源：[releases.rs/docs/1.47.0](https://releases.rs/docs/1.47.0/)；演示：`cargo run -p versions --bin rustc_1_47_0`

## Language
- **闭合（未使用）的 closure 现在会告警**——定义了却从不使用的 closure 触发 warning。

## Compiler
- 稳定 `-C control-flow-guard` codegen 选项：为 Windows 平台启用 Control Flow Guard（CFG），其他平台忽略。
- 升级 LLVM 11。
- 新增 tier 3* 目标：`thumbv4t-none-eabi`。
- FreeBSD 工具链升级到 11.4。
- `RUST_BACKTRACE` 输出更紧凑。

## Libraries
- `CStr` 实现 `Index<RangeFrom<usize>>`。
- **std/core 的 trait 对任意长度数组实现**（不再仅限长度 ≤ 32 的数组）——数组的泛型能力大幅放开。
- `ops::RangeFull` 与 `ops::Range` 实现 `Default`。
- `panic::Location` 实现 `Copy`、`Clone`、`Eq`、`Hash`、`Ord`、`PartialEq`、`PartialOrd`。

## Stabilized APIs
- `Ident::new_raw` — 用原始标识符创建 proc_macro Ident
- `Range::is_empty` — 空范围判断
- `RangeInclusive::is_empty` — 含端点范围的空判断
- `Result::as_deref` — `Result<T: Deref, E>` → `Result<&T::Target, E>`
- `Result::as_deref_mut` — 可变版本
- `Vec::leak` — 把 Vec 泄漏成 `&'a mut [T]`
- `pointer::offset_from` — 同一分配内两指针的有符号差
- `f32::TAU` — 常量 τ = 2π
- `f64::TAU` — 常量 τ = 2π
- 以下既有方法成为 const fn：
  - 所有 NonZero 整数的 `new`
  - 所有整数的 `checked_add`/`checked_sub`/`checked_mul`/`checked_neg`/`checked_shl`/`checked_shr`/`saturating_add`/`saturating_sub`/`saturating_mul`
  - 有符号整数的 `checked_abs`/`saturating_abs`/`saturating_neg`/`signum`
  - `char`/`u8` 的 `is_ascii_alphabetic`/`is_ascii_uppercase`/`is_ascii_lowercase`/`is_ascii_alphanumeric`/`is_ascii_digit`/`is_ascii_hexdigit`/`is_ascii_punctuation`/`is_ascii_graphic`/`is_ascii_whitespace`/`is_ascii_control`

## Cargo
- build-dependencies 默认以 opt-level 0 构建；可用 `[profile.release.build-override] opt-level = 3` 覆盖。
- `cargo-help` 现在为命令显示 man 页（而非仅 --help 文本）。
- `cargo-metadata` 新增 `test` 字段指示目标是否启用了测试。
- `workspace.default-members` 现在遵守 `workspace.exclude`。
- `cargo-publish` 当 package.publish 只指定一个 registry 时默认使用它。

## Misc
- rustdoc 搜索栏旁新增帮助按钮，说明 rustdoc 的按类型搜索。
- rustdoc 新增 Ayu 主题。

## Compatibility Notes
- Emscripten 最低支持版本提升到 1.39.20。
- 修复解析尾表达式 `{} && false` 的回归。
- 过程宏在 `macro_rules!` 中展开的处理变化，应保存更多 span 信息；若宏不卫生（unhygenic）或未正确处理 `Delimiter::None` 可能编译失败。
- CloudABI 目标支持降为 tier 3。
- linux-gnu 目标要求最低内核 2.6.32、glibc 2.11。
- 新增 `rustc-docs` 组件，可安装并阅读编译器内部 API 文档（当前仅 x86_64-unknown-linux-gnu）。
