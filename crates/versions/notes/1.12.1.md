# Rust 1.12.1（2016-10-20）

> 来源：[releases.rs/docs/1.12.1](https://releases.rs/docs/1.12.1/)；演示：`cargo run -p versions --bin rustc_1_12_1`

补丁版本（patch release），修复 1.12.0 引入的回归。

## Regression Fixes
- ICE：`'assertion failed: concrete_substs.is_normalized_for_trans()'`（[#36381](https://github.com/rust-lang/rust/issues/36381)）。
- 布尔值双重取反（`!!x`）引发的混淆。
- rustc 1.12.0 release 模式 SIGSEGV（syn crate 0.8.0 触发）。
- ethcore crate 在 Windows 上构建报 LLVM 错误。
- release 模式带调试信息链接时内存占用过高。
- 升级到 1.12 后出现内存损坏。
- `Let NullaryConstructor = something;` 导致内部编译错误（"tried to overwrite interned AdtDef"）。
- 修复 ICE：invoke/call/store 类型不匹配时注入 bitcast。
- debuginfo：以更稳定的方式处理 MIR-trans 中的 spread_arg。
