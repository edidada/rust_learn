# Rust 1.26.0（2018-05-10）

> 来源：[releases.rs/docs/1.26.0](https://releases.rs/docs/1.26.0/)；演示：`cargo run -p versions --bin rustc_1_26_0`

## Language
- **闭包实现 Copy/Clone**：所有捕获变量均满足对应 trait 时成立。
- **含尾区间范围 `..=` 稳定**：`for x in 0..=10` 等。
- **`'_` 生命周期稳定**：可出现在任何可省生命周期处，如 `impl Reader for BufReader<'_> {}`。
- **`impl Trait` 返回位置稳定**：`fn foo() -> impl Iterator<Item=u8>`（参数位置 1.25 已稳定）。
- **模式匹配自动解引用**（match ergonomics）。
- **`u128`/`i128` 128 位整数稳定**。
- **`main` 可返回 `Result<(), E: Debug>`**，返回 `Err` 时进程以非零码退出并打印 Debug 信息。
- 大量操作可用于 const 上下文：常量数组索引、常量引用/解引用、元组结构体构造等。
- **切片固定模式匹配稳定**：
  ```rust
  match points {
      [1, 2, 3, 4] => println!("All points were sequential."),
      _ => println!("Not all points were sequential."),
  }
  ```

## Compiler
- wasm32-unknown-unknown 默认链接器改为 LLD；修复嵌套类型的指数级投影复杂度（某些 crate 编译时间降低约 12%）；新增 `--remap-path-prefix`、`powerpc-unknown-netbsd` 目标。

## Libraries
- `From<u16> for usize` 等实现；整数 `fmt::Debug` 支持十六进制（`{:02x?}`）；`cmp::Reverse` 实现 `Default/Hash/Copy/Clone`。
- `str::repeat` 大场景提速 8x；`ascii::escape_default` 进 libcore；std/core 宏支持尾逗号；`char::{ToLowercase,ToUppercase}` 可 `Clone`。

## Stabilized APIs（指针方法族 + 更多）
- `*const T::add/sub/wrapping_add/wrapping_sub/copy_to/copy_to_nonoverlapping/read/read_unaligned/read_volatile`
- `*mut T::add/sub/wrapping_add/wrapping_sub/replace/swap/write/write_unaligned/write_volatile/write_bytes/copy_to/copy_to_nonoverlapping/read/read_unaligned/read_volatile`
- `Box::leak`、`FromUtf8Error::as_bytes`、`LocalKey::try_with`、`Option::cloned`
- `btree_map::Entry::and_modify`、`hash_map::Entry::and_modify`、`iter::FusedIterator`
- `ops::RangeInclusive`、`ops::RangeToInclusive`、`process::id`
- `slice::rotate_left/right`、`String::retain`

## Cargo
- `cargo -v --list` 输出自定义命令路径；Cargo 二进制版本号与 Rust 一致。

## Misc
- 官方推荐《The Rust Programming Language》第二版。

## Compatibility Notes
- `use std::ops::Fn as dyn;` 这类别名不再允许。
- 解引用结果不再提升为 `'static`。
- `AsciiExt` trait 正式弃用（改用固有方法）。
- `"e-of"` 之类 `"e0"` 不再解析为 `0.0`，直接报错。
- rustdoc 移除 hoedown；高阶生命周期约束成为硬错误。
