# Rust 1.30.0（2018-10-25）

> 来源：[releases.rs/docs/1.30.0](https://releases.rs/docs/1.30.0/)；演示：`cargo run -p versions --bin rustc_1_30_0`

## Language
- **过程宏（procedural macros）可用**：`#[derive]`/属性式/函数式宏的自定义能力上线。
- **raw identifier（`r#`）**：关键字可作标识符，如 `let r#for = true;`。
- 匿名 trait 参数弃用（2018 版将成硬错误）。
- **路径中可用 `crate`**：`use crate::foo;` 指向 crate 根。
- 使用外部 crate 不再需要 `::` 前缀（以前模块里要写 `::serde_json::from_str(...)`）。
- `#[used]` 属性可防 static 被优化掉。
- **宏可用 `use` 导入/重导出**；`#[macro_export]` 的宏进入 crate 根模块（`local_inner_macros` 建议用于依赖本地宏的宏）。
- 宏可捕获 `vis`（pub 等可见性）；非宏属性允许任意字面量；`#[panic_handler]` 属性。

## Compiler
- 新增 `riscv32imc-unknown-none-elf`、`aarch64-unknown-netbsd` 目标；LLVM 8。

## Libraries
- `ManuallyDrop` 允许未定长内部类型。

## Stabilized APIs
- `Ipv4Addr::BROADCAST/LOCALHOST/UNSPECIFIED`、`Ipv6Addr::LOCALHOST/UNSPECIFIED`（关联常量）
- `Iterator::find_map`
- `str::trim_start`、`str::trim_end`、`str::trim_start_matches`、`str::trim_end_matches`（1.33 弃用 trim_left/trim_right 族的新名字）

## Cargo
- workspace 中 `cargo run` 无需指定包；`cargo doc --message-format=json`；构建进度条。

## Misc
- rustdoc `--edition`、`--color`、`--error-format`；提供 rust-gdbgui 脚本；工具属性（如 `#[rustfmt::skip]`）可用。
