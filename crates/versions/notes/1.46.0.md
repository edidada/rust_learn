# Rust 1.46.0（2020-08-27）

> 来源：[releases.rs/docs/1.46.0](https://releases.rs/docs/1.46.0/)；演示：`cargo run -p versions --bin rustc_1_46_0`

## Language
- **`if`/`match`/`loop` 表达式可用于 const fn**——const 求值能力大幅扩展。
- const fn 中可强制转换/强转为 `&[T]` 切片。
- **`#[track_caller]` 稳定**：标注函数后，其中 panic 的消息带调用者位置。
- 元组的递归索引无需括号：`x.0.0`（原先要写 `(x.0).0`）。
- `mem::transmute` 可用于 statics 与 constants（const fn 中仍不允许）。

## Compiler
- Apple iOS/tvOS 可用 cdylib 目标。
- x86_64-unknown-linux-musl 默认静态 PIE。

## Libraries
- `mem::forget` 成为 const fn。
- `String` 实现 `From<char>`。
- 所有整数稳定 `leading_ones`/`trailing_ones`。
- `vec::IntoIter<T>` 实现 `AsRef<[T]>`。
- NonZero 类型对其可零类型实现 `TryFrom`（如 `NonZeroU8: TryFrom<u8>`）。
- `&[T]`/`&mut [T]` 实现 `PartialEq<Vec<T>>`。
- `(String, u16)` 实现 `ToSocketAddrs`。
- `vec::Drain<'_, T>` 实现 `AsRef<[T]>`。

## Stabilized APIs
- `Option::zip` — 两 Option 合并成元组 Option
- `vec::Drain::as_slice` — 取已出队项的切片

## Cargo
- 编译时新增若干环境变量：`CARGO_BIN_NAME`/`CARGO_CRATE_NAME`、`CARGO_PKG_LICENSE`、`CARGO_PKG_LICENSE_FILE`。

## Compatibility Notes
- 目标配置 `abi_blacklist` 更名为 `unsupported_abis`（旧名仍可用）。
- 对实现 `Drop` 的 C-like enum 做 cast 现在 warn（未来硬化）。
- `#[repr(i128)]`/`#[repr(u128)]` 用于 struct 时编译失败（仅 enum 允许）。
- `macro_rules!` 接到的 token 现在总是捕获 span 信息，可能破坏依赖 dummy span 的宏。
- Windows 的 InnoSetup 安装器不再提供。
- `{f32,f64}::asinh` 对负数返回正确值。
- 不再接受仅因 lifetime 绑定不同而重叠的 trait impl。
- 修复 existential associated type 的 lifetime 推导（少数曾错误通过的代码现在拒绝）。
- Linux 上 rustc 动态链接 libz（需系统安装）。
- ARMv7 + QEMU 下 `#[should_panic]` 测试不可用。
- 过程宏的 pretty printing 输出改变（不稳定实现细节）。
