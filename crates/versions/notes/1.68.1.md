# Rust 1.68.1（2023-03-23）

> 来源：[releases.rs/docs/1.68.1](https://releases.rs/docs/1.68.1/)；演示：`cargo run -p versions --bin rustc_1_68_1`

Patch 版本，内容很少，全部照实记录。

## Changes
- **修复 Windows MSVC 产物中的错误编译（miscompilation）**：由为发布版 rustc 启用 ThinLTO 引入，当前认为仅限于 rustc 自身编译使用的 `-Zdylib-lto` 场景，并非 ThinLTO 的通用 bug，只有 rustc 的产物受影响。
- 修复 `--enable-local-rust` 构建。
- 链接器检测代码中把 `$prefix-clang` 当作 clang。
- 修复编译器代码中的一个 panic。
