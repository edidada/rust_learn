# Rust 1.59.0（2022-02-24）

> 来源：[releases.rs/docs/1.59.0](https://releases.rs/docs/1.59.0/)；演示：`cargo run -p versions --bin rustc_1_59_0`

## Language
- **const 参数默认值稳定**：const 泛型参数可写默认值（如 `struct Foo<const N: usize = 3>`），并取消类型/const 参数的排序限制（const 参数可混排在类型参数之间）。
- **destructuring assignment 稳定**：可在赋值/复合赋值左侧用模式（tuple/struct/slice 等解构直接赋值）。
- 放宽 trait impl 上泛型 bound 和 where 子句的 private-in-public lint。
- `asm!` / `global_asm!` 对 x86、x86_64、ARM、Aarch64、RISC-V 稳定（注：`let ... else` 是 1.65.0 稳定，本版没有）。

## Compiler
- 新符号 mangling 格式稳定（opt-in `-Csymbol-mangling-version=v0`）；`-Cremark`；sparc64 ABI 修复。
- 相同 `#[test]` 类属性宏重复出现时告警；新增 `riscv64gc-unknown-freebsd`（tier 3）；`--json future-incompat` 稳定。
- **本版再次默认关闭增量编译**：一个已知增量编译 bug 频发造成 ICE，除非设置 `RUSTC_FORCE_INCREMENTAL=1`（需 94124）。

## Libraries
- 部分 `Hash{Map,Set}` 方法去掉不必要的 bound。

## Stabilized APIs
- `std::thread::available_parallelism` — 可用并行度
- `Result::copied` / `Result::cloned`
- `core::arch::asm!` / `core::arch::global_asm!`
- `ops::ControlFlow::{is_break, is_continue}`
- `TryFrom<char> for u8`，配套 `TryFromCharError`（实现 Clone/Debug/Display/PartialEq/Copy/Eq/Error）
- `iter::zip` — 自由函数 zip
- `NonZeroU{8,16,32,64,128,size}::is_power_of_two`
- `ToLowercase` / `ToUppercase` 实现 `DoubleEndedIterator`
- `TryFrom<&mut [T]> for [T; N]` — 可变切片转数组
- `Once` 实现 `UnwindSafe` / `RefUnwindSafe`
- aarch64 ARMv8 Neon intrinsics
- **Const-stable**：`mem::MaybeUninit::{as_ptr, assume_init, assume_init_ref}`、`ffi::CStr::from_bytes_with_nul_unchecked`

## Cargo
- 稳定 strip 相关 profile 选项、future-incompat 报告；`--release` 可缩写 `-r`；term.quiet 配置；`cargo {publish,search,login}` 移除 `--host`。

## Compatibility Notes
- std::sys::unix 弱符号重构（如 1.58 所述）可能在较新 glibc 生成带版本的新符号。
- `#![cfg_attr(..., crate_type/crate_name = ...)]` 弃用（future-compat lint）；改用命令行 flag。
- `#[no_link]` 对名字解析不再有效，可能暴露新名字与现有名字冲突。
- Cargo 先编译库再编译二进制（文档生成顺序）；`doc=false` 依赖也被尊重。
- `zip`弱化对底层 iterator advance 的保证（可多 advance，需配合 `zip_relay`）。
- 空切片上的 `split_inclusive()` 输出空。
- Windows 上 `std::env::temp_dir` 可用时改用 `GetTempPath2`。
- `unreachable!` 对齐 2021 其它格式化宏行为（如不再打印非字符串参数）。
